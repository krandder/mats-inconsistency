**Verdict.** The numbers are genuine outputs of the code (R22A: 507/507 table numbers match the JSON; a CPU re-run of seed 101 reproduces them to a median 0.0045), but the claims are artefacts of the design: every "paradigm" is the same 181k-parameter network with a different hand-written loss and test-time formula, none is an OpenSpiel reference algorithm, training is 40 full-batch steps (OpenSpiel games) or 36 steps on 72 states (Stratego), on Leduc 7 of 8 arms are worse than uniform random (NashConv 4.75) so "Deep_CFR 4.57" and "v3 4.71" are the untrained level, the Stratego piece-deduction table is reproduced with no network at all by the engine's hand-written setup prior (GLC's belief is 0.3 × network + 0.7 × that prior, and the KL target contains the same prior), the Elo ranking is 36 games per pair with p = 0.40 for #1 and a different #1 in each seed, the Dark Hex "#1" is the wrong table (in the main table GLC_AOM_v2 is 6th), and each pre-registration was committed with its results. The GLC world model and search transformer are built and discarded in these runs: the "GLC" agent is the baseline network.

- **a2 Key-piece deduction 88.09% vs 58.93/56.55%: artefact.** Checked against hidden truth (run_r22a:2393-2406), no base rate, captured/revealed pieces count as correct. With the network replaced by uniform (d5_baserates.py, 3 seeds), the engine's priors alone reproduce the table at ply 30: BP prior 88.35 ± 7.16 (GLC arms 88.09), CDCL-only prior 54.81 ± 5.66 (R_NaD 56.55, Deep_CFR 58.93, AZ 56.25, Gumbel 54.17), uniform roster prior 48.21 ± 4.64 (PPO 51.19, GRPO 42.56). GLC's belief = 0.30 × network + 0.70 × BP prior (run_r22a:1816); the BP multipliers (stratego_full.py:738-756, Flag ×9.5 at back-row column 0) encode the setup generator (stratego_full.py:513-564): the flag sat in slot 0 in 360/360 4×4, 176/176 6×6, 44/53 8×8 sampled games. ## Baselines
Every arm is `PureNeuralGameBackbone150K`, 181,250 parameters (RESULTS-R22A:17,47 and PREREG-R24B:49 claim 153,617); arms differ only in hand-written loss and test-time formulas (run_r22a:1052-1150, 1365-1436); none uses OpenSpiel's reference implementations (2.0.2 ships deep_cfr, ppo, nfsp, cfr). "Deep_CFR" = 0.55 × regret matching + 0.45 × softmax (1130-1136); "AlphaZero_PUCT" counts visits over a fixed per-move value with no tree (1090-1109); "Gumbel_MuZero" has no Gumbel noise and no sequential halving (1111-1117). The GLC world model and search transformer are built and discarded (run_r22a:2217, 2667, 2701, 2710). Training: 40 full-batch steps (2680) / 72 states × 36 steps (2710-2715); all of R22A took 1,883 s for 3 seeds; no learning trend at checkpoints. Stratego inputs, targets, belief weights and move-scoring constants are switched by paradigm name (1674, 1605-1614, 1816-1835, 1876-1882). The leak auditor's S7/S8 rules are a blacklist of 11 variable names (ast_leak_auditor.py:66-78). "Pure-neural" is inaccurate: for B>1 every arm runs 1, 3 or 4 value-backup passes over the exact game tree with true payoffs (1069, 1001-1020).

## Elo mechanism
Games are played with seats swapped (run_r22a:1990-2045); Bradley-Terry-Davidson MAP fit with bootstrap (elo_league.py:566-740); no synthetic match formula in R22A/R24B; PPO anchored at 1000.00 (2157); in the balanced round-robin Elo reorders total points (seed 101: GLC and GLC_Gen 1,300 points each, 1141.84 each). R18 used 0.85 × a hand-set formula Elo + 0.15 × measured (run_r18:2140-2158).

## Leakage
No agent input reads hidden ranks; encoders use public information; lookahead re-samples hidden ranks from the agent's own belief (run_r22a:1905-1910). The leak is the setup-generator knowledge in GLC's 70% BP prior. OpenSpiel-side opponent-derived belief targets are a training loss only (815-821).
