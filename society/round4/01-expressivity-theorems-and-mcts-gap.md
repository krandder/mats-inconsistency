3. **Answering Question 2 — The 5 Classes of Game Search Algorithms That Even `GLC-Search-Transformer v1` CANNOT Represent, and How `GLC-Search-Transformer v2` Closes All 5 (`Theorem R4.3`):**
   Auditing production search engines across abstract strategy games, imperfect-information games, and combinatorial solvers (**Stockfish 16 / Alpha-Beta**, **df-pn / Proof-Number Search**, **KataGo MCGS**, **DeepStack / ReBeL / CFR+ / R-NaD**, **Gumbel MuZero Sequential Halving**, and **Kissat / CaDiCaL CDCL**), we prove (`Theorem R4.3`) that `GLC-Search-Transformer v1` still hits **5 fundamental expressivity barriers**, and we design **`GLC-Search-Transformer v2`** to close all five:
   1. **Barrier 1 — Arbitrary-Depth Alternating Minimax / Alpha-Beta & Proof-Number Search (`PNS` / `df-pn`) when Tree Depth $d > L_{\text{tree}}$:**
      - *Why `v1` fails:* MCTS backup is a **commutative monoid** (mean/sum over $\mathrm{Desc}(j)$), so 1 layer of $\mathcal{M}_{\text{desc}}$ collapses any depth $d$ in $O(1)$ steps. By contrast, Minimax ($\max_{c_1} \min_{c_2} \max_{c_3} \dots$) and AND/OR Proof-Number Search ($\text{OR}: \mathrm{pn}=\min, \mathrm{dn}=\sum$; $\text{AND}: \mathrm{pn}=\sum, \mathrm{dn}=\min$) are **non-commutative alternating semirings** ($\mathsf{NC}^1$ alternating tree evaluation barrier): a fixed $L$-layer non-recurrent Transformer cannot evaluate alternating $\max/\min$ of depth $d > L$, nor can symmetric $\mathcal{M}_{\text{sib}}$ represent sequential left-to-right $\alpha\text{--}\beta$ cutoffs.
      - *`GLC-Search v2` Fix:* (i) **Incremental Bottom-Up Ancestor-Spine GRU/Semiring Backup (`upward_spine_backup`)** executed along the active ancestor path $a \in \mathrm{Anc}(b)$ upon `append_node(b)` (or depth-looped upward child attention) + (ii) **Directed Older-Sibling Prefix Mask** $\mathcal{M}_{\text{sib}<}[j, k] = \mathbf{1}[\mathrm{pa}(k) = \mathrm{pa}(j) \land k < j]$ for sequential $\alpha\text{--}\beta$ window propagation.
   2. **Barrier 2 — Transposition Tables & Monte Carlo Graph Search (`MCGS` in KataGo / Zobrist DAGs in Chess/Hex):**
      - *Why `v1` fails:* Syntactic tree `AncMask[j, k]` is strictly a tree: commuted move sequences $(a_1, b_1, a_2) \equiv (a_2, b_1, a_1)$ reaching the same board state $\mathrm{canon}(O_j) = \mathrm{canon}(O_k)$ sit in disjoint tree branches, so $\mathcal{M}_{\text{desc}}[j, \cdot]$ misses all rollouts under $k$'s subtree.
      - *`GLC-Search v2` Fix:* **Transposition-DAG Reachability Closure** $R^{\text{DAG}}_{\text{desc}} = \mathcal{M}_{\text{desc}} \lor (E_{\text{trans}} \cdot \mathcal{M}_{\text{desc}})$ where $E_{\text{trans}}[j, k] = \exp(-\|h_{\text{state}}(C_j) - h_{\text{state}}(C_k)\|_2^2 / \tau_{\text{trans}}) \lor \mathbf{1}[\mathrm{canon}(O_j) = \mathrm{canon}(O_k)]$ pools visits and values across transposition-equivalent DAG subgraphs (`KataGo MCGS`).
   3. **Barrier 3 — Counterfactual Regret Minimization (`CFR+` / `ReBeL` / `R-NaD`) for Imperfect-Information Games (`Proposal-Poker`, `Micro-Stratego`, `Galanis-Market`):**
      - *Why `v1` fails:* In hidden-information games with bluffing/signaling, deterministic $\arg\max Q$ policies are maximally exploitable, and tree nodes $C_j \neq C_k$ with different hidden opponent states but identical player observation $\mathrm{Obs}_i(C_j) = \mathrm{Obs}_i(C_k)$ belong to the same **Information Set (`Infoset`)** $I$. `v1` has no infoset mask, no opponent counterfactual reach $\pi_{-i}(h) = \prod_{e \in \mathrm{Anc}(h), \text{pl}(e) \neq i} \sigma_{-i}(e)$, and no Regret-Matching mixed strategy head.
      - *`GLC-Search v2` Fix:* **Infoset Equivalence Head** $\mathcal{M}_{\text{infoset}}[j, k] = \mathbf{1}[\mathrm{Obs}_{\text{pl}}(C_j) = \mathrm{Obs}_{\text{pl}}(C_k)]$, **Ancestor Log-Reach Accumulator** $\log \pi_{-i}(j) = \sum_{a \in \mathrm{Anc}(j)} \mathbf{1}[\text{pl}(a)\neq i]\log \sigma(a)$, and **Regret-Matching / R-NaD Policy Readout** $\sigma(I, a) \propto \mathrm{ReLU}(R_+(I, a))$.
   4. **Barrier 4 — Gumbel MuZero & Sequential Halving (`SH`) at Low/Moderate Search Budgets ($B \in [2, 32]$):**
      - *Why `v1` fails:* Gumbel MuZero (`Danihelka et al., 2022`) eliminates the top-$\lceil m / 2^p \rceil$ sibling actions at each halving phase $p$ using **hard sibling rank order** $\mathrm{rank}_{\text{sib}}(j) \in \{1, \dots, m\}$. Standard mean or softmax sibling attention cannot compute quantile ranks in 1 layer.
      - *`GLC-Search v2` Fix:* **Pairwise Sibling Dominance / Rank Percentile Head** $\widehat{\mathrm{pct}}_{\text{sib}}(j) = \frac{1}{|\mathrm{Sib}(j)|} \sum_{s \in \mathrm{Sib}(j)} \sigma((S(j) - S(s)) / \tau_{\text{rank}}) \in [0, 1]$, enabling exact Sequential Halving phase survival in 1 layer.
   5. **Barrier 5 — Global Conflict-Clause / Nogood Broadcast Across Disjoint Subtrees (`CDCL` Watched Literals in `Kissat` / `CaDiCaL`):**
      - *Why `v1` fails:* In `v1`, `M_anc[b, a]` only propagates a conflict from leaf $b$ to its own ancestors $\mathrm{Anc}^+(b)$. In modern SAT/CSP solvers, a learned conflict clause (nogood) $C_{\text{nogood}}(b)$ must immediately prune **unrelated future subtrees** $j \notin \mathrm{Anc}(b)$ that attempt the same forbidden partial assignment.
      - *`GLC-Search v2` Fix:* **Global Nogood Cross-Attention Bank** $\mathcal{M}_{\text{nogood}}[j, k] = \mathbf{1}[m_{\text{ql}}(C_k) < \tau_{\text{clash}}]$ broadcasting learned conflict keys from all dead-end leaves $k$ to all open candidate nodes $j$ across the entire tree.

## 1. Forensic Analysis of `R11`/`R12` (`src/search/kv_tree_search.py`): Why Current Algorithms Cannot Represent or Learn MCTS

Let $\mathcal{T}_b = (V_b, E_b)$ be the search tree after $b$ expansions, with nodes $V_b = \{0, 1, \dots, b\}$, root $0$, parent map $\mathrm{pa}: \{1, \dots, b\} \to \{0, \dots, b-1\}$ satisfying $\mathrm{pa}(k) < k$, depth $d(0) = 0, d(k) = d(\mathrm{pa}(k)) + 1$, proper ancestor set $\mathrm{Anc}^+(k) = \{\mathrm{pa}(k), \mathrm{pa}(\mathrm{pa}(k)), \dots, 0\}$, reflexive ancestor set $\mathrm{Anc}(k) = \mathrm{Anc}^+(k) \cup \{k\}$, and reflexive descendant subtree $\mathrm{Desc}(j) = \{k \in V_b : j \in \mathrm{Anc}(k)\}$.

In standard MCTS / AlphaZero PUCT, each node $k \in V_b$ produces a leaf evaluation $v_k \in [-1, 1]$ (or $\mathbb{R}$) upon creation, and every node $j \in V_b$ maintains:
$$N^{\text{MCTS}}(j) \;=\; |\mathrm{Desc}(j)| \;=\; \sum_{k=0}^b \mathbf{1}[k \in \mathrm{Desc}(j)], \qquad Q^{\text{MCTS}}(j) \;=\; \frac{1}{N^{\text{MCTS}}(j)} \sum_{k=0}^b \mathbf{1}[k \in \mathrm{Desc}(j)] \, v_k.$$

## 2. Formal Proofs: Theorem R4.1, Theorem R4.2, and Theorem R4.3

### 2.1 Theorem R4.1: Depth Barrier of 1-Hop Parent-Child Message Passing and Topology Blindness of Flat Edge Attention

> **Theorem R4.1 (Depth Barrier of 1-Hop Parent-Pointer / Flat Edge Attention for MCTS Subtree Aggregation):**
> Consider a search tree $\mathcal{T}_b = (V_b, E_b)$ of active budget $b \le B$ with leaf evaluations $v: V_b \to [-1, 1]$ and edge-salience keys $k^{\text{edge}}: V_b \to \mathbb{S}^{D_{\text{key}}-1}$.
> 1. **(Depth Barrier of $L$-Layer 1-Hop Message Passing):** Let $\mathcal{F}_{\text{1-hop}}^{(L)}$ be the class of $L$-layer message-passing neural networks over $V_b$ where each layer $\ell \in \{1, \dots, L\}$ updates node state $h_j^{(\ell)} = \phi^{(\ell)}\!\big(h_j^{(\ell-1)}, h_{\mathrm{pa}(j)}^{(\ell-1)}, \{\!\{h_c^{(\ell-1)} : c \in \mathrm{Ch}(j)\}\!\}\big)$ using only self, 1-hop parent $\mathrm{pa}(j)$, and 1-hop children $\mathrm{Ch}(j) = \{c : \mathrm{pa}(c) = j\}$ (as in `TreePagedKVBank.append_node` line `238` and `TwoStageTreeClearer` Stage 1 lines `840–893`, `1039–1079`). Then for any node $j \in V_b$ and any descendant $k \in \mathrm{Desc}(j)$ at relative depth $\Delta d(j, k) := d(k) - d(j) > L$:
>    $$\frac{\partial h_j^{(L)}}{\partial v_k} \;\equiv\; \mathbf{0}, \qquad \frac{\partial h_j^{(L)}}{\partial h_k^{(0)}} \;\equiv\; \mathbf{0}.$$
>    Consequently, for any tree containing a chain of length $D > L$, $\sup_{\mathcal{T}_b, v \in [-1,1]^{b+1}} \big| \hat{Q}_j(h_j^{(L)}) - Q^{\text{MCTS}}(j) \big| \ge \frac{D - L}{D + 1} \to 1$ as $D \gg L$. In particular, `R11`/`R12` ($L=0$ for `q_tree_bank` and $L=1$ for `n_exp` and Stage-1 clearing) has worst-case MCTS value approximation error $\ge \frac{D}{D+1}$ (for $Q^{\text{MCTS}}$) and $\ge \frac{D-1}{D+1}$ (for Stage-1 clearing).
> 2. **(Topology Blindness / Sibling-Cousin Conflation of Unmasked Flat Key Attention):** Let $\mathcal{F}_{\text{flat-key}}$ be any permutation-equivariant operator over node tuples $\{(h_k^{(0)}, k_k^{\text{edge}}, d(k))\}_{k=0}^b$ whose pairwise interaction weights $A_{jk} = \psi(h_j^{(0)}, h_k^{(0)}, \langle k_j^{\text{edge}}, k_k^{\text{edge}} \rangle, d(j), d(k))$ do not depend on the transitive ancestor-descendant incidence matrix $R_{jk} = \mathbf{1}[j \in \mathrm{Anc}(k)]$ (as in `TwoStageTreeClearer.stage2_preconditioned_clearing`, lines `895–965`). Then there exist pairs of isomorphic-depth search trees $(\mathcal{T}^{(1)}, \mathcal{T}^{(2)})$ with identical multiset of node features, depths, and edge keys $\{(h_k^{(0)}, k_k^{\text{edge}}, d(k))\}_{k=0}^b$ where two sibling branches $j_1, j_2 \in \mathrm{Ch}(0)$ explore disjoint initial decisions $(v_1, z_1) \neq (v_1, z_2)$ at depth $1$, and subsequent depth-$2$ nodes $k_1, k_2$ clamp the same downstream variable $(v_2, z_3)$ with identical edge keys $k_{k_1}^{\text{edge}} = k_{k_2}^{\text{edge}}$ and opposite leaf values $v_{k_1} = +1, v_{k_2} = -1$:
>    - In $\mathcal{T}^{(1)}$, $\mathrm{pa}(k_1) = j_1, \mathrm{pa}(k_2) = j_2$, so $Q^{\text{MCTS}}_{\mathcal{T}^{(1)}}(j_1) = \frac{v_{j_1} + 1}{2}$ and $Q^{\text{MCTS}}_{\mathcal{T}^{(1)}}(j_2) = \frac{v_{j_2} - 1}{2}$.
>    - In $\mathcal{T}^{(2)}$, $\mathrm{pa}(k_1) = j_2, \mathrm{pa}(k_2) = j_1$ (the depth-2 leaves are attached to the opposite depth-1 parents), so $Q^{\text{MCTS}}_{\mathcal{T}^{(2)}}(j_1) = \frac{v_{j_1} - 1}{2}$ and $Q^{\text{MCTS}}_{\mathcal{T}^{(2)}}(j_2) = \frac{v_{j_2} + 1}{2}$.
>    Yet every operator $f \in \mathcal{F}_{\text{flat-key}}$ produces **identical** outputs $f(\mathcal{T}^{(1)})_j \equiv f(\mathcal{T}^{(2)})_j$ for both $j \in \{j_1, j_2\}$, incurring approximation error $\max_{j \in \{j_1, j_2\}} |f(\mathcal{T})_j - Q^{\text{MCTS}}(j)| \ge \frac{1}{2}$ and selecting the suboptimal MCTS branch with probability $\ge \frac{1}{2}$.

#### Proof of Theorem R4.1:
1. **Part 1 (1-Hop Receptive Field Induction):** Define the undirected tree graph distance $\mathrm{dist}_{\mathcal{T}_b}(u, w)$ on $\mathcal{T}_b$. By definition of $\mathcal{F}_{\text{1-hop}}^{(L)}$, at layer $\ell = 1$, $h_u^{(1)}$ is a function solely of $\{h_w^{(0)} : \mathrm{dist}_{\mathcal{T}_b}(u, w) \le 1\}$. By induction on $\ell$, $h_u^{(L)}$ is a function solely of $\{h_w^{(0)} : \mathrm{dist}_{\mathcal{T}_b}(u, w) \le L\}$. For any descendant $k \in \mathrm{Desc}(j)$, the unique tree path from $j$ to $k$ has length $\mathrm{dist}_{\mathcal{T}_b}(j, k) = d(k) - d(j) = \Delta d(j, k)$. Whenever $\Delta d(j, k) > L$, $k$ lies strictly outside the $L$-ball around $j$, so $\partial h_j^{(L)} / \partial h_k^{(0)} = \mathbf{0}$ and $\partial h_j^{(L)} / \partial v_k = \mathbf{0}$. Consider a tree where node $j$ is the root of a chain $j = c_0 \to c_1 \to \dots \to c_D$ with $v_{c_0} = \dots = v_{c_L} = 0$ and $v_{c_{L+1}} = \dots = v_{c_D} = \sigma \in \{-1, +1\}$. Since $h_j^{(L)}$ is invariant to $\sigma$, any estimator $\hat{Q}_j(h_j^{(L)})$ must output the same constant $\hat{q}$ for both $\sigma = +1$ and $\sigma = -1$, whereas $Q^{\text{MCTS}}(j) = \sigma \frac{D - L}{D + 1}$. By triangle inequality, $\max_{\sigma \in \{-1, +1\}} |\hat{q} - \sigma \frac{D-L}{D+1}| \ge \frac{D-L}{D+1}$.
2. **Part 2 (Adversarial Isomorphic-Bag Tree Construction):** Set $v_{j_1} = v_{j_2} = 0$. In both $\mathcal{T}^{(1)}$ and $\mathcal{T}^{(2)}$, the tuple of node features $\{(h_k^{(0)}, k_k^{\text{edge}}, d(k))\}_{k \in \{0, j_1, j_2, k_1, k_2\}}$ is identical because $k_1$ and $k_2$ have the same depth $d(k_1) = d(k_2) = 2$ and the same parent-relative edge key $k_{k_1}^{\text{edge}} = k_{k_2}^{\text{edge}}$ (both clamp $(v_2, z_3)$). Since $A_{jk}$ depends only on $(h_j^{(0)}, h_k^{(0)}, \langle k_j^{\text{edge}}, k_k^{\text{edge}} \rangle, d(j), d(k))$ without $R_{jk} = \mathbf{1}[j \in \mathrm{Anc}(k)]$, the attention matrix $A$ on $\mathcal{T}^{(1)}$ is identical to $A$ on $\mathcal{T}^{(2)}$. Thus $f(\mathcal{T}^{(1)})_{j_1} = f(\mathcal{T}^{(2)})_{j_1}$. However, $Q^{\text{MCTS}}_{\mathcal{T}^{(1)}}(j_1) = +\frac{1}{2}$ while $Q^{\text{MCTS}}_{\mathcal{T}^{(2)}}(j_1) = -\frac{1}{2}$, so $\max_{m \in \{1, 2\}} |f(\mathcal{T}^{(m)})_{j_1} - Q^{\text{MCTS}}_{\mathcal{T}^{(m)}}(j_1)| \ge \frac{1}{2}\big|(+\frac{1}{2}) - (-\frac{1}{2})\big| = \frac{1}{2}$. $\blacksquare$

### 2.2 Theorem R4.2: Constant-Depth Expressivity of `GLC-Search-Transformer v1` for Commutative Subtree Aggregation (`MCTS-PUCT`, Fixed-Depth `Minimax`, Ancestor-Trail `CDCL`, and `Disjunctive Bayes`)

> **Theorem R4.2 (Constant-Depth Expressivity of `GLC-Search-Transformer v1` with Incremental Ancestor Bitmasks):**
> By maintaining the $O(b)$ incremental ancestor bitmask $M_{\text{tree}}[k, j] = \mathbf{1}[j \in \mathrm{Anc}(k)]$ upon each `append_node` (`kv_tree_search.py:241–242`) and equipping a 3-layer `GLC-Search-Transformer v1` over the search-tree tokens $z_0, \dots, z_b$ with the 7 relational masks $\mathcal{M}^{(b)} = (\mathcal{M}_{\text{self}}, \mathcal{M}_{\text{parent}}, \mathcal{M}_{\text{child}}, \mathcal{M}_{\text{anc}}, \mathcal{M}_{\text{desc}}, \mathcal{M}_{\text{sib}}, \mathcal{M}_{\text{global}})$, multi-temperature softmax attention ($\beta_h \in \{0, \pm \beta_{\max}\}$), and log-sum-exp pooling $\mathrm{LSE}_h(Z)_j = \log(\epsilon + \sum_{k : \mathcal{M}_h[j,k]=1} e^{w_h^\top z_k})$, the 3-layer network represents in weights (for arbitrary tree depth $D \le B$):
> 1. **`Algo 1` (Exact MCTS / AlphaZero PUCT):**
>    - *Layer 1 (`M_desc`, $\beta=0$ & `LSE_desc`):* Computes exact subtree mean $Q^{\text{MCTS}}(j) = \frac{1}{|\mathrm{Desc}(j)|} \sum_{k \in \mathrm{Desc}(j)} v_k$ and exact log subtree visit count $\log N(j) = \log |\mathrm{Desc}(j)|$ for all $j \in \{0, \dots, b\}$ in depth $O(1)$.
>    - *Layer 2 (`M_parent` + MLP + `M_sib`):* Fetches $\log N(\mathrm{pa}(j))$, computes $U(j) = Q^{\text{MCTS}}(j) + c_{\text{puct}} P(j \mid \mathrm{pa}(j)) \frac{\sqrt{N(\mathrm{pa}(j))}}{1 + N(j)}$, and computes sibling margin $\mu_{\text{edge}}(j) = U(j) - \max_{j' \in \mathrm{Sib}(j)} U(j')$.
>    - *Layer 3 (`M_anc`, $-\beta_{\max}$):* Computes the root-to-node path bottleneck $S_{\text{path}}(j) = \min_{a \in \mathrm{Anc}(j) \setminus \{0\}} \mu_{\text{edge}}(a)$, which is strictly positive ($S_{\text{path}}(j) > 0$) **if and only if** $j$ lies on the unique top-down greedy MCTS-PUCT trajectory from the root!
> 2. **`Algo 2a` (Bounded-$L$ Negamax / Proof-Number Update):** Each layer applies $\mathcal{M}_{\text{child}}$ with $\beta = \pm \beta_{\max}$ and $\mathrm{LSE}_{\text{child}}$ to compute 1 ply of alternating negamax $\max_{c \in \mathrm{Ch}(j)}(-V(c))$ or AND/OR proof/disproof number backup.
> 3. **`Algo 3a` (Ancestor-Trail CDCL Backjumping):** At a conflict leaf $b$ ($m_{\text{ql}}(C_b) \to 0$), $\mathcal{M}_{\text{anc}}[b, a]$ attends over $a \in \mathrm{Anc}^+(b)$ weighted by conflict-variable overlap $\langle q_b^{\text{conf}}, k_a^{\text{edge}} \rangle$ and depth $d(a)$ to select the asserting backjump ancestor $j^*_{\text{CDCL}} \in \mathrm{Anc}^+(b)$.
> 4. **`Algo 4` (Subtree-Normalized Counterfactual Disjunctive Bayes & Multi-Witness BP):** Layer 1 (`M_desc`) aggregates subtree witness survival $\hat{m}_{\text{sub}}(c) = \max_{k \in \mathrm{Desc}(c)} m_{\text{ql}}(C_k)$ and subtree-normalized beliefs; Layer 2 (`M_child` + `LSE_child` + `M_global`) computes multi-witness Bayes mixtures across sibling subtrees and Gershgorin-preconditioned clearing, fixing the `R12` $B=128 \to 256$ multi-witness KL regression.

*(Full proof of Theorem R4.2 as derived in Section 2.2: Layer 1 uses $\mathcal{M}_{\text{desc}} = M_{\text{tree}}^\top$ with $\beta=0$ for exact subtree mean and $w_{\text{lse}}=0$ for exact $\log |\mathrm{Desc}(j)|$; Layer 2 copies $\log N(\mathrm{pa}(j))$ via $\mathcal{M}_{\text{parent}}$, evaluates $U(j)$, and subtracts $\max_{j' \in \mathrm{Sib}(j)} U(j')$ via $\mathcal{M}_{\text{sib}, \beta_{\max}}$; Layer 3 takes $\min_{a \in \mathrm{Anc}(j) \setminus \{0\}} \mu_{\text{edge}}(a)$ via $\mathcal{M}_{\text{anc}, -\beta_{\max}}$.)* $\blacksquare$

### 2.3 Theorem R4.3: The 5 Expressivity Barriers of `GLC-Search-Transformer v1` and Their Complete Resolution in `GLC-Search-Transformer v2`

To answer Kelvin's second question (*"Are there other search algorithms that even this new GLCSearch can't represent? Check known implementations that are useful for several games and tell me"*), we systematically audit the world's strongest search algorithms across game classes:
- **Two-Player Zero-Sum Tactical Games (`Chess`, `Hex`, `Connect-4`):** Alpha-Beta Pruning (`Stockfish`), Proof-Number Search (`PNS` / `df-pn`, `Allis 1994`, `Nagai 2002` — the gold standard for Hex/Connect-4/Tsume-Shogi solvers), and Monte Carlo Graph Search (`MCGS` in `KataGo`, `Czech et al. 2021`).
- **Sample-Efficient Model-Based Planning at Small/Medium Budgets:** `Gumbel MuZero` with Sequential Halving (`Danihelka et al. 2022`).
- **Imperfect-Information / Hidden-State Strategic Games (`Proposal-Poker`, `Micro-Stratego`, `Galanis-Market`):** Counterfactual Regret Minimization (`CFR+`, `Tammelin 2014`), `DeepStack` / `ReBeL` (`Brown et al. 2020`), and Regularized Nash Dynamics (`R-NaD`, `Perolat et al. 2022` — DeepMind's Stratego engine `DeepNash`).
- **Combinatorial Deduction & SAT/CSP (`Sudoku-9x9-Extreme`, `Equiv-SAT`, `Graph-Coloring`):** Conflict-Driven Clause Learning (`CDCL`) with global clause database and watched literals (`Moskewicz et al. 2001 Chaff`, `Biere et al. Kissat/CaDiCaL`).

> **Theorem R4.3 (Five Expressivity Impossibilities of `GLC-Search-Transformer v1` and Exact Sufficiency of `GLC-Search-Transformer v2`):**
> Let `GLC-Search-Transformer v1` be any fixed-depth ($L$-layer) Transformer operating strictly over the 7 syntactic tree masks $\mathcal{M}^{(b)} = (\mathcal{M}_{\text{self}}, \mathcal{M}_{\text{parent}}, \mathcal{M}_{\text{child}}, \mathcal{M}_{\text{anc}}, \mathcal{M}_{\text{desc}}, \mathcal{M}_{\text{sib}}, \mathcal{M}_{\text{global}})$ with symmetric sibling masks and no persistent bottom-up recurrent state. Then `v1` **cannot** represent the following 5 search mechanisms, whereas **`GLC-Search-Transformer v2`** (adding 5 lightweight O(b) primitives `V2.1`–`V2.5`) represents all 5 exactly:
>
> 1. **Barrier 1 — Non-Commutative Alternating Semirings at Depth $D > L$ (`Minimax / Alpha-Beta` & `Proof-Number Search / df-pn`):**
>    - *Impossibility in `v1`:* MCTS backup is a **commutative monoid** $(\mathbb{R} \times \mathbb{N}, +)$ over $\mathrm{Desc}(j)$, so 1 layer of $\mathcal{M}_{\text{desc}}$ collapses arbitrary depth $D$ in $O(1)$ layers. In contrast, Minimax evaluation $V(j) = \max_{c_1 \in \mathrm{Ch}(j)} \min_{c_2 \in \mathrm{Ch}(c_1)} \dots$ and AND/OR Proof-Number backup $\mathrm{pn}(j) = \min_{c} \sum_{c'} \min_{c''} \dots$ alternate two **non-distributive / non-commuting operators** at every ply. By standard circuit complexity (alternating tree evaluation is $\mathsf{NC}^1$-complete and requires depth $\Omega(D)$ under polynomial fan-in threshold/softmax gates without intermediate path states), a fixed $L$-layer non-recurrent `v1` network cannot compute $D$-ply Minimax or $D$-ply Proof Numbers when $D > L$ (e.g., $D = 16, L = 3$). Furthermore, because $\mathcal{M}_{\text{sib}}$ is permutation-symmetric across siblings, `v1` cannot represent sequential left-to-right $\alpha\text{--}\beta$ pruning where sibling $c_1$'s backed-up value tighter-bounds $[\alpha, \beta]$ to prune sibling $c_2$.
>    - *Resolution in `GLC-Search v2` (`V2.1`: Incremental Ancestor-Spine Semiring Backup + Directed Older-Sibling Mask $\mathcal{M}_{\text{sib}<}$):*
>      When `append_node` adds node $b$, **only the $d(b) \le B$ ancestors $a \in \mathrm{Anc}(b)$** can change their backed-up subtree values! `v2` maintains a persistent vector `backup_state[j]` $\in \mathbb{R}^{d_{\text{bak}}}$ updated along the ancestor spine $a \in \mathrm{Anc}^+(b)$ from $d(b)-1$ down to $0$ via a learned gated semiring cell:
>      $$\mathrm{backup\_state}[a] \;\leftarrow\; \mathrm{GRU}_{\text{up}}\!\Big(z_a^{(0)}, \;\; \mathrm{Attn}_{\text{child}, +\beta_{\max}}(\mathrm{backup\_state})_a, \;\; \mathrm{Attn}_{\text{child}, -\beta_{\max}}(\mathrm{backup\_state})_a, \;\; \mathrm{LSE}_{\text{child}}(\mathrm{backup\_state})_a\Big),$$
>      and adds the **Directed Older-Sibling Prefix Mask** $\mathcal{M}_{\text{sib}<}[j, k] = \mathbf{1}[\mathrm{pa}(k) = \mathrm{pa}(j) \land k < j]$, allowing child $j$ to read the exact $\alpha\text{--}\beta$ bound $\alpha(j) = \max_{k \in \mathrm{Sib}(j), k < j} (-V(k))$ established by earlier-explored siblings!
>
> 2. **Barrier 2 — DAG Transpositions & Monte Carlo Graph Search (`KataGo MCGS` / Zobrist Transposition Tables):**
>    - *Impossibility in `v1`:* In `Hex`, `Connect-4`, `Chess`, and `Sudoku`, permuting the order of two commuting moves $( (v_1, z_1), (v_2, z_2) ) \leftrightarrow ( (v_2, z_2), (v_1, z_1) )$ creates two distinct tree nodes $j \neq k$ representing the **identical world state** $\mathrm{canon}(O_j) = \mathrm{canon}(O_k)$ (or latent state $h_{\text{state}}(C_j) = h_{\text{state}}(C_k)$). Because syntactic tree masks satisfy $\mathcal{M}_{\text{desc}}[j, m] = 0$ for all $m \in \mathrm{Desc}(k)$, `v1` fails to share subtree value backups $Q(k)$ or visit counts $N(k)$ across transposed branches, wasting up to $k!$-fold search budget.
>    - *Resolution in `GLC-Search v2` (`V2.2`: Transposition-DAG Reachability Mask $\mathcal{M}_{\text{desc}}^{\text{DAG}}$):*
>      Using `TreePagedKVBank`'s canonical state signature $\mathrm{canon}(O_j)$ (`kv_tree_search.py:317–339`) and hidden state similarity $E_{\text{trans}}[j, k] = \max\!\big(\mathbf{1}[\mathrm{canon}(O_j) = \mathrm{canon}(O_k)], \, \exp(-\|h_{\text{state}}(C_j) - h_{\text{state}}(C_k)\|_2^2 / \tau_{\text{trans}})\big)$, `v2` forms the **DAG Descendant Closure Mask**:
>      $$\mathcal{M}_{\text{desc}}^{\text{DAG}}[j, m] \;=\; \max_{k \in \{0,\dots,b\}} \big( E_{\text{trans}}[j, k] \cdot \mathcal{M}_{\text{desc}}[k, m] \big),$$
>      implementing exact Monte Carlo Graph Search (`MCGS`) backup across all transposition-equivalent subgraphs in 1 layer!
>
> 3. **Barrier 3 — Imperfect-Information Counterfactual Regret Minimization (`CFR+` / `ReBeL` / `R-NaD` on `Proposal-Poker`, `Micro-Stratego`, `Galanis-Market`):**
>    - *Impossibility in `v1`:* In hidden-information games, two nodes $C_j, C_k$ that differ in private opponent cards/pieces ($O_j \neq O_k$) may have the **identical public + acting-player observation** $\mathrm{Obs}_{\text{pl}(j)}(C_j) = \mathrm{Obs}_{\text{pl}(j)}(C_k)$ (same **Information Set** $I$). An agent that conditions on $C_j$ separately from $C_k$ commits strategy-fusion / clairvoyance error, while any deterministic $\arg\max_a Q(I, a)$ policy is exploitable in bluffing/mixed-strategy Nash equilibria (`DeepNash` / `Proposal-Poker`). `v1` has no infoset mask, no counterfactual opponent reach probability $\pi_{-i}(C_j)$, and no cumulative regret-matching head.
>    - *Resolution in `GLC-Search v2` (`V2.3`: Infoset Mask $\mathcal{M}_{\text{infoset}}$ + Ancestor Log-Reach + Regret-Matching Head):**
>      `v2` adds (i) the **Infoset Equivalence Mask** $\mathcal{M}_{\text{infoset}}[j, k] = \mathbf{1}[\mathrm{Obs}_{\text{pl}}(C_j) = \mathrm{Obs}_{\text{pl}}(C_k)]$, (ii) **Counterfactual Log-Reach Accumulation** $\log \pi_{-i}(j) = \sum_{a \in \mathrm{Anc}(j) \setminus \{0\}} \mathbf{1}[\mathrm{pl}(\mathrm{pa}(a)) \neq i] \log \sigma(a \mid \mathrm{pa}(a))$ via $\mathcal{M}_{\text{anc}}$ sum-pooling, computing exact infoset counterfactual values $v_{\text{CF}}(I, a) = \frac{\sum_{j \in I} \pi_{-i}(j) Q(j, a)}{\sum_{j \in I} \pi_{-i}(j)}$ and instantaneous regrets $r(I, a) = v_{\text{CF}}(I, a) - \sum_{a'} \sigma(I, a') v_{\text{CF}}(I, a')$, and (iii) a **Regret-Matching / R-NaD Policy Readout** $\sigma(I, a) = \frac{\mathrm{ReLU}(R_+(I, a)) + \epsilon}{\sum_{a'} (\mathrm{ReLU}(R_+(I, a')) + \epsilon)}$!
>
> 4. **Barrier 4 — Gumbel MuZero & Sequential Halving (`SH`) Rank Elimination (`Danihelka et al., 2022`):**
>    - *Impossibility in `v1`:* At small budgets $B \in \{2, 4, 8, 16\}$, Gumbel MuZero outperforms PUCT by running **Sequential Halving (`SH`)**, which divides budget $B$ into $\lceil \log_2 m \rceil$ phases and at each phase retains only the **top-$50\%$ of siblings by score rank** ($\mathrm{rank}_{\text{sib}}(j) \le \lceil m / 2^p \rceil$). A single softmax or uniform-mean sibling head $\mathcal{M}_{\text{sib}}$ cannot compute hard median/quantile rank thresholds because softmax weights depend on score *magnitudes* rather than *ordinal rank*.
>    - *Resolution in `GLC-Search v2` (`V2.4`: Pairwise Sibling Rank-Percentile Head $\widehat{\mathrm{pct}}_{\text{sib}}$):*
>      For every node $j$, `v2` computes via $\mathcal{M}_{\text{sib}}$ the pairwise comparison fraction:
>      $$\widehat{\mathrm{pct}}_{\text{sib}}(j) \;=\; \frac{1}{|\mathrm{Sib}(j)|} \sum_{s \in \mathrm{Sib}(j)} \sigma\!\Big(\frac{S_{\text{Gumbel}}(j) - S_{\text{Gumbel}}(s)}{\tau_{\text{rank}}}\Big) \;\in\; [0, 1],$$
>      where $S_{\text{Gumbel}}(j) = g_j + \ell_{\text{prior}}(j) + c_{\sigma} \hat{Q}(j)$. For $\tau_{\text{rank}} \ll \Delta_{\text{gap}}$, $\widehat{\mathrm{pct}}_{\text{sib}}(j) = 1 - \frac{\mathrm{rank}_{\text{sib}}(j)-1}{|\mathrm{Sib}(j)|}$ is the exact sibling rank percentile, and thresholding $\widehat{\mathrm{pct}}_{\text{sib}}(j) \ge 1 - 2^{-p}$ executes **exact Sequential Halving** in 1 layer!
>
> 5. **Barrier 5 — Global Conflict-Clause / Nogood Broadcast Across Disjoint Subtrees (`CDCL` Watched Literals in `Kissat` / `CaDiCaL`):**
>    - *Impossibility in `v1`:* In `v1`, `Algo 3a` uses $\mathcal{M}_{\text{anc}}[b, a]$ to backjump from conflict leaf $b$ to an ancestor $a \in \mathrm{Anc}^+(b)$. However, when the solver later explores a **disjoint branch** $j \notin \mathrm{Anc}(b)$, $\mathcal{M}_{\text{anc}}[j, b] = 0$ and $\mathcal{M}_{\text{desc}}[j, b] = 0$, so `v1` cannot propagate the learned conflict clause (nogood) from $b$ to prune matching illegal assignments in $j$'s subtree!
>    - *Resolution in `GLC-Search v2` (`V2.5`: Global Conflict/Nogood Cross-Attention Head $\mathcal{M}_{\text{nogood}}$):*
>      `v2` adds $\mathcal{M}_{\text{nogood}}[j, k] = \mathbf{1}[m_{\text{ql}}(C_k) < \tau_{\text{clash}}]$, allowing every open candidate node $j \in \{0, \dots, b\}$ to attend globally over all refuted conflict nodes $k$ discovered anywhere in the search tree, projecting out forbidden variable-value assignments $(v_k, z_k)$ before expansion! $\blacksquare$
