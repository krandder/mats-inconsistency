## 2. Leakage in pretraining: no Y or dev leak; training-time key use must be labelled
- **Target.** `x[idx][:, :p]` (pl:369) is the held-out agent's own noisy readings: tokens are [readings, keys] (pl:69). No Y, no latent bits. Predicting them uses only cross-agent reading correlations, which are observations.
  - Caveat: this signal is a latent-structure (omega) signal, not task-free noise. Call it "self-supervised on observations", not "nothing extra".
- **Blind arm.** The query is qproj(the held-out agent's full key: var one-hot + accuracy) (pl:235). The other agents' keys are not fed (pl:234, dec_keys=False).
  - The encoder already sees its own key in every arm (pl:69), and agent j owns its key. So this is not a test-time leak: the Y-phase decode has no key path (pl:215).
  - It is training-time use of key/structure information, which sharpens the encoder's identity code. Label it "blind at inference; keys used as pretraining queries", not plain "blind".
- **Warm-up mismatch.** In keys arms, decode_masked concatenates keys regardless of use_keys (pl:233-234). The 1000-step key warm-up therefore applies only in the Y phase, while the record says key_warmup=1000.
- **Dev.** Val/dev/stats use separate seeds (pl:36); pretraining uses select=False. No dev episode enters training.

## 3. Fixed-power channel: scored messages are 1 bit/dim per sample; training is pooled
- **Eval.** logits() calls net.eval() (pl:296), so BatchNorm uses running stats. "quant" = sign(u - running_mean) (pl:189-194): a fixed per-dim threshold, per sample, exactly b bits.
- **Training.** BatchNorm uses statistics over all 512x13 messages in the batch, across agents and episodes. The cross-episode dependence is O(1/6656), so negligible information.
  - But E[s^2]=1 holds only on average over agents. A single agent can exceed power 1, so "1 bit/dim capacity" is pooled, not per agent. The scored sign messages are unaffected.
- **Bug (small).** symbols() (pl:397) runs after logits() has called net.train(). So symbol entropy uses dev-batch BatchNorm stats and updates the running stats with dev data before regret_noisy. The effect is negligible: it decays over the 1000 fine-tune steps, and the main "regret" is computed before this point. Wrap symbols() in eval().
