# ForecastWorld: forecasts plus source keys, aggregated by attention (2026-10-22)

Stage 2 of the Deger plan without LLMs: forecasters output calibrated forecasts on all 20 questions plus a key describing which news-like sources they read; an aggregator combines them. Everything has an exact Bayes ceiling. Environment and ceilings: `aggbench/forecast_world.py` (docstring). Runner: `scripts/forecast_world_run.py`. This README is generated by `scripts/render_forecast_world.py` from `cells/*.json`; plot data is `figure-data.json`.

Metric: mean per-question KL from (A) full-info Bayes (nats; its expectation is the log-loss excess over A). Learned arms: mean ± sd over 3 training seeds, best-val checkpoint on a dev split, fresh episodes every step, test on 4096 test-split episodes. Held-out: forecasters may also read 10 sources never seen in training.
