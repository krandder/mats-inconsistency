# Joint-Learning Remedies with `FSQ` on Leak-Reduced `Z9-p2` (`b481850`) and `E2` at `b in {2, 4, 6}` (`#3893`, `#3894` & `#3896`)

**Track: `EXPLORATORY` (`gate must-fixes applied per #3894 & #3896`)**

Tests remedies for the joint encoder-decoder chicken-and-egg problem at `b in {2, 4, 6}` bits/agent (`2^b in {4, 16, 64}` symbols, `3` seeds `0, 1, 2`) with `FSQ` (`2309.15505`) as the quantizer, `key_scale = 0.1` (`in_norm=False`), and `key_warmup = 1000` steps (`best_val_kl` restricted to `t >= key_warmup`) whenever an arm takes keys (`dec_keys = True`):
- `0_fsq_joint`: Plain joint end-to-end training with `FSQ` (`usage_w = 0.0`, `Y labels only`).
- `a_fsq_alt_opt`: `(a)` Alternating optimization (`k_alt` steps decoder with encoder frozen, `k_alt` steps encoder with decoder frozen; `usage_w = 0.0`, `Y labels only`).
- `b_fsq_dec_warmstart`: `(b)` Decoder warm-start on a random fixed full-entropy `FSQ` code (first 30% of steps with encoder frozen), then joint end-to-end training (`usage_w = 0.0`, `Y labels only`).
- `c_fsq_entropy_bonus`: `(c)` Encoder marginal symbol-entropy / usage bonus (`L_usage`, `usage_w = 0.10` on `Z9-p2-lf`, `0.08` on `E2`, `Y labels only`).
- `d_fsq_staged_channel`: `(d)` Staged continuous-to-discrete channel (`tanh(u)` float message first, cosine-annealed quantization `alpha(t): 0 -> 1` to `b`-bit `FSQ`, then pure discrete `b`-bit `FSQ` + discrete decoder lock-in; `usage_w = 0.0`, `Y labels only`).
- `e_fsq_biased_curr_plus_best`: `(e)` Biased-bit curriculum on `Z9-p2-lf` (**`structure-informed (simulator-side: sets latent-bit priors to 0.8 -> 0.65 -> 0.5 and uses k in prior_logit)`**, **not** `Y labels only`) or high-to-normal piece-SNR curriculum on `E2`, combined with the best of `(a)-(d)` (`dec_keys = True`, `STRUCTURE-KNOWN (decoder reads keys['full'] outside b)` on `Z9-p2-lf`, `key_scale = 0.1`, `key_warmup = 1000`).
- `e_fsq_biased_curr_plus_best_keys0`: `(e)` on `Z9-p2-lf` with `dec_keys = False` (**`BLIND DECODER (messages only; curriculum still simulator-side structure-informed)`**), compared directly against the blind 4-bit searched reference (`0.2160`) and the blind `5.49`-bit `bit_id+reading` reference (`0.0060`).

### Scope & Interpretation Notes (`#3896` Must-Fixes 1–5)
- **Structure-Known vs. Blind Decoder (`#3896` Must-Fixes 1 & 2):** On `Z9-p2-lf`, every keyed arm (`dec_keys = True`) is **`STRUCTURE-KNOWN (decoder reads keys['full'] outside b)`**: the `14`-float per-agent bit-identity and accuracy key `keys['full']` is passed directly to the decoder outside the `b`-bit channel (`FSQJointRemedyNet.decode`: `h_in = torch.cat([m, kk], dim=-1)`), so the `b`-bit bottleneck only compresses the agent's `2` binary readings. At `b = 2`, those `2` binary readings fit **losslessly** into `2` bits (the `4` reading pairs `(0,0),(0,1),(1,0),(1,1)`), so `0.0085` at `b = 2` (`+0.0018` vs plain 8k Transformer `0.0068`, `+0.0065` vs 8k ISAB `0.0020`) **only shows that `FSQ` learns the 2-bit identity map and tests nothing about compression**.
- **Blind Decoder Headline (`#3896` Must-Fix 2):** On `Z9-p2-lf`, the blind arm (`e_fsq_biased_curr_plus_best_keys0`, `BLIND DECODER (messages only; curriculum still simulator-side structure-informed)`) reaches `0.2601` at `b = 2` (`0/3` escaped), `0.2188` at `b = 4` (tying the searched 4-bit blind code `0.2160`), and `0.0813` at `b = 6` (**`+0.0793` behind 8k ISAB `0.0020` and `+0.0745` behind plain 8k Transformer `0.0068`**, whereas the blind hand code `bit_id+reading` reaches `0.0060` at `5.49` bits — so **Kelvin's blind challenge is not met**).
- **Spec & Channel Comparison Note (`#3896` Must-Fix 5):** The `0/3` escape result for `(iii)` in `tt-compression-decoupling-20261022` ran on the **old `Z9-p2` spec (`prior = 0.4567`, deterministic `2` readers/bit + `6` distractors = `7` agents)** with **Gaussian / Gumbel channels**, whereas this table runs on **leak-reduced `Z9-p2-lf` (`prior = 0.2702`, `Dirichlet` random assignment = `13` agents)** with **`FSQ`**. Comparing them does **not** isolate "FSQ fixes joint learning" because the spec and channel are confounded.
