# li-criterion-finite: a finite, enumeration-free logical induction criterion

Key: `li-criterion-finite`. Script: `math/li-criterion-finite/check.py`, output: `math/li-criterion-finite/output.txt` (run 2026-10-02, numpy+scipy, ~60 s).

## TL;DR
- MarketMaker's fixed point protects against **one** (aggregate) trader, in **every** valuation of the cube, not only consistent worlds. Nothing in it is per-trader. TradingFirm adds per-trader guarantees, and those exist only **over time** (budgets + weights + summed losses).
- A "common fixed point of every T in C" implies that no T gains in any world (trivial theorem), but it usually **does not exist** (two traders: T1 = 0.3-p, T2 = 0.7-p). Even a randomized market cannot defend each (trader, world) pair (LP infeasible; certificate value 0.10). The finite criterion that is always achievable is **aggregate safety**: a zero residual of `clip(p + Σ w_k T_k(p)) - p`. It needs **no world enumeration**, because `gain ≤ (1+‖x‖∞)·‖residual‖₁` over the whole cube (checked).
- **Static collapse (theorem):** with everything given at block 0 (D_t ≡ Γ, finite), a constant market p is inexploitable by *every* trader (history-dependent, uncomputable, any class) iff p ∈ relint conv PC(Γ). So the LI criterion at a fixed point says only "coherent and non-dogmatic". The rest (timeliness, frequencies, convergence) lives in the transient, in the training distribution, or in self-reference.
- **Convergence cannot come from history-free traders (refuted):** no class of memoryless traders, however large, rules out oscillation between two coherent points with growing run lengths. If the prices are the whole state (p_{t+1} = Φ(p_t)), one self-forecasting trader T = Φ(p) - p forces Σ|Δp|² < ∞, and with isolated fixed points that gives convergence.
- Gradient traders: the aggregate fixed point is the minimiser of the summed convex loss. It is Richardson's PDG inconsistency only if (i) the axiom traders are hard (infinite weight / projection; finite-weight relu² penalties land outside K_Γ) and (ii) the claim traders are c_k(logit q_k - logit p_k), the gradient of KL(p‖q); the file's earlier (q-p)/(p(1-p)) is KL(q‖p), a different minimiser. **[skeptic: corrected]**

## Setting
Finite sentence set S (|S| = n), propositional theory Γ, worlds PC(Γ) ⊆ {0,1}^S (propositionally consistent with Γ), coherent polytope K_Γ := conv PC(Γ). Prices p ∈ [0,1]^S.
A **memoryless trader** is a continuous T: [0,1]^S → R^S (shares per sentence; cash = -T(p)·p, so the trade has value 0 at the prices). It may depend on fixed sentence structure, but not on history. The value of trade x at prices p in world W is x·(W - p).
Weak Dutch book at p: x with x·(W-p) ≥ 0 for all W ∈ PC(Γ) and > 0 for some W. Strict: > 0 for all W.

## (1) What MarketMaker and TradingFirm give (full.txt 5.1-5.3)
**Known [GBCST16, Lemma 5.1.1, https://arxiv.org/abs/1609.03543].** For one n-strategy T_n and history P_{≤n-1}, Brouwer gives V with V = clip(V + T_n(V)). Then T_n[φ] > 0 ⇒ V(φ) = 1, and T_n[φ] < 0 ⇒ V(φ) = 0, so W(T_n(V)) ≤ 0 for **all W** (any 0/1 assignment, and indeed any W ∈ [0,1]^S). Restated: V solves the variational inequality T(V)·(q - V) ≤ 0 for all q in the cube, i.e. T(V) lies in the normal cone of the cube at V. The fixed-point set is the same for clip(V + ηT(V)) for every η > 0, so a network may damp its steps.
Proposition 5.1.2 approximates this to 2^-n by search, and Lemma 5.1.3 sums 2^-n over days, so one trader's total gain stays < 1.
**What TradingFirm adds:** (a) **enumeration**: every e.c. trader appears as some T^k, entering on day k. (b) The **Budgeter** scales T^k down by a factor ≤ 1 (and zeroes it after a breach, eq. 5.2.1) so that its value never drops below -b in any W ∈ PC(D_n), and leaves it unchanged if it never would have. (c) The firm is the weighted sum Σ 2^{-k-b} B^{b,k}. Because each budgeted component is bounded below, a bounded firm forces each component to be bounded above. This is the only place where per-trader guarantees appear, and it needs **many days**. On one day only the aggregate is protected.

## (2) Inductor over a finite class C
**Def A (common fixed point).** p is a common fixed point if p = clip(p + T(p)) for every T ∈ C.
**Theorem 1 (trivial, proven).** At a common fixed point, T(p)·(W - p) ≤ 0 for all T ∈ C and all W ∈ [0,1]^S. Proof: Lemma 5.1.1, coordinate by coordinate, for each T separately. ∎
**Refuted: existence.** C = {T1 = 0.3 - p, T2 = 0.7 - p} on one sentence with PC = {0,1} has no common fixed point (the fixed points are {0.3} and {0.7}). Over all p, the deterministic min_p max_{k,W} gain is 0.100. **Randomizing does not help:** the LP "find π with E_π[T_k(p)(W-p)] ≤ 0 for every (k, W)" is infeasible. Certificate: λ = ½(T1, W=0) + ½(T2, W=1) gives g(p) = p² - p + 0.35 ≥ 0.10. ~~The tempting minimax argument fails because "for all T and all W" is a max over pairs (k, W), which is bilinear in (θ, ν), not concave.~~ **[skeptic: wrong explanation, corrected]** Minimax does hold (the game between π over p and λ over pairs (k, W) is bilinear on compact simplices, von Neumann); the certificate λ is exactly the LP dual (skeptic S7: max_λ min_p = min_π max = 0.100). What fails is the step after minimax: for fixed λ, Σ λ_{k,W} T_k(p)·(W - p) is not of the form T'(p)·(W' - p) for one world W', because each trader is paired with a different world, so Lemma 5.1.1 gives no p with value ≤ 0.
**Def B (aggregate safety, the finite criterion).** Given weights w > 0, let T_w = Σ w_k T_k. p is (C, w)-safe if p = clip(p + T_w(p)).
**Theorem 2 (proven; existence by Brouwer).** A (C, w)-safe p always exists, and Σ_k w_k T_k(p)·(W - p) ≤ 0 for all W ∈ [0,1]^S. Per-trader gains are not bounded: at p = 0.5 in the example above, the firm gains 0 while T1 gains +0.10 in W=0 and T2 gains +0.10 in W=1 (checked).
**Theorem 3 (proven; enumeration-free).** For x = T_w(p) and r = clip(p + x) - p:
max_{W ∈ [0,1]^S} x·(W - p) ≤ (1 + ‖x‖∞)·‖r‖₁.
Proof per coordinate: the max gain is |x_i|·d_i, where d_i is the room in the direction of x_i, and |r_i| = min(|x_i|, d_i). If |x_i| ≤ d_i, the gain is |x_i|·d_i ≤ |r_i| (since d_i ≤ 1). Otherwise the gain is |x_i||r_i|. ∎ **[skeptic: holds; sharper constant max(1, ‖x‖∞) also holds (S6). Caveat: r must be the undamped residual (η = 1); a damped residual clip(p + ηx) - p is η times smaller, so divide by η.]** So a block can be trained or monitored on the fixed-point residual alone, with no enumeration of worlds. Coherence comes from which traders are in C, not from the residual.
**Theorem 4 (when common fixed points exist; gradient traders; standard convex VI).** Let T_k = -∇F_k with each F_k convex and C¹ on the cube. The fixed points of clip(p + T_w(p)) are exactly the minimisers of F_w = Σ w_k F_k over the cube (first-order optimality of a convex function on a convex set). If the F_k ≥ 0 have a common zero, these minimisers are the common zeros, and those are common fixed points ~~(each T_k = 0 there)~~ **[skeptic: gap fixed]** (because each common zero minimises each F_k over the cube; T_k need not vanish there if the zero is on the boundary and F_k is only defined on the cube, e.g. F = p on [0,1], S2). Example: relation traders T_j = -relu(a_j·p - b_j)·a_j, with F = ½Σ relu(a_j·p - b_j)². If the a_j·W ≤ b_j are all facets of K_Γ **and the equalities of its affine hull are included as two-sided traders** (K_Γ is usually not full-dimensional; in the toy it is 2-dimensional in R^5), the fixed-point set is exactly K_Γ. **[skeptic: condition added]**

**Theorem 5 (proven; Nash and game view).** p solves VI(T_w, cube) iff each "price-setter" φ best-responds to the linear payoff p_φ·T_w,φ(p*) held fixed: p_φ = 1 if T > 0, 0 if T < 0, anything if T = 0. So p is a Nash equilibrium of that pseudo-game [Facchinei-Pang 2003, VI ⇔ NE (unverified)]. Zero-sum view: market p vs nature W with payoff T_w(p)·(W - p). Brouwer gives inf_p max_W ≤ 0 for each fixed T_w, but not uniformly over the traders (counterexample above).
**Known (defensive forecasting).** Vovk, Takemura and Shafer, "Defensive forecasting" (https://arxiv.org/abs/cs/0505083): for any continuous gambling strategy there is a forecasting strategy that does not lose to it. Vovk et al., "Defensive forecasting for linear protocols" (https://arxiv.org/abs/cs/0506007): in linear protocols, for any continuous Skeptic there is a Forecaster that keeps Skeptic's capital from growing. This is their "meta-theorem": every continuous law can be enforced. Perdomo and Recht, "In Defense of Defensive Forecasting" (https://arxiv.org/abs/2506.11848), is a tutorial with algorithms for calibration and experts. Lemma 5.1.1 is the multi-sentence defensive-forecasting step. TradingFirm is their "mix the tests and defend the mixture" step, with Budgeter supplying the nonnegative capital that makes mixture-boundedness imply component-boundedness.

## Static collapse and the role of time

(b) If p ∉ relint K_Γ, a constant trader exploits it.
Proof (a): p = E_μ W with μ(W) > 0 for every W ∈ PC(Γ), so every trade sequence has E_μ[value_t] = 0. If the value is ≥ -b everywhere, then μ(W)·V_t(W) ≤ (1 - μ(W))·b, so V_t(W) ≤ b(1-μ_min)/μ_min, which is bounded.
**[skeptic: holds; (a) and (b) both rechecked. Scope: sentences whose truth does not depend on the prices. ## (4) No resolutions during the blocks (everything at block 0)
- Statements about the fixed point alone: coherence, affine coherence, provability induction (as p*(φ) = 1 for theorems), and non-dogmatism (relint; Thm 6).
- Paradox resistance becomes a fixed-point statement **if** sentences may refer to the network's own prices. It is aggregate-only.
- Convergence is about the trajectory (Thms 7-8), not the fixed point.
- Timeliness (provability induction or affine coherence along the diagonal before the derivation is done) is a property of the iterate at block t relative to C_t = traders computable in ≤ t blocks. This is the only place the LI "day" index survives: day n ↔ block t, e.c. ↔ block-bounded.
- Pseudorandom frequencies cannot be defined from one run without feedback. It needs the problem distribution (end-of-run labels), and becomes multicalibration.

## What it implies for the network
1. Make the block's per-step objective the **fixed-point residual of an aggregate trader** (Thm 3): r(p) = clip(p + Σ w_k T_k(p)) - p. It is enumeration-free, and r = 0 certifies no aggregate gain in any world. With gradient traders (Thm 4), the block is projected gradient descent on a convex PDG-style inconsistency, which converges (iterates to a minimiser) **provided ∇F is L-Lipschitz and the step is < 2/L** **[skeptic: condition added; logit/KL traders have unbounded L near 0 and 1]**. ~~Kelvin's ban on history then costs nothing~~ **[skeptic: overstated]** Convergence then comes from the Lyapunov function, not from traders; per-trader guarantees, timeliness and frequencies are still not provided.
2. Coherence needs facet-level (global) traders, not just local inference-rule traders. ~~Local ones give the LP "local polytope" (check 1: 50% incoherent).~~ **[skeptic: corrected]** Check 1's 50% came from an incomplete local set; a complete local set is coherent on the toy (S1). For larger theories the local polytope is a strict outer approximation (unverified citation above), so global traders are still needed in general. Budget for this: projecting onto K_Γ is NP-hard in general, so the network approximates it, and the gap is exactly where logical uncertainty lives.
3. Do not ask the fixed point for per-trader guarantees, frequency learning or timeliness. Those come from (a) the iterate at block t relative to block-bounded traders and (b) multicalibration from the end-of-run loss over the problem distribution.
4. ~~Self-reference ("my final price of χ is < p0") is handled by continuity alone. The fixed point lands at p0 as long as the network's update is continuous in its own prices.~~ **[skeptic: overstated]** Continuity gives a fixed point, not p0: the file's own Check 6 shows any other trader of weight w on χ moves it to p0 - w. The fixed point is p0 only if the aggregate trader on χ is the ramp trader alone (or is zero exactly at p0).

## Ideas
- Train with the end loss **plus** an auxiliary residual loss ‖clip(p_t + T_θ(p_t)) - p_t‖₁ at each block, using a fixed library of relation traders (facets of K_Γ for small Γ, computed by LP).
- Parametrise the block as p ← Π(p - η∇F_θ(p)) with F_θ convex (input-convex network) in p. Theorems 4 and 8 then guarantee convergence (with step < 2/L) to an interpretable fixed point; ~~unique~~ uniqueness needs **strict** convexity (S8: relu² facet loss has a continuum of fixed points). **[skeptic: corrected]**
- Test probe: at 100 or 500 blocks, measure the residual for held-out traders (e.g. random facet traders) to get a "generalisation of inexploitability" curve.
- Add the self-forecasting trader T_Φ as a diagnostic: the cumulative quadratic variation Σ|Δp_t|² tracks convergence.

## Open
- Does a finite class of block-bounded memoryless traders give a quantitative timeliness bound (provability induction at block t with an explicit ε_t)? Conjecture: yes, with ε_t ≈ residual_t·(1 + ‖T‖), for theorems whose recogniser lies in C_t.
- Is there a per-trader guarantee without history, e.g. Hedge-style weights that are a function of the current prices only? Conjecture: no in general (Thm 7 style constructions).
- What is the best tractable outer approximation of K_Γ (Sherali-Adams or Lasserre levels) for the trader library, and how does the level relate to the number of blocks?
