# PDG inconsistency for propositional belief states (key: pdg-propositional)

Script: `math/pdg-propositional/check.py`, output: `math/pdg-propositional/output.txt` (numpy/scipy, K = 2..6, exhaustive enumeration as ground truth).

## Setting

- Atoms a_1..a_K, worlds Ω = {0,1}^K. Axioms Γ = clauses C_1..C_r. Mod Γ = {w ∈ Ω : w ⊨ Γ}, n = |Mod Γ|.
- Query sentences φ_1..φ_m with price table p_j = P(φ_j) ∈ [0,1] and confidences β_j > 0.
- Model vectors v_w = (φ_1(w),…,φ_m(w)) ∈ {0,1}^m. Coherent polytope (marginal polytope, Nilsson's "probabilistic logic" polytope) Q = conv{v_w : w ∈ Mod Γ} ⊂ [0,1]^m.
- PDG M: one variable per atom; for each sentence (and clause) a binary variable Φ_j with a deterministic edge atoms → Φ_j (the truth function, β = ∞); an unconditional edge on each clause variable with cpd δ_true and β = ∞; an unconditional edge on each Φ_j with cpd Bern(p_j) and confidence β_j.
- Binary KL: d(q‖p) = q log(q/p) + (1−q) log((1−q)/(1−p)). logit z = log(z/(1−z)).
- Inc_M(µ) = Σ_L β_L E_{x∼µ(X_L)} KL(µ(Y_L|x) ‖ p_L(Y_L|x)) (Richardson 2022, eq. (1), local 2202.txt l.200; https://arxiv.org/abs/2202.11862), ⟨⟨M⟩⟩ = inf_µ Inc_M(µ). Convention ∞·0 = 0.

## Results

**R1 (theorem): explicit form; a convex program.** Inc_M(µ) = Σ_j β_j d(µ(φ_j)‖p_j) if µ is supported on Mod Γ (and the deterministic Φ-variables equal the truth values), +∞ otherwise. Hence

  ⟨⟨M⟩⟩ = min_{µ ∈ Δ(Mod Γ)} Σ_j β_j d((V^Tµ)_j ‖ p_j) = min_{q ∈ Q} f(q),  f(q) := Σ_j β_j d(q_j‖p_j).

Proof: an edge with β = ∞ contributes 0 iff its KL is 0, else ∞. The deterministic edges force Φ_j = φ_j(atoms) µ-a.s.; the clause edges force µ(C_i) = 1, i.e. supp µ ⊆ Mod Γ. The edge on Φ_j has source the unit variable, so its term is β_j KL(µ(Φ_j)‖Bern(p_j)) = β_j d(µ(φ_j)‖p_j). µ ↦ V^Tµ maps Δ(Mod Γ) onto Q. The objective is convex in µ (convex function of a linear map); min is attained (compact domain, lower semicontinuity). ⟨⟨M⟩⟩ = ∞ iff Γ is unsatisfiable or the hard prices (p_j ∈ {0,1}) are jointly incompatible with Q, i.e. Q ∩ {q : q_j = p_j for every hard j} = ∅. [Skeptic correction: the original said "a hard price is incompatible"; hard prices can each be attainable and jointly not, e.g. axiom ¬(A∧B), P(A) = P(B) = 1; skeptic S3.] Conditional prices P(ψ|χ) = c as an edge χ → ψ give the perspective term β µ(χ) d(µ(ψ|χ)‖c), still jointly convex in µ (extension, same proof).
Check: primal (exponentiated gradient + SLSQP over µ) on 15 random instances, K = 4,5,6, n = 8..56 models.

**R2 (theorem): uniqueness and form of the projection.** (a) If every β_j > 0 and ⟨⟨M⟩⟩ < ∞, q* = argmin_Q f is unique (d(·‖p) is strictly convex on its domain: d'' = 1/q + 1/(1−q)). If some β_j = 0, q*_j can be non-unique. (b) µ* is generally NOT unique (fibres {µ : V^Tµ = q*} have dimension up to n−1−rank). The PDG's γ → 0 semantics (Richardson–Halpern 2021, local pdg2021.txt l.1183-1231; https://arxiv.org/abs/2012.10800) selects one: here IDef(µ) = −H(µ) + Σ_j α_j H_µ(Φ_j) (deterministic edges have H(Φ|atoms)=0), and the α-terms are constant on the argmin set, so µ* = the maximum-entropy distribution on Mod Γ with marginals q*; inside relint Q it is Gibbs, µ*(w) ∝ exp(θ·v_w)·1[w ⊨ Γ]. Proof: limit points µ̄ of µ_γ satisfy f(µ̄) = ⟨⟨M⟩⟩ and IDef(µ̄) ≤ IDef(µ) for every minimiser µ (compare f+γIDef at µ_γ and µ); −H is strictly convex, so the minimiser is unique. (c) KKT / logit form: when q* ∈ (0,1)^m, set x* := β ∘ (logit q* − logit p). Then x*·v_w is minimal over Mod Γ on a set that contains supp µ* (q* lies on the face of Q minimising x*). [Skeptic correction: the original said "exactly on supp µ*"; that needs strict complementarity and is refuted in general. Counterexample S1: sentences A, B, A∧B, β = 1, p = σ(−1, 0, 1) = (0.269, 0.5, 0.731): q* = (½, ½, ½), µ* = ½δ_00 + ½δ_11 (the fibre is a single point), x* = (1, 0, −1), and x*·v_w = 0 on the three worlds 00, 01, 11. World 01 minimises but has µ* = 0. The maxent µ* is supported on the models in the minimal face of Q containing q*, which can be strictly smaller than the x*-minimising face.] Also (skeptic S2, theorem): with all p_j ∈ (0,1), q*_j ∈ {0,1} iff Γ decides φ_j (moving off the boundary toward any model lowers f with directional derivative −∞), so the boundary case in the check below is an entailed sentence, not one "forced by other prices". So, when no sentence is decided by Γ, the projected table is logit q*_j = logit p_j + x*_j/β_j: "move each price in logit space in proportion to the optimal arbitrage position divided by the confidence". If Γ ⊨ φ_j then q*_j = 1 whatever p_j > 0 (correct values on entailed sentences, in one projection). (d) Unpriced sentences ψ: coherence only fixes µ(ψ) to the LP interval [min, max]{µ(ψ) : V^Tµ = q*}; the maxent µ* picks one point; with no prices at all µ* is uniform on Mod Γ (model frequency).
(e) Pythagoras (Csiszár 1975 I-projection, unverified recollection; it is the Bregman Pythagorean inequality for the separable Bernoulli negentropy): for every q ∈ Q, f(q) ≥ ⟨⟨M⟩⟩ + Σ_j β_j d(q_j‖q*_j).
Checks: q* from two random starts agree to 5.5e-9; x* = β(logit q* − logit p) matches the dual optimum to 3.5e-7 (relative) on interior coordinates, and diverges where q*_j ∈ {0,1} (one instance had q*_j = 1 because Γ ⊨ φ_j (skeptic S2 replayed the instance; the script's printed comment "forced by axioms+other prices" is wrong), dual x_j → ∞: dual sup not attained there); γ → 0 minimisers of Inc − γH converge to the maxent µ* (‖µ_γ − µ*‖_1 = 6e-3, 6e-4 at γ = 1e-2, 1e-3; three seeds); entropic mirror descent from uniform landed on the maxent µ* (its iterates are always Gibbs); Pythagoras (e) holds on 1200 random coherent q (min slack −1.6e-8, solver error); ψ = a1∧a4 example: coherent interval [0, 0.515], maxent 0.239.

**R3 (theorem): ⟨⟨M⟩⟩ = 0 iff the table is coherent.** ⟨⟨M⟩⟩ = 0 ⟺ p ∈ Q ⟺ there is a probability measure on models of Γ that reproduces every price ⟺ no affine combination A = c + Σ y_j φ_j has P(A) outside [min_{w⊨Γ} W(A), max_{w⊨Γ} W(A)] (one-day, finite form of Affine Coherence, Thm 4.2.10 abridged / 4.5.5 full; local full.txt l.1781) ⟺ no portfolio y has guaranteed gain G(y) := min_{w⊨Γ} Σ y_j (φ_j(w) − p_j) > 0 (de Finetti / separating hyperplane). Proof: d(q‖p) = 0 iff q = p, and the last two equivalences are Farkas. Check: 30/30 random tables (half built coherent, half random) agree with an LP feasibility test.

**R4 (theorem): exact arbitrage meaning (LMSR duality).**
 ⟨⟨M⟩⟩ = sup_{x ∈ R^m} min_{w ⊨ Γ} Σ_j [ x_j φ_j(w) − β_j log(1 − p_j + p_j e^{x_j/β_j}) ]
     = max_{q} min_{w⊨Γ} [ LL_β(p, w) − LL_β(q, w) ],  LL_β(p,w) := −Σ_j β_j log p_j^{φ_j(w)} (1−p_j)^{1−φ_j(w)},
with optimum q = q*, x = x*. The summand is the profit of buying x_j YES shares of φ_j in a binary logarithmic market scoring rule (Hanson's LMSR) market with liquidity β_j that starts at price p_j and ignores the axioms. So **⟨⟨M⟩⟩ is exactly the largest risk-free profit one trader can take, in one shot, from independent per-sentence LMSR market makers quoting the table**, and that trader's best move pushes the prices to the projected table q*. Every model w of Γ then gives LL(p,w) − LL(q*,w) ≥ ⟨⟨M⟩⟩, with equality on supp µ*: the projected table beats the raw one in log score in every world, by at least ⟨⟨M⟩⟩ (dominance, cf. Predd et al. 2009 "Probabilistic coherence and proper scoring rules", IEEE Trans. IT, unverified recollection).
Proof: Fenchel duality, min_Q f = sup_x [min_{v∈Q} x·v − f*(x)], with f*(x) = Σ β_j log(1 − p_j + p_j e^{x_j/β_j}); the second form is Sion's minimax (linear in v ∈ Q, concave in q) plus sup_q [d(v‖p) − d(v‖q)] = d(v‖p); the two forms coincide because with e^{x/β} = q(1−p)/((1−q)p) the LMSR profit equals β[d(v‖p) − d(v‖q)] for v ∈ {0,1}.
Check: the dual SLSQP value matches the primal to 1.4e-8 on all 15 instances; dominance min_w gain − ⟨⟨M⟩⟩ ≥ −1.5e-7 everywhere and = 0 (1.5e-7) on the support.

**R5 (theorem, plus refuted claims): bounds on fixed-price (relation-trader) arbitrage.** Write the LMSR profit as G(x) − Σ β_j ψ_{p_j}(x_j/β_j), ψ_p(t) = log(1−p+pe^t) − pt ∈ [0, t²/8] (Hoeffding's lemma). Hence for every portfolio y bought at the table prices:
  G(y) ≤ sqrt( ⟨⟨M⟩⟩ · Σ_j y_j²/β_j / 2 ),  equivalently  min_{q∈Q} Σ β_j (q_j − p_j)² ≤ ⟨⟨M⟩⟩/2  (Pinsker per coordinate),
and in the other direction ⟨⟨M⟩⟩ ≤ min_{q∈Q} Σ β_j (q_j − p_j)²/(p_j(1−p_j)) (χ² bound). So ⟨⟨M⟩⟩ ≍ (weighted Euclidean distance from p to Q)² when prices are away from 0 and 1.
- Refuted: "⟨⟨M⟩⟩ upper-bounds the normalised one-shot arbitrage gain". Counterexample: sentences A, ¬A, prices 0.5, 0.5+ε, β = 1. Selling one share of each gains ε in every world, while ⟨⟨M⟩⟩ ≈ ε² (computed 1.0e-2, 1.0e-4, 1.0e-6 for ε = 0.1, 0.01, 0.001). The sqrt bound is tight here (0.1008, 0.01, 0.001).
- Refuted: the reverse, "⟨⟨M⟩⟩ ≤ C · gain". Axiom A, price P(A) = δ: one-share gain 1 − δ ≤ 1 but ⟨⟨M⟩⟩ = log(1/δ) → ∞ (4.6, 9.2, 18.4).
- Unnormalised fixed-price arbitrage is scale-free (0 or ∞), so it cannot equal ⟨⟨M⟩⟩. The LMSR's price impact (the entropic risk charge βψ) is what makes the gain finite and equal to ⟨⟨M⟩⟩.
- Relation trader example (Fréchet): sentences A, B, A∧B with P = (0.4, 0.7, 0.5). The trader "sell A∧B, buy A" gains 0.1; ⟨⟨M⟩⟩ = 0.01015 ≥ 2G²/Σ(y²/β) = 0.0100 (nearly tight); q* = (0.449, 0.7, 0.449) (the violated Fréchet facet becomes tight). For {A, B, A∧B}, Q is exactly the Fréchet polytope max(0, a+b−1) ≤ c ≤ min(a, b).

**R6 (known / theorem): cost of computing q*, µ*.**
- Hardness (known): deciding ⟨⟨M⟩⟩ < ∞ includes SAT; deciding ⟨⟨M⟩⟩ = 0 (p ∈ Q) is probabilistic satisfiability (PSAT), NP-complete (Georgakopoulos, Kavvadias, Papadimitriou 1988, J. Complexity; Nilsson 1986, AI Journal; unverified recollection). So no polynomial exact method unless P = NP; Richardson, Halpern, De Sa (UAI 2023, https://arxiv.org/abs/2311.05580, unverified) solve PDG inference via exponential conic programs in polynomial time for bounded treewidth.
- Frank–Wolfe / column generation (theorem + known): the linear minimisation oracle over Q is min_{w⊨Γ} g·v_w with g = ∇f(q) = β ∘ (logit q − logit p), a weighted MaxSAT/ILP call. This is the scheme of combinatorial prediction-market makers (Dudík, Lahaie, Pennock EC 2012; Kroer, Dudík, Lahaie, Balakrishnan EC 2016 "Arbitrage-free combinatorial market making via integer programming", arXiv 1606.02825; unverified recollection). Every iterate is a mixture of models, so it is coherent on the query set. The FW gap g·(q_t − s_t) ≥ f(q_t) − ⟨⟨M⟩⟩ is a free certificate. Rate [skeptic: corrected, now theorem (a posteriori)]: the textbook constant C_f (Jaggi 2013, sup over all x, s ∈ Q) is +∞ here, because the Bregman divergence of f is Σ β_j d(y_j‖x_j) and it blows up as x_j → 0 or 1 (skeptic S5), and the original bound "Σ β_j / min q_j(1−q_j) along the path" is also infinite, since every FW segment ends at a 0/1 vertex. What holds is a per-iterate bound: KL ≤ χ² gives f(x + γ(s−x)) ≤ f(x) − γ·gap + (γ²/2)·C(x), with C(x) = 2 Σ_{j undecided} β_j (s_j − x_j)²/(x_j(1−x_j)) ≤ 2 Σ_j β_j/(x_j(1−x_j)). The standard induction then gives f(q_t) − ⟨⟨M⟩⟩ ≤ 2 C_max/(t+2), with C_max the maximum over the iterates actually visited. That is finite as long as the iterates stay inside (0,1) on undecided coordinates, which exact line search keeps them doing (the derivative is ∞ at the boundary). An a-priori bound on min_t q_t(1−q_t) is open (conjecture: bounded below in terms of min_j min(q*_j, 1−q*_j) and f(q_0)). It degrades when q* sits near 0 or 1. Skeptic S5 check: K = 6, 3000 iterations, C_max = 69.2, no violations of the bound. Check (K = 6, exact line search): gap 5.1, 0.59, 0.083, 0.0096, 0.0019 at t = 1, 10, 100, 1000, 5000, true suboptimality always below the gap (1.3, 0.25, 0.036, 0.0040, 0.0008).
- Sandwich bounds (theorem): any set of found models S ⊆ Mod Γ gives the upper bound min_{conv S} f ≥ ⟨⟨M⟩⟩. Any outer relaxation L ⊇ Q (local/pairwise-consistency polytope, Sherali–Adams level k, Fréchet constraints) gives the lower bound min_L f ≤ ⟨⟨M⟩⟩ in polynomial time for fixed k. It is exact at level K, and at the local level when the atom/sentence hypergraph is a junction tree (Wainwright & Jordan 2008, unverified). Duals evaluated with the relaxed oracle are also valid lower bounds. Gap example (computed): sentences A≠B, B≠C, A≠C each priced 0.9. Pairwise-local marginals (singles 1/2, each pair 0.45/0.45/0.05/0.05) are consistent, so the relaxed value is 0, but q1+q2+q3 ≤ 2 on Q and ⟨⟨M⟩⟩ = 3 d(2/3‖0.9) = 0.6038 (solver 0.60376). There is no general multiplicative approximation guarantee for relaxations (conjecture: as hard as PSAT gap versions).
- Entropic smoothing (theorem): µ_γ = argmin Inc − γH is unique, Gibbs: µ_γ(w) ∝ exp(−x·v_w/γ) 1[w⊨Γ] with x = β(logit q − logit p), q = E_{µ_γ} v (a fixed point that MCMC, belief propagation or mean field can approximate). It satisfies ⟨⟨M⟩⟩ ≤ Inc(µ_γ) ≤ ⟨⟨M⟩⟩ + γ log |Mod Γ| ≤ ⟨⟨M⟩⟩ + γ K log 2 (proof: compare objective values at µ_γ and the maxent µ*). Check: Inc(µ_γ) − ⟨⟨M⟩⟩ = 4e-5..1e-8, far below γ log n. Caveats: sampling models of Γ is NP-hard in general (sampling even one model solves SAT) and exact counting is #P-hard [skeptic: corrected from "sampling is #P-hard"]; a mean-field (product) µ satisfies hard clauses only when its support is a subcube inside Mod Γ, which can be a single world and so lose almost all the entropy [skeptic: the original "unless Mod Γ contains a subcube" is vacuous, since every model is a subcube]; so use finite axiom β or Bethe/BP with hard factors (exact on trees, heuristic on loops; no general error bound).

## Implications for the network

1. A fixed point with coherence is available and convex: block state = a coherent table q (a mixture of models), and the end-of-run loss can be the self-supervised f(q_out) = Σ β_j d(q_out,j ‖ p_j). By R2(e), f(q_out) − ⟨⟨M⟩⟩ ≥ D_β(q_out‖q*), so no ground-truth q* is needed. **[Skeptic caveat: this holds only for q_out ∈ Q.** For an unconstrained output, f is minimised by copying the input (q_out = p gives f = 0 < ⟨⟨M⟩⟩). Mixing in non-model vectors also takes f below ⟨⟨M⟩⟩: in the Fréchet example, f reaches 0.0054 < ⟨⟨M⟩⟩ = 0.0102 (skeptic S4). So the loss is sound only if q_out is built as a mixture of proposals that have each been checked against Γ (a linear-time clause check), or if a large hard penalty is added on axiom violations.] Report the FW gap per block as a cheap progress signal for testing at 100 and 500 blocks.
2. A natural block is one Frank–Wolfe/arbitrageur step. (i) Compute per-sentence "mispricing" g_j = β_j(logit q_j − logit p_j) (local, cheap). (ii) Propose a world w ⊨ Γ minimising g·v_w (the world the arbitrageur bets on: a learned MaxSAT/local-search proposal, the only hard part). (iii) Mix: q ← (1−η)q + η v_w. With exact proposals, prices are coherent at every block, entailed sentences go to 1, refuted to 0, and the error falls like 1/t, so more blocks help. If proposals violate axioms, the coherence error is bounded by the mass placed on non-models. Under the self-supervised loss, though, non-model proposals are rewarded (skeptic S4), so a block must reject proposals that fail the clause check rather than only tolerate them. The 1/t rate needs exact proposals and the a-posteriori curvature condition in R6.
3. An alternative is an exponential-weights (entropic mirror descent) block over worlds, µ ← µ·exp(−η g·v_w). It converges to the maxent µ*, which gives model-frequency behaviour on unpriced sentences (R2(d)), but it needs sampling or message passing over Mod Γ.
4. ⟨⟨M⟩⟩ has an LI reading: it is the one-shot profit of the best trader against per-sentence LMSR market makers with liquidity β, and q* is where that trader leaves the prices. This uses no history and no adversarial market maker, since the "trader" is the solver's dual variable. It covers one-day coherence, not LI's learning-over-time properties.
5. Practical: clip prices to [ε, 1−ε] or use finite β on axioms, otherwise ⟨⟨M⟩⟩ = ∞ (inconsistent Γ or hard 0/1 prices). β is the knob for how far logic may move a given input price.
