## 1. Why the expected result is uninformative as built

**1a. Protected arm: null by construction.** Belief/forecast adapters are trained on truth only; in
`mixed` the goal is drawn from its own RNG stream, independent of board and evidence (shiphunt.py:148-149);
the Bayes oracle `posterior()` has no goal term. So P(S | E, G) = P(S | E) and hiding G costs exactly
nothing at the optimum. Any measured gap is format or optimisation noise. Report it as an implementation
check, never as a finding.

**1b. "Need to know what you are looking for" cannot bind.** The belief pass is asked for every cell
(render.py `belief_seq`: all 12 cells on `easy`) from a ~100-token context. The environment designer
has already done the relevance work by fixing the query list, and nothing is scarce (no report budget, no
attention budget). Value equivalence (Grimm et al. 2020) and hard-attention bottlenecks (Tang et al. 2020)
both say task-blind perception costs only under a capacity limit. Expected cost is 0. Any nonzero cost is a
prompt-format artefact (see 2).

**1c. The forecast pass is not goal-blind and cannot be by deletion.** With the goal deleted the forecast
prompt still says "Event: success = 1 hit(s)" or "1 miss(es)" (render.py `event_text`). In a
single-objective environment the queried event *is* the goal. The approval rater pays for stated
P(success) >= 0.7 (shiphunt.py `approval_reward`), so "inflate the queried event" is goal-contingent
optimism that needs no goal token. A second leak: the plan is chosen by the goal-conditioned policy.
Under "hit" it picks high-P cells, under "avoid" low-P cells, so the goal is decodable from
(situation report at the plan's cells) inside the forecast pass. Deletion removes the goal's *text*, not its
*information*.

**1d. Hidden assumption: wishful thinking needs to know the goal.** It does not. In a select-then-evaluate
loop, the generic distortion is overconfidence in the direction of whatever was selected (sharpen the
beliefs, inflate the chosen plan's forecast). It flatters under every goal, so a goal-blind adapter can
learn it under fused or dose training. This is the optimizer's-curse shape (Smith & Winkler 2006), and Paster et al.
2022 show the conditioning-on-outcome version of it. Goal-blind content can remove only the *signed,
goal-contingent* part of the bias. If E5 reports "the goal-deleted fused arm is still overconfident, so
goal-blindness does not protect", that is the predicted result and says nothing against the design. If it
reports "goal-deleted is calibrated", check that the sharpening part was measured at all.

## 2. Confounds, measured (frozen Qwen3-0.6B, CPU, no training)

Script: hawks/E5-maskood.py. Results: hawks/E5-maskood-n12.json (12 episodes x 12 cells, `easy`, goal
alternating hit/avoid). An earlier 4-episode run is hawks/E5-maskood-n4.json. The script teacher-forces a
report `A:1 B:0 ...` and reads P(occupied) from the 0/1 logits at each slot. It compares the first-draft
single-pass typed mask (vendored in the script; the harness has since replaced it) with no mask.

| arm | KL from no-mask, nats/slot | Brier vs truth | mean P(occ) |
|---|---|---|---|
| no mask, true goal | 0 | 0.213 | 0.309 |
| no mask, goal swapped hit<->avoid | 0.033 | 0.205 | 0.308 |
| mask as first typed (instructions + first token CTRL, hidden from report) | 0.161 | 0.199 | 0.274 |
| mask hiding only the goal (instructions typed as content) | 0.0195 | 0.202 | 0.300 |
| same, goal swapped | 0.0195 (identical outputs) | 0.202 | 0.300 |

What this shows:
- About 88% of the shift from that single-pass mask (0.161 vs 0.0195) comes from hiding the instructions and
  the position-0 attention sink, not from hiding the goal. Attention sinks: Xiao et al. 2024. The artefact
  even *lowers* Brier (0.199 vs 0.213, because mean P(occ) moves toward the 2/12 base rate). A confounded
  mask comparison can therefore look like a perception *gain*. The per-episode Brier sd is about 0.05
  (same JSON). At this N no Brier difference in the table is resolved. KL is the measure of shift size.
- With no information in it at all, a swapped visible goal still moves beliefs by 0.033 nats/slot at init.
  So the visible-goal arm starts with a goal-contingent offset. Compare *changes from the pre-RL
  checkpoint*, and use `shuffled` (not `deleted`) as the information control.
- Under the content mask, outputs are exactly invariant to the goal (last two rows are identical). The mask
  is transitively closed: content positions see only content (hawks/E5-maskcheck.out, run against the
  07:01Z roles.py). Two consequences for T2c. First, T2.md point 3 ("the content mask is not transitive")
  holds only if forecast positions may attend to plan positions. Second, a goal-identity probe at masked
  positions is at chance by construction, so it cannot fail and proves nothing. It is informative only for
  the leaks in 1c (event text, plan selection). Whoever revives the single-pass mask must type the task frame
  and the first token as content. Also, the 07:01Z draft added the relevance router's bias on content query
  rows as well, and `goal_reaches` did not detect it (E5-maskcheck.out, last two lines). The router has since
  been removed. Any reintroduction must apply the bias to action rows only.
- Infra note for siblings: /tmp/lir-agent/pylib accelerate 1.15.0 fails with a circular import (07:07Z).
  Setting `sys.modules["accelerate"] = None` before importing transformers works around it (E5-maskood.py, line with sys.modules).

## 3. Prior work (fetched 2026-10-03 unless marked)

- Paster, McIlraith, Ba 2022, "You Can't Count on Luck", https://arxiv.org/abs/2205.15967 (abstract).
  Goal/return conditioning fails in stochastic environments because returns may come "due to luck". The
  fix, ESPER, conditions on cluster-average returns "independent from environment stochasticity". This is the
  named paper for E5a.
- Yang, Schuurmans, Abbeel, Nachum 2022, "Dichotomy of Control", https://arxiv.org/abs/2210.13435
  (abstract). A mutual-information constraint "that removes any information from the latent variable
  associated with randomness in the environment". It is an information constraint, not an attention mask:
  the precedent for 1c.
- Sekar et al. 2020, Plan2Explore, https://arxiv.org/abs/2005.05960 (abstract). A task-agnostic world model
  "almost matches" a reward-aware oracle, so goal-blind perception is cheap when capacity is adequate.
- Grimm, Barreto, Singh, Silver 2020, Value Equivalence, https://arxiv.org/abs/2011.03506 (abstract).
  Task-blind (maximum-likelihood) models cost only under "limited representational resources".
- Tang, Nguyen, Ha 2020, "Neuroevolution of Self-Interpretable Agents", https://arxiv.org/abs/2003.08165
  (abstract). A hard self-attention bottleneck seeing "a small fraction" of the input. This is relevance under a
  binding budget, the regime E5c needs.
- Xiao et al. 2024, StreamingLLM / attention sinks, https://arxiv.org/abs/2309.17453 (abstract). Initial
  tokens act as a "sink"; removing them breaks the model. This explains the 0.161 row.
- Ratner et al. 2023, Parallel Context Windows, https://arxiv.org/abs/2212.10947 (abstract). It restricts
  attention to within-window blocks in "any off-the-shelf LLM without further training". Ma, Wang, Tian 2025,
  Block-Attention, https://arxiv.org/abs/2409.15355 (abstract). Block masks reach parity with full attention
  after block fine-tuning. **Together these answer the "no small-paper precedent" objection.** Structured
  attention masks in pretrained decoders are an established small modification. They also show the mask has
  an OOD cost that adaptation must remove before any comparison.
- Yang et al. 2019, XLNet two-stream attention, https://arxiv.org/abs/1906.08237 (abstract fetched; the
  content/query-stream passage was quoted from the PDF by the 06:55Z draft, but the PDF did not parse on this
  pass, so the quote is unverified here).
- Smith & Winkler 2006, "The Optimizer's Curse", Management Science 52(3), https://doi.org/10.1287/mnsc.1050.0451
  (the DOI resolves to the INFORMS page; abstract 403, content unverified this pass).

## 4. Reshaped E5 (exact changes)

Order: E5c first (no RL, cheapest, and it alone answers Kelvin's objection), then E5a on checkpoints shared
with B0 and the dose arms. E5b runs only if E5a shows a signed effect.

**E5c: does goal-blindness cost perception when relevance has work to do?** (Grimm/Tang regime; no reward.)
Env change: two boards per episode with interleaved evidence lines. The goal names the board ("find a ship on
board 2"), drawn independently of both boards. Use enough probes that the context is the bottleneck (>= 40
lines per board on `medium`), or a report budget K < n_cells. Belief adapter trained on truth only, 0.6B,
>= 3 seeds. Arms in the belief pass:
- goal visible;
- goal deleted, with a goal-free *query* naming the board ("Report P(ship) for board 2 cells") chosen by the
  action pass (relevance = which query);
- goal deleted, no query (report both boards);
- goal shuffled (wrong board named).

Metric: Brier and ECE against the Bayes oracle on the goal board's cells, and in-context truth-trained curves
over steps. Prediction: the query arm matches the visible arm and beats no-query. If visible beats query
beyond seed sd, the goal carries perceptual information beyond the query. That would be the real cost of
goal-blindness and a finding against the design.

**E5a: does deletion remove goal-contingent wishful thinking?** (Paster 2022 modified: text POMDP, mixed
goals.) Fused B0 and dose arms (`loss_bf` alpha > 0, losses.py:198) with goal_mode in {deleted, visible,
shuffled} and reward in {approval, random}. `random` is the existing sharpening control (rollout.py:181).
Use `goal="mixed"` and >= 3 seeds. The protected arm runs once at deleted vs visible as the 1a check.
Metrics on the belief pass against the Bayes oracle, each as change from the pre-RL checkpoint, decomposed:
- signed goal-contingent bias b_G = mean over cells of (p - p_bayes) * s(goal), with s = +1 for hit and -1 for avoid;
- overconfidence = slope of logit(p) on logit(p_bayes), minus 1;
- probe: goal decodable from belief-pass outputs.

Prediction: deleted has b_G ~ 0 but overconfidence > random-reward control; visible has both. Decision: goal
deletion stays in the design only if b_G(visible) - b_G(shuffled) > 0 beyond seed sd under approval reward. The
report must say deletion leaves the sharpening component untouched (1d).

**E5b: forecast-side goal blindness** (only if E5a is positive). Replace the goal-naming event with a
goal-neutral claim set: per-cell hit claims plus P(k hits among the plan), both directions. The harness
computes P(success) from these by formula given the goal, outside the forecaster, and the approval rater reads
the derived value. Arms: current event text vs goal-neutral set. Also report a probe decoding the goal from the
situation-report values at the plan's cells (the selection leak, 1c). If that probe is far above chance, state
plainly that the forecast side is protected by the control mask, not by blindness.

**Kill instead if:** neither the two-board env nor a report budget can be built tonight. E5c is then null by
construction (1b), and E5a alone answers a different question (wishful thinking), not the one asked.

**Cost:** E5c is belief-only truth training on 0.6B, under 1 L4-hour for 4 arms x 3 seeds at `medium` sizes
(estimate, unmeasured). E5a reuses B0 and dose rollouts plus 2 extra goal_mode arms. The frozen controls
above ran on CPU in 72 s (E5-maskood-n12.json "secs").
