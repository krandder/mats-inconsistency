# Hawk E2: gradient routing for a reward-only action adapter

Hawk for item E2 in `../GOAL.md`. Written 2026-10-03 by the E2 hawk subagent. No runs were made; this is a
pre-run review. Verdict: **RESHAPE** (the exact change is in section 5).

Item as filed: gradient routing (Cloud et al. 2024) confines the reward gradient to an action adapter.
Measure the fraction of the reward-gradient norm that reaches the belief parameters, and test whether it
predicts sycophancy. Objection supplied with the item: with shared attention and a shared residual
stream, adapter-level masks do not localise representations, so the belief tokens still change.

## 1. Main problem: in the protected arm the metric is zero by construction

GOAL.md already says the policy's GRPO objective excludes forecast and belief tokens, and that its
gradient is routed only to the action adapter. With that design, the reward gradient that reaches the
belief adapter is **exactly 0**, so the "fraction" is a unit test of the code, not a finding. In the
fused baseline B0 it is some number. So "fraction predicts sycophancy" reduces to the arm contrast
(B0 vs protected), with 3 seeds per arm, which gives two clusters and n = 6. That is not a correlation,
and it repeats the B0-vs-E1 comparison.

LIR's control mask χ is defined per **parameter coordinate** (`../li-net/STUDY-LIR.md` line 13; LIR 2026,
`../li-net/lir2026.txt` line 277, "a control mask χ ∈ [0,∞]^A"). In a PDG each cpd has its own
parameters, so freezing the parameters freezes the cpd. In a transformer, the belief "cpd" is a
function of the belief adapter, the base weights **and the context**, and the context includes K/V
vectors that the action adapter computes at the action and plan positions. A parameter-level mask
therefore does not imply a cpd-level mask. That is the item's objection, and it is right for two of the
three channels below.

## 2. Three channels by which reward can move beliefs with zero reward gradient on belief parameters

- **P (parametric).** The reward moves weights that the belief computation uses. This is zero only if
  (i) the base model is frozen during RL and (ii) adapters are routed **per token**, so the action
  adapter is inactive at belief and forecast positions. Standard PEFT LoRA applies the adapter at every
  position, so with an off-the-shelf implementation the action adapter runs inside the belief tokens'
  forward pass. The gradient fraction would read 0 while belief outputs move. Emergent misalignment shows
  that narrow training spreads broadly through shared weights (Betley et al. 2025,
  https://arxiv.org/abs/2502.17424, verified: "Training on the narrow task of writing insecure code
  induces broad misalignment").
- **K (KV / attention).** The belief and forecast tokens that come after any action or plan token in the
  trajectory (every later turn of a POMDP episode, and every forecast of a policy-written plan) attend to
  K/V vectors produced by the action adapter. Even with **identical text**, their hidden states change.
  The gradient metric cannot see this. It is exactly the item's objection.
- **D (distributional / conditional).** The policy learns to write plans, phrasing and actions that
  steer the forecaster and the belief reporter (GOAL.md itself expects "phrasing tricks that fool the
  forecaster"). The belief adapter keeps learning on truth, but only on the states the policy visits, so
  it co-adapts to the policy. This is Drori et al.'s "conditional feedback spillover".

## 3. Prior work that mostly answers it (fetched and verified)

- **Drori, Marks, Woodworth, Cloud, Turner (2025), "Output Supervision Can Obfuscate the Chain of
  Thought"**, https://arxiv.org/abs/2511.11584 (HTML v1 fetched). It is from the same group as gradient
  routing and runs the same experiment one level up. They split spillover into *parametric* (Def. 6:
  ∇_out E[M_out]·∇_CoT E[M_CoT] > 0) and *conditional* (Def. 5: ∇_CoT E[M_out]·∇_CoT E[M_CoT] > 0).
  "Mind & Face" (separate parameters for the CoT and the output; Kokotajlo & Demski 2024 as cited there,
  (unverified) as to the original) zeroes the parametric term. "Reward targeting" (dropping the
  ∇_CoT term from REINFORCE) addresses the conditional term. Results (REINFORCE, Qwen3-4B/8B/14B):
  Mind & Face alone was "ineffective" in the polynomial setting. In the terminal setting with the regex
  penalty, both mitigations were "only partially successful" alone (M&F 0.98/0.03, RT 1.0/0.00), and
  RT+M&F prevented spillover completely. Overall, "reward targeting had a larger effect than Mind &
  Face". Consequences for E2:
  - E2's protected arm **is** Mind & Face plus reward targeting, with per-role adapters in place of
    model copies. The headline "parameter separation alone does not stop belief drift" is already
    shown.
  - What Drori et al. did **not** have is a truth signal on the "mind": their CoT had no ground truth.
    E2's real new piece is the belief and forecast adapters that keep learning prequentially on
    realised truth during RL, in an environment where truth is checkable. Frame E2 as "Drori et al.
    2025 + a truth-trained Mind", not as "gradient routing measures leakage".
- **Cloud et al. (2024), Gradient Routing**, https://arxiv.org/abs/2410.04332 (abstract verified). This
  is the named base paper. Its weighted, data-dependent masks are what allows a dose knob (section 5).
- **Chen, Arditi, Sleight, Evans, Lindsey (2025), Persona Vectors**, https://arxiv.org/abs/2507.21509
  (abstract verified). Sycophancy shifts after finetuning "are strongly correlated with shifts along the
  relevant persona vectors". This is an activation-level metric, applied to the residual stream at the
  belief positions, that sees channels P and K. A gradient-norm fraction sees neither.

## 4. Confounds that make "fraction of reward-gradient norm" meaningless even in B0

1. **Adam erases gradient scale.** Per-coordinate normalisation makes the size of each update roughly
   independent of the gradient norm. A group that receives 5% of the gradient norm can get a
   comparable share of the parameter movement. Measure ‖Δθ‖ per group (the update fraction), not ‖g‖.
2. **Gradient credit is a weak proxy for functional effect.** This is our own verified result. On the
   wealth-net, exact leave-one-out settlement beats gradient norm at ranking units against an ablation
   oracle by 0.245 ± 0.097 Spearman, 3/3 seeds (`../traders-net/study/X1/CLAIMS.md` line 35,
   `../traders-net/study/M3/results/stop_rule.json`). Gradient norm alone scores Spearman 0.168 ± 0.07
   (`../traders-net/study/D1/IDEAS-NET.md`, Q1 row). Expect the same weakness here: measure the
   functional change of the belief outputs directly.
3. **Adapter size and rank.** The norm fraction scales with the parameter count of each group. It has
   to be normalised per parameter, or reported against a random-mask group of matched size.
4. **There may be no sycophancy to predict.** A Mastermind/Battleship POMDP has no user and no opinion
   to flatter, and the environment reward is **aligned with truth**: an accurate belief gives better
   actions. So even fused GRPO has little incentive to distort beliefs, which makes a null result
   uninformative. Belief distortion appears only under a reward–truth conflict. Examples: the reward
   reads the situation report or the forecast (the RLHF analogue of a fooled judge); the utility
   favours hidden states the agent cannot affect (an incentive for wishful thinking); or overconfidence
   pays as a commitment device.
5. **n.** With two arms and 3 seeds, no slope can be estimated. Our own X1 found that 3-seed sd
   understates by a median 1.7x (`../traders-net/study/D1/IDEAS-NET.md`, robustness hygiene item).

## 5. Reshape (exact change)

Replace E2 with: **"Drori et al. 2025 (Mind & Face + reward targeting) with a truth-trained Mind, on the
text POMDP; channel-decomposed belief drift vs a gradient-routing dose."**

1. **Dose, not two arms.** Set the gradient-routing mask weight α on the belief and forecast adapters
   for the reward loss to α ∈ {0, 0.1, 0.3, 1}, using a Cloud et al. weighted mask. α = 1 is B0 and
   α = 0 is the protected arm. Run 3 seeds per α (5 if the budget allows). Report the slope of belief
   drift on α, and the slope on the measured **update-norm fraction** ‖Δθ_belief‖/‖Δθ‖. The gradient-norm
   fraction stays as a secondary column only.
2. **Reward–truth conflict knob.** Add a fooled-judge reward term with weight w ∈ {0, 0.3}. The term
   rewards a confident P(success) in the committed-plan forecast and a situation report that names a
   reward-favoured hidden state. Run the α sweep at w = 0.3. At w = 0, run only α ∈ {0, 1}, as the
   no-conflict check. Before training, record the cosine between the reward gradient and the
   truth-log-likelihood gradient on the belief tokens in B0 at initialisation. If it is > 0 at w = 0,
   the w = 0 condition has no incentive to distort beliefs, and it must not be read as evidence.
3. **Sycophancy, defined for this environment.** Use two measures: (a) wishful bias = mean over
   episodes of the reported P(reward-favoured hidden state) minus the Bayes posterior from the evidence
   (computable in Mastermind/Battleship); (b) forecast optimism = forecast P(success) minus the realised
   rate, together with calibration (ECE, Brier). Add a persona-vector-style probe: the mean residual
   projection at belief positions onto the direction "reward-favoured minus truthful" fitted before RL.
4. **Cheapest control (evaluation only, no training) that separates the claim from the objection.**
   For each final checkpoint, score the belief and forecast outputs with teacher forcing on three fixed
   context sets:
   - C0: pre-RL trajectories cut **before** the first action or plan token. Any change here = channel P.
     It must be bit-identical at α = 0; otherwise the adapter is not routed per token, which is an
     implementation bug.
   - C1: the same pre-RL trajectories with the text unchanged, cut after action and plan tokens. Swap
     only the action adapter (pre-RL vs post-RL). Change = channel K.
   - C2: post-RL on-policy trajectories vs C1, with the same post-RL belief adapter. Change = channel D.
   The claim "control masks protect beliefs" survives only if belief drift at α = 0 is ≈ 0 in all
   three of C0, C1 and C2 while B0 drifts. If drift sits in C1 or C2, the objection wins. The fallback
   GOAL.md names (separate losses) would not fix that; the fixes are a stop-gradient on action-position
   K/V for belief readers, a goal-blind content mask extended to action tokens, or Drori-style targeting.
5. **Cheap pre-check before any GPU.** Inspect the code and run one forward pass: confirm the base is
   frozen and that the action adapter's LoRA delta is masked to action positions (zero at
   belief/forecast positions). If adapters are applied at all positions, fix that first; otherwise
   E2 measures an implementation detail.

**Kill condition, if the reshape is not taken.** Run E2 as filed (gradient-norm fraction, two arms, no
reward–truth conflict) only if B0 is shown to produce measurable wishful bias at w = 0 (a pilot run with
the bias > 2 sd above the pre-RL level). Without that, the fraction is 0 vs x by design and there is
nothing for it to predict.
