• **Model:** The task collapses to "estimate Σ from T error samples, then GLS" — and since v_t is shown, history errors are observed exactly, no filtering. At T=0 the structure-blind prior rule is exactly Bayes, so the whole design problem is making T-sample structure inference necessary, identifiable, and non-memorisable. The spec mostly does this; variant (b) is mis-specified, and the finite family invites a memorisation shortcut the spec doesn't guard against.

  **1. Shortcut pass?** At T=0, Bayes = GLS with prior-averaged Σ̄: a fixed linear rule, optimal and structure-blind — the spec owns this ("prior-level"). The dangerous near-shortcuts: (i) per-trader precision weighting from history variances passes scaling-vs-T and T=0 tests but fails dedup/history-gate by construction — those cruxes are well-aimed; (ii) sample-covariance plug-in GLS passes *everything* whenever T ≥ N, so T<N regimes are essential to force prior usage; (iii) memorising the finite family (§4). Structure matters when shared-source variances are ≳ Var(v), within-group ρ ≳ 0.3–0.5, and N ≫ K; if ρ ≲ 0.2 or idiosyncratic t2 dominates, oracle-GLS ≈ precision-weighting and no test separates anything. Calibrate the prior so the average Bayes-vs-blind KL is ≥ ~0.5 nats, and verify the 0.3-nat gate numerically before training.

  **2. Exact Bayes.** (a) is correct and cheap: likelihood per hypothesis is exp(−T/2 [log|Σ_h| + tr(Σ_h⁻¹S)]) with S the scatter matrix; mixture-GLS posterior. Identifiable for any T ≥ 1 provided family members differ; T < N is harmless (singular S is fine inside the trace) — this is (a)'s big advantage over plug-in GLS. Pitfalls: the family must equal the generative support exactly, else "exact Bayes" is mis-specified; enumeration must be polynomial in N (restrict block structure); posterior concentration needs T large relative to log M, and that M-vs-T trade-off *sets the task difficulty* — make it an explicit design knob. (b) is the weak point: the generator produces sparse factor structure (K ≪ N), which inverse-Wishart cannot represent — IW induces a restrictive, non-sparse correlation law, so (b) is Bayes for the wrong prior and will underperform (a) precisely in the sparse-sharing regimes the cruxes target. Numerically, IW needs ν > N+1 for a mean (ν ≥ 66 at N=64 — a near-point prior at small T), and the multivariate-t predictive via 1-D quadrature is fine but inherits all of this. Cut (b) for v1.

  **3. Token design.** Per-report tokens, one per (t,i): scalar channel r_{t,i}, separate v_t channel on history tokens, role flag (history/query), round scalar t (normalised), and the trader's id vector through a small encoder. Query round: N report tokens + a learned [QUERY] token, attention-pooled to output (μ, σ²). Rationale: the binding crux requires query token i to attend to same-id history tokens — per-report tokens make that attention directly inspectable; per-trader history-column tokens would make the shuffle control trivially detectable and binding untestable. Provide log N and log T as explicit scalars: helps length generalisation (the beyond-N variance-shrink failure) and lets the model modulate posterior sharpness with T. Keep raw report values in a dedicated unnormalised channel so value-tie shortcuts (the exact-copy dedup failure mode) are unavailable by construction — correlated-but-unequal reports force covariance-style discounting.

  **4. Learnability.** All prior failure modes bite: (i) at small T the optimum ≈ fixed weights, so gradient to use history/ids is weak — the source-binding plateau, now at scatter-matrix level. Fix: curriculum T large→small, random T per batch, ≤10% T=0 episodes. (ii) Loss must be Gaussian NLL (μ and σ²) — MSE cannot teach dedup variance-discounting or a nats-scale gate. (iii) Weight loss by per-episode Bayes-vs-blind gap (dense hard-example emphasis) so shared-evidence discounting gets gradient — this directly targets the earlier shared-evidence failure. (iv) Randomise N per batch up to 64+ to attack non-shrinking variance. Memorisation risk: if the same finite family recurs across episodes, the model can memorise sufficient-statistic→posterior maps per structure, indistinguishable from in-context inference on train metrics. Fix: M ≥ 10^5 (GPU-batched solves), plus an eval split with completely fresh structures; report the novel-structure gap as the headline number.

  **5. One change + first pilot.** Change: make the structured family the sole Bayes target for v1 — planted partition into blocks (one shared source each, optional global common source, idiosyncratic noise), variances on a discrete grid, M ≈ 10^5 hypotheses enumerated GPU-batched; drop IW. Pilot: N ∈ {4…16}, T ∈ {8…64} (T ≥ N often enough to identify structure), train a ~4M-param per-report set transformer on NLL against the exact mixture-GLS target. Success criteria: ≥90% of the Bayes-vs-blind gap closed at T ≥ N; history gate tracked ≥ 0.3 nats; dedup predictive variance within ~2× of Bayes; shuffled-history control wipes the T>0 gain.
