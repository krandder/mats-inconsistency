Model: Gemini 4 Argon (High)

### 1. Shortcut Audit & Regimes Where Structure Matters
As written, four structure-blind shortcuts will pass unless the prior is constrained:
- **Equal-weight eigenvector trap ($\Sigma\mathbf{1} = c\mathbf{1}$):** Exact GLS weights satisfy $w \propto \Sigma^{-1}\mathbf{1}$. If clusters have equal size and equal variance, $\mathbf{1}$ is an eigenvector of $\Sigma^{-1}$, making equal averaging ($w_i = 1/N$) *Bayes-optimal for the predictive mean*; correlation structure only changes scalar shrinkage toward $0$.
- **Public-source redundancy:** A common source adds $s_{\text{pub}}^2 \mathbf{1}\mathbf{1}^\top$ to $\Sigma$. By Sherman–Morrison, $(\Sigma_0 + s_{\text{pub}}^2\mathbf{1}\mathbf{1}^\top)^{-1}\mathbf{1} \propto \Sigma_0^{-1}\mathbf{1}$: a common source *never* alters relative trader weights, only overall shrinkage and variance.
- **Diagonal-variance proxy:** If shared noise is added on top of $t_i^2$, shared-source traders have larger marginal variance $\Sigma_{ii} = \sum_s A_{is}^2 s_s^2 + t_i^2$. A correlation-blind rule weighting by historical per-trader precision ($1/\hat{\Sigma}_{ii}$) automatically downweights shared traders without estimating covariance.
- **Query-time cluster trimming ($T=0$ shortcut):** If $t_i^2 \ll s_s^2$, traders sharing a source emit near-identical query reports $r_i \approx v + \eta_s$. A set transformer can deduplicate at $T=0$ by downweighting dense clusters in $r$ alone, repeating your exact-tie lesson.

**Regime where structure matters:** Enforce **constant marginal variance** ($\Sigma_{ii} \equiv \sigma_e^2$ across all $i$), **asymmetric cluster sizes** (e.g., one clique of size $k \approx N/2$ vs. singletons), **moderate correlation** $\rho \in [0.6, 0.85]$ so query reports do not tie ($t_i^2 \ge 0.15\sigma_e^2$), and **signed loadings** $A_{is} \in \{-1, 0, +1\}$ (oppositely loaded pairs cancel noise and get *upweighted*, whereas positively correlated pairs get *downweighted*—indistinguishable without historical cross-covariance).

### 2. Exact Bayes: Correctness, Cost & Pitfalls
- **Variant (a) (Finite family):** A small fixed hypothesis catalog lets the model learn a prior-level classifier that breaks when $N$ scales ($N=64+$). Conversely, enumerating all cluster partitions over $N$ traders scales as the Bell number $B_N$ (intractable for $N \ge 15$). Either restrict (a) to small-$N$ mechanistic probes or sample $M$ candidate structures $A^{(m)}$ per episode.
- **Variant (b) ($\mathcal{IW}(\nu, \Psi)$):**
  - *Prior mismatch & $T < N$ dilution:* Generating data from low-rank factor structure $\Sigma = A\operatorname{diag}(s^2)A^\top + \operatorname{diag}(t^2)$ while computing Bayes targets under $\mathcal{IW}(\nu, \Psi)$ yields **misspecified Bayes**. Because proper $\mathcal{IW}$ requires $\nu > N-1$, at $N=64, T=16$ the rank-$T$ update $\Psi + \sum_{t=1}^T e_t e_t^\top$ only modifies a $T$-dimensional subspace and the isotropic prior $\Psi$ dominates ($\nu/(\nu+T) > 80\%$), washing out strong shared-factor correlations.
  - *Numerical pitfall & fast reduction:* Evaluating an $N$-D multivariate-$t$ density at $Q$ quadrature nodes costs $O(QN^3)$ and underflows in float32 when $(\nu+T)/2 > 50$. Reduce $(r - v\mathbf{1})^\top \Psi_{\text{post}}^{-1}(r - v\mathbf{1})$ first to three scalars—$a = \mathbf{1}^\top \Psi_{\text{post}}^{-1}\mathbf{1}$, $\hat{v} = \mathbf{1}^\top \Psi_{\text{post}}^{-1}r / a$, and $c_\perp = r^\top \Psi_{\text{post}}^{-1}r - a\hat{v}^2$—then integrate 1-D in log-space around $\hat{v}$ in $O(N^3 + Q)$ time.

### 3. Token Design for Binding and Scaling
- **Reject flat per-report tokens `(trader_id, round_id, r_{t,i}, v_t)`:** $N(T+1)$ tokens hits $8{,}256$ tokens at $N=64, T=128$, scales as $O(N^2T^2)$, and requires a two-hop composition (match `round_id` to form $e_{t,i}e_{t,j}$, then pool over `trader_id`)—directly causing Astra's source-binding plateau.
- **Use $2N$ tokens ($N$ history-column + $N$ query tokens) with random-projection history encoding:**
  Pass residuals $e_{t,i} = r_{t,i} - v_t$ explicitly. Pool each trader's $T$ history rounds into one column vector using shared per-round random orthogonal features $u_t \in \mathbb{R}^{d_h}$: $h_i = \frac{1}{\sqrt{T}}\sum_{t=1}^T e_{t,i} u_t$. Then a single dot-product attention layer across trader tokens computes $\langle h_i, h_j \rangle \approx \frac{1}{T}\sum_{t=1}^T e_{t,i}e_{t,j} = \hat{\Sigma}_{ij}$ for any $T$. Splitting into $N$ history tokens `(trader_id_i, h_i)` and $N$ query tokens `(trader_id_i, r_i)` keeps sequence length at $2N$ while making history-to-query binding directly testable via `trader_id` permutation.

### 4. Failure Modes & How to Make It Learnable
- **Why it will plateau:** (1) *Scalar target bottleneck:* supervising only on scalar $v$ (or $(\mu_{\text{post}}, \sigma_{\text{post}}^2)$) gives 1–2 scalars of gradient per episode; diagonal weighting already captures ~85% of variance reduction, trapping SGD before it learns matrix inversion $\Sigma^{-1}\mathbf{1}$. (2) *Softmax $N$-scaling failure:* row-normalized attention sums to 1, failing to scale posterior precision with effective sample size $N_{\text{eff}} = \mathbf{1}^\top \Sigma^{-1}\mathbf{1}$ as $N$ grows beyond training.
- **How to fix it:**
  1. **Explicit per-trader precision-weight head + dense auxiliary supervision:** Have each trader token output an unnormalized precision contribution $\hat{\beta}_i$ so $\hat{\tau}_{\text{post}} = 1 + \sum_i \hat{\beta}_i$ and $\hat{\mu}_{\text{post}} = \hat{\tau}_{\text{post}}^{-1}\sum_i \hat{\beta}_i r_i$, and supervise $\hat{\beta} \in \mathbb{R}^N$ directly against the oracle vector $\beta^* = \Sigma_{\text{post}}^{-1}\mathbf{1}$ during training.
  2. **Curriculum:** Train first at $T \ge 4N$ with $\Sigma_{ii} \equiv 1$ and signed loadings $\{\pm 1, 0\}$, then anneal to smaller $T$.

### 5. One Concrete Spec Change & First Pilot
- **Spec change:** Fix marginal variances $\Sigma_{ii} \equiv \sigma_e^2$ across traders with asymmetric cluster sizes and signed loadings ($\pm 1$), and require an explicit per-trader weight readout $\hat{\beta} \in \mathbb{R}^N$ scored against $\Sigma_{\text{post}}^{-1}\mathbf{1}$.
- **First pilot:** Run the pre-training Rewiring Audit at $N=8, T=32, \Sigma_{ii}=1$ (one 5-trader clique at $\rho=0.8$ + 3 singletons) to verify a $\ge 0.3$ nats gap over diagonal weighting; then run a $2 \times 2$ Set Transformer pilot on $N=8, T=32$ comparing `{flat N(T+1) vs. 2N column tokens}` $\times$ `{v-only loss vs. +beta* supervision}`, evaluated zero-shot at $N=32$ and under shuffled-history control.
