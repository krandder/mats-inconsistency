Model: Fable 5.1 (claude-fable-5-1). Round 2, Claude critic. No experiments run; this is a critique of text.

1. ATTACKS

Codex, hierarchical junta (persistent b_x). The new ingredient is prior-level by construction. An item's evidence saturates at tau^2, a constant of the training prior, so the per-item weight 1/(n_x + sigma^2/tau^2) is a fixed table the net learns without any in-context inference; that is exactly the discounting Kelvin excluded. The only in-context part left is A's 92-template selection, unchanged. And b_x never resolves, so at large N the Bayes-gap floor is set by tau^2, not by aggregation, which muddies the policy readout.

Codex, provenance world. Event IDs make dedup exact key matching, the case already measured (depth 2+, about 80% with group keys). Copies identical in every field pose no similarity question, and MCTS has no event IDs; the realistic version is correlated, not identical, evidence. It is a regression test, not a new observation.

Gemini, 16-bit subspace junta. It fixes the wrong objection. Pigeonhole lookup only helps case (i), and the query is unobserved anyway. The objection that carries over untouched is that |R|=2 with four cells is 120-way model selection on one-layer statistics (bit agreement times label difference), the easiest (iii). Worse, with 65,536 moves and N<=2048 exact repeats never occur unless the policy forces them, so (i) and the copies-vs-fresh distinction vanish from the world. Four cells also means every posterior is sharp after ~50 readings; N=2048 tests saturation, not aggregation.

Gemini, transposition graph. "32 permutation/reflection rules" is unspecified, so exact Bayes is undefined until Phi is. Once specified, similarity is an equivalence (same state, identical value): case (i) with hidden identity under a 32-template menu, with no graded similarity, which is the whole point of "semantically similar". It also needs order-aware path tokens; with set tokens the invariance is free.

Agreement: Codex's ignorability qualifier is right and should be a stated assumption in every world. It does not, however, guard against the count-to-value shortcut under value-adaptive policies; neither critic's proposal tests that.

2. PORTFOLIO (build order)

P1 Junta W1 (12 bits, |R|<=3, 298 templates). Behaviour: inferred relevance plus rare-cell queries under concentrated policies. Exact Bayes: mixture over R with per-cell (count, sum). In-context forced: R is per-episode; the prior-level shortcut is count-to-value regression, guarded by held-out policies. Predicted mechanism: layer 1 per-bit and per-pair contrasts plus per-cell counts; layer 2 template weights and 1/m weighting, attention logits tracking -log(m_g/N). Cheapest; the policy-invariance crux lives here.

P2 Crossed items x sources (market world). K items v_k ~ N(0,1); S sources with bias b_s ~ N(0,tau^2); a reading of (k,s) is v_k + b_s + eps. Policy chooses (k,s) pairs with arbitrary concentration. Exact Bayes: linear-Gaussian; sufficient statistics n_ks and sum_ks, one (K+S)-dimensional solve, any N. Behaviours: repeats from one source saturate (graded copies, not identical ones); a source's bias is identifiable only through the overlap graph, which items it also rated and what other sources said about them, so prior-level shrinkage that ignores the graph fails. Heterogeneous biased sources combined into one estimate is market-like. Test with K and S grown beyond training, answering Codex's point that N>256 only adds repeats. Mechanism: alternating item-to-source-to-item residual passing; a depth-L net does about L rounds of Gauss-Seidel, so the gap should fall with L and rise with graph diameter.

P3 Measurements plus constraints. Same v; three token types: measurement y = v_k + eps; difference c = v_k - v_j + eps'; equality v_k = v_j (zero noise, "these are the same item"). Exact Bayes: linear-Gaussian, equalities as hard merges. Behaviours: dedup via a stated constraint; information that reaches the query only along a path; the path length l between query and nearest measurement is a dial. Mechanism: type-routed heads; prediction that the gap jumps when l exceeds depth. This is the depth crux.

P4 CTW cut-tree (my r1 W2). Non-menu similarity (2^(2^d - 1) partitions), exact in O(Nd), hierarchical evidence, one head per level. Last: the mechanism is predictable and the prior unnatural. Worth building only if P1-P3 show the net is using a template-menu trick that P4 forbids.

3. CRUXES

C1 "Attention-style aggregation can be policy-invariant at N >> N_train." P1: train on a policy mixture at N<=64; test at N=4096 under Zipf with the query in a cell of multiplicity m_q/N <= 1/256. Contamination slope: regress (net mean - Bayes mean) on (dominant-cell mean - query-cell Bayes mean) over 2000 episodes; Bayes slope is 0 by construction. Refuted if slope > 0.5 on >= 16/20 seeds at N=4096 while the same seeds show slope < 0.1 at N=64 (so it is a length effect, not a training failure). If slope > 0.5 already at N=64, the net never learned the mechanism and the test is void; report both.

C2 "In-context dedup needs depth that grows with the redundancy structure." P3 with l in {1..6}, depths L in {2,3,4,6}, l uniformly represented in training. Prediction: KL gap at l > L-1 is > 5x the gap at l=1. Refuted if a depth-2 net is within 0.05 nats of Bayes at l=6 on >= 16/20 seeds; that would mean one layer does multi-hop through learned transitive keys and the depth story is wrong.

C3 "A bounded consensus state can match full-context aggregation." P2 with K = N/4 growing. Compare full attention with a matched-parameter net whose context passes through k=32 query-conditioned summary tokens. Refuted if the bottleneck gap exceeds the full-attention gap by > 0.1 nats at N=2048 and grows monotonically over N in {128,512,2048}. Both halves are required: the bottleneck must match when K is fixed (sufficient statistics bounded) for the failure at growing K to be informative.

C4 "The net dedups in context rather than by prior-level discounting." P2 intervention: to the same episode append 8 more readings of the query item from the already-dominant source, versus 8 readings from 8 new sources; measure delta_rep/delta_fresh per episode against the Bayes ratio. Train at source-concentration rho, test at 5 rho. Refuted if the net's predictions are closer in KL to a "training-rate shrinkage" reference (Bayes with the training rho baked in) than to in-context Bayes on > 80% of test episodes, at every depth tested.

4. ARCHITECTURE

The findings that would motivate changes are specific failure modes, not successes. If C1 fails by contamination slope, the mechanism is softmax normalising by m_g/N, and the fix is a count-normalised attention (a head whose output is divided by an in-context group count, or a log-count bias on logits) that restores slope < 0.1 at N=4096 with the same parameters and training N. If C2 shows the gap jumps at l > L-1, that motivates a weight-shared iterative layer run until residual inconsistency stops falling, which is Kelvin's minimised-inconsistency search as an architecture; justified if the iterated net matches a depth-6 net at l=6 with depth-2 parameters. If C3 shows the bottleneck matches only when sufficient statistics are bounded, that defines the bounded consensus state as a ledger of sufficient statistics and says when it cannot exist (growing item sets without a query-conditioned summary). If all four cruxes survive at 64x N under held-out policies, no new architecture is justified, and that result is itself the sharp observation: plain attention already is the policy-invariant aggregator, and the program should move to the reasoning axis rather than the observation axis.
