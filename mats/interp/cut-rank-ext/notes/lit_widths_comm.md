## 0. Bottom lines (details, quotes and tags below)

1. Smooth real messages, EXACT computation (Abelson; Luo-Tsitsiklis). Two-way, any number of messages and rounds, message functions and the final output (computed by one side from its OWN full input plus all messages received) twice continuously differentiable, f of class C^2: total number of real values sent >= rank of the m x n mixed Hessian [d^2 f / dx_i dy_j] at every point (Abelson's own memo, MIT/LCS/TM-102 April 1978, Thm 2, read in full [FT, IMG]; restated as LT93 Thm 5.1 for any open D, with the final output C^2 too). One-way, local: the optimum is exactly dim span{ df/dx_i (x*, .) } (Abelson Thm 1; LT93 Thm 3.1(b)); but Abelson's own example Phi = sum y_k x_1^k + sum x_k y_1^k needs n values one-way and 3 two-way, so the one-way span dimension does not bound two-way protocols. With only C^1 messages and a merely continuous final function: LT91 Thm 2.1, >= min{n_f, m_f}. I found NO epsilon-approximate or mean-square version of any of these.
2. Continuity alone is not one thing.
   (a) one-way, exact, worst case: continuity of the ENCODER alone gives dimension lower bounds, the decoder may be arbitrary (DHM89 Thm 3.1 + proof; Siegel Prop. 1).
   (b) multi-round / adaptive with arbitrary (irregular) dependence on past messages: the Borsuk-Ulam bound collapses from m to about log2 m (Krieg-Novak-Ullrich arXiv:2412.06468 Thm 1; Ullrich arXiv:2610.33781 Thm 1, Cor. 2). LT's classes avoid this by requiring the message maps to be regular jointly in (own input, past messages).
   (c) mean-square / measure-weighted: continuity (even with continuous decoder) gives NO lower bound [MINE, Lusin]. A mean-square lower bound needs explicit Lipschitz constants (or a modulus of continuity); then the Gromov waist theorem gives one [MINE sketch, section E].
3. Stable widths (CDPW 2022): worst case over a compact K; Thm 3.3 Carl-type inequality eps_n <= C(r,gamma)(n+1)^{-r} sup_m (m+1)^r delta*_{m,gamma}; Thm 4.1 in Hilbert space delta*_{26n,2} <= 3 eps_n. Average-case: only DEFINITIONS found (Bensalah-Nouy-Soffo 2025, Sec. 2), no Carl/Borsuk-Ulam theorem.
4. Caps on continuous summaries: Menger-Nobeling (covering dimension m => continuous injective encoder into R^{2m+1}); Hunt-Kaloshin (k > 2 d_B => prevalent linear maps injective with Holder inverse, exponent theta < (k-2d_B)/(k(1+tau/2)) in Hilbert space). ReLU: weights -> function is locally Lipschitz (PRV Prop. 4.1); local functional dimension <= #parameters - #hidden units (GLMW Thm 7.1, stated with biases).
5. Bits: Lee-Shraibman/Krause Thm 4.3 as printed has output = LEAF LABEL (a function of the transcript only), so it does NOT cover an output that depends on a party's private input; the extension (rank <= #leaves) is immediate [MINE]. Rank only yields b >= log2 rank (exponentially lossy; Chakrabarti-Regev give Omega(n) for the inner-product-sign problem where rank gives log n).
6. Waist (Gromov 2003): any continuous f: S^n -> R^k (or R^n -> R^k with Gaussian measure) has a fibre whose t-neighbourhood is at least as big as that of a codimension-k great sphere (subspace), for ALL t. Holds for every non-degenerate Gaussian (Akopyan-Karasev Thm 1.1); the exact t-neighbourhood form FAILS for some compactly supported radial measures.
7. Claim checks are in section (iii): both claims survive as stated in their literal upper-bound / leaf-count form, but each needs a stated hypothesis (which metric, which Lipschitz constants, which coin model, worst-case length) that the sources force.

## A. Real-valued communication complexity

### A1. The model (Luo-Tsitsiklis 1993, Sec. 1.1) [FT]
Luo, Z.-Q.; Tsitsiklis, J. N. "On the communication complexity of distributed algebraic computation." J. ACM 40(5):1019-1047, Nov. 1993. URL: https://www.mit.edu/~jnt/Papers/J047-93-luo-algebr.pdf (author-hosted copy, 29 pp.; page images of pp. 1022, 1026 and 1035 viewed [IMG]). Tech-report version LIDS-P-1851 (1989): https://dspace.mit.edu/entities/publication/02189982-adb7-4f17-8775-d1bca2effa4d (PDF fetch returned HTTP 429 at 10:54Z, not read).
- Two processors; P1 holds x in R^m, P2 holds y in R^n; both know the functional form of f. Two-way protocol: r(pi) = number of exchanged messages (both directions counted together). Message i from P1: m_i(x,y) = m~_{i1}(x, m_1, ..., m_{i-1}); from P2: m_i = m~_{i2}(y, m_1, ..., m_{i-1}) (eqs. 1.1-1.2).
- "Legitimate": (a) f(x,y) = h(x, m_1, ..., m_{r}) (P1 evaluates the final result) or (b) f(x,y) = h(y, m_1, ..., m_{r}) (P2 evaluates), eqs. (1.3)-(1.4). So the final output may depend on the evaluating party's FULL input and the whole transcript.
- Table I (classes): Pi_1: message functions AND final function continuously differentiable; Pi_2: twice continuously differentiable; Pi_infty: infinitely differentiable; Pi_rat: rational; then polynomial/rational, linear/polynomial. C(f;D) = min number of messages over legitimate protocols in the class that are correct on the domain D. [IMG p. 1022] The classes are nested (more restrictions as one goes down the table, "the corresponding communication complexity can only increase"): C_1 <= C_2 <= C_infty <= C_rat. So a lower bound for C_1 holds for all smaller classes, while Abelson's Thm 5.1 is a statement for C_2 and does not by itself cover protocols whose messages are only C^1.
- Quote (p. 1021): "Typically, some smoothness constraints have to be imposed on the message functions ... This is because there exist one-to-one functions from R^m into R, and processor P1 could transmit the value of its vector x by using a single message. In particular, P1 can simply interleave the binary expansions of the components of x and use the resulting number as a message." Also: "smoothness assumptions prohibit the use of one-to-one functions from R^m into R, if m > 1."
- Quote (p. 1021): "it is reasonable to count the number of real-valued messages being transmitted, as opposed to counting individual bits."
- Sec. 1.2: "The problem formulation we are using is due to Abelson [1, 2] who established lower bounds on one-way and two-way communication complexity, assuming that the message functions are once (respectively, twice) continuously differentiable."

### A2. Abelson 1978 / 1980: primary memo opened, plus Luo-Tsitsiklis restatements
OPENED (primary): H. Abelson, "Lower bounds on information transfer in distributed computations," MIT/LCS/TM-102, April 1978 [FT, IMG pp. 2-3 of the memo]: the technical memo behind the FOCS 1978 (pp. 151-158) and J. ACM 27(2):384-392 (1980), DOI 10.1145/322186.322200 papers. URL: https://dspace.mit.edu/handle/1721.1/148930 (the direct /bitstream/ URL returned HTTP 429 / the SPA shell; I fetched the PDF and the extracted-text bitstream through the DSpace REST API at 11:17-11:18Z). The memo's reference list: [1] Abelson, "Towards a theory of local and global in computation," Theoret. Comput. Sci. 6 (1978) 41-67; [2] Abelson, "Correction to: Towards a theory of local and global in computation," Theoret. Comput. Sci. (in press).
NOT opened: the J. ACM 1980 and FOCS 1978 versions (ACM DL fetch at 10:51Z: HTTP 403, Cloudflare), the TCS paper and its Correction (source of the one-way theorem). The memo may differ from the journal text in details; the journal statements are available only through LT93/LT91 [2ND] below, which agree with the memo.
Statements in the memo (all functions real-valued; "information transfer" = number of real values transmitted):
- Model (Sec. 2, p. 4): X = (x_1..x_a), Y = (y_1..y_b); multi-stage: at stage k X sends Y the values of a_k functions f^k(X, g^1, ..., g^{k-1}) and Y sends X b_k functions g^k(Y, f^1, ..., f^{k-1}) (both directions within a stage, using what was received in earlier stages); the function is output by one predetermined side at stage r as a function of its own data and what it received; total information transfer = total number of values sent. "We will assume from here on that all functions computed at each stage have continuous 1st and 2nd derivatives (C^2)." Expressed in "number of function values transmitted, rather than in terms of bits".
- Theorem 1 (one-way, p. 3, "for the proof, see [1], [2]"): "A C^1 function Phi: X x Y -> R can be represented in the form Phi(X,Y) = g(f_1(X), f_2(X), ..., f_N(X), Y) where f_i: X -> R and g: R^{N+b} -> R are C^1 functions, if and only if, given any value X_0 for X, at most N of the functions dPhi/dx_j |_{X_0} [Y -> dPhi/dx_j (X_0, Y)] are linearly independent." (Printed as a global iff; LT93 states the iff locally, (3.2) below, so read it locally.)
- Example (p. 3): Phi(X,Y) = sum_{k=1}^n y_k x_1^k + sum_{k=1}^n x_k y_1^k: the n functions dPhi/dx_k (Y) are linearly independent, so ONE-WAY (either direction) needs n values; TWO-WAY needs 3: X sends x_1, Y sends y_1, X then sends sum_k x_k y_1^k. So in the smooth model two-way protocols can beat the one-way functional dimension arbitrarily; the one-way span dimension is NOT a lower bound for two-way protocols.
- Theorem 2 (two-way, p. 5): "Let Phi: X x Y -> R be a C^2 function and let R be the rank of the matrix of second order partial derivatives [d^2 Phi / dx_i dy_j]. Then any multi-stage distributed computation of Phi must have total information transfer at least R between X and Y (assuming that the functions computed at each stage are all C^2)."
  Proof (Sec. 4, Lemma 4.1): induction over stages with the chain rule, d^2 Phi/dx_i dy_j = sum_{m=1}^{N} Gamma_{im}(X,Y) Lambda_{mj}(X,Y) with N the total transfer, so at EVERY point the |X| x |Y| matrix is a product of an |X| x N and an N x |Y| matrix and has rank <= N ("The fact that all functions involved are C^2 allows us to interchange the order of the x_i and y_j differentiations"). So the bound is pointwise (rank at any point), exact computation, no restriction on the number of stages.
  Examples: inner product (identity matrix, rank n; "maximal, in the sense that any function can be computed with information transfer equal to the number of variables in X"); determinant with X = one column; solving M z = b, Lemma 2.1: rank n-1; network corollaries (determinant > n^2/2 total transfer; matrix product; linear systems >= n(n-1)).
  Open items stated there (Sec. 6): an upper bound for two-way is missing; relating to BITS is "useful to investigate"; computations using conditional expressions (non-differentiable) are not covered.
- Luo-Tsitsiklis restate the same two results with exact hypotheses (below). Both versions agree on: exact computation, C^2 for the two-way bound, rank of the cross-derivative matrix.
- LT93 Thm 5.1 (two-way; attributed to Abelson [2] = the J. ACM paper; Sec. 5 opening: f twice continuously differentiable on the open domain D_f in R^m x R^n; footnote: proved in [2] for real-valued functions on R^{m+n}, the proof stays valid over C) [IMG p. 1035]:
  "For any open set D in D_f and any p in D, we have C_2(f; D) >= rank(H_xy(f))(p)."  (5.1)
  Def. 5.1: H_xy(f) is the m x n matrix with (i,j) entry d^2 f / dx_i dy_j. Cor. 5.1: C_2(f;D) >= max_{p in D} rank(H_xy(f))(p). Cor. 5.2 (strengthening by at most 1, proof: compose f with a C^2 g): C_2(f;D) >= max over scalars c, max_{p in D} of rank[ H_xy(f)(p) + c grad_x f(p) grad_y f(p)^T ].
  Hypotheses: the protocol must compute f EXACTLY on all of D; message functions AND final function C^2 (class Pi_2); any number of rounds; count = total messages both ways; local (every open D, any p), global form = max over p. Which matrix: only the cross second derivatives between the two parties' inputs.
  Tightness (LT93 Thm 5.2): f(x,y) = x^T Q y has C = rank Q, attained by a ONE-WAY LINEAR protocol (SVD). Weak in general: f linear in (x,y) has C = 1 but bound 0; for an entry of (x+y)^{-1} with n x n matrices Abelson gives Omega(n), while under rational protocols LT93 prove n^2 - 1 (abstract, Sec. 6).
- LT93 Thm 3.1 (one-way, P1 -> P2; "the main available result on one-way protocols is due to Abelson [1]") [IMG p. 1026]:
  "Let f: R^m x R^n -> R be an infinitely differentiable function. (a) Let D be a subset of R^m x R^n. There holds C_infty(f;D) <= r if and only if there exist infinitely differentiable functions m_1, ..., m_r: R^m -> R and h: R^{r+n} -> R such that f(x,y) = h(y, m_1(x), ..., m_r(x)) for all (x,y) in D. (b) Let (x*, y*) be some element of R^m x R^n. There exists some open set D containing (x*,y*) for which C_infty(f;D) <= r if and only if dim(span{g_{1,x*}, ..., g_{m,x*}}) <= r, where g_{i,x*}(y) = (df/dx_i)(x*, y) and the span is taken in the vector space of functions of y defined on an open set containing (x*,y*)."
  Footnote 1: stated for Pi_infty; "The result was actually proved in [1] for the class Pi_1(f;D) but the proof remains valid for Pi_infty(f;D)". Consequence (3.3): C_infty(f; R^m x R^n) >= max_{x*,y*} dim span{g_{i,x*}}. The lower bound is tight locally only; message functions need not be polynomial even if f is.
  For the lane: for smooth ONE-WAY exact protocols the local optimum IS the functional dimension of x -> f(x,.) at x* (rank of the Jacobian of the front-to-readout map), i.e. a local functional-dimension statement, not an eps-rank statement.
- LT93 rational / polynomial results (outline Sec. 1.3 and abstract read [FT]; the individual theorems of Secs. 3, 5.3, 6 were NOT read line by line): one-way polynomial case "almost optimal" (within one message) via field-extension theory; restricting to polynomial protocols "increases the communication complexity by at most one"; for f_j(x,y) = f~_j(x+y) a complete characterization, linear protocols optimal; Sec. 5.3 new two-way lower bounds for rational f with rational messages via Hilbert's Nullstellensatz; Sec. 6: an entry of (x+y)^{-1}, n x n complex matrices, lower bound n^2 - 1 under rational protocols vs Omega(n) from Abelson. Rational messages are a SUBCLASS of Pi_2 on their domain of definition, so Abelson's bound applies to them too.

### A3. Luo-Tsitsiklis 1991, SIAM J. Comput. 20(5):936-950 [FT, IMG p. 938]
"On the communication complexity of solving a polynomial equation." URL: https://web.mit.edu/jnt/www/Papers/J035-91-luo-comm-polyn.pdf
- Model: Pi_1(f; D_x x D_y) = message functions ONCE continuously differentiable and final evaluation function h merely CONTINUOUS (Abelson's Pi_2: all C^2). NOTE the naming clash: in LT93 Table I the class Pi_1 has BOTH the messages and the final function C^1; the 1991 paper's Pi_1 is the larger class with h only continuous. Quote: "As discussed in [L89], Pi_1 is, in some sense, the most general class of protocols for which the notion of communication complexity is well defined for problems involving continuous variables." Thm 1.1 = Abelson's bound (rank H_xy at any p).
- Assumption 2.1 (f C^1 on D_x x D_y, open subsets of R^m, R^n; S^(2)(y) = {S in D_x : f(S,y) contains an open interval}): (a),(b) every nonempty open S is in S^(2)(y), resp. S^(1)(x); (c) dim[grad_y f(x,y); x in S] >= n_f for all y in D_y and all S in S^(2)(y); (d) dim[grad_x f(x,y); y in S] >= m_f for all x and all S in S^(1)(x).
- Thm 2.1: "Under Assumption 2.1, C_1(f; D_x x D_y) >= min{n_f, m_f}." Exact computation, two-way, any number of messages. Application: root of sum (x_i+y_i) z^i = 0 needs >= n messages (Abelson's bound gives only Omega(1)).
- Quote (Sec. 3 remark): the only assumptions used are C^1 message functions and a continuous final function; "assumption (a) [C^1 messages] is necessary since its removal could lead to unreasonable conclusions."
- For the lane: this is the only C^1/continuous-output theorem I found; the object bounded is the span of partial gradients (a "tangent rank"), under a uniform nonconstancy hypothesis.

### A8. Continuity vs smoothness: examples
- One-way, exact, worst case: continuity of the encoder suffices for a dimension bound (B1, B2 below). [MINE, short proof: if x -> m(x) in R^r is continuous and f(x,y) = h(y, m(x)) exactly, then m is injective on the quotient of x-space by "same readout x ~ x' iff f(x,.) = f(x',.)"; invariance of domain forbids a continuous injection of an r'-manifold into R^r for r < r'.]
- Adaptive continuous measurements beat the non-adaptive Borsuk-Ulam count exponentially: Krieg, Novak, Ullrich, "How many continuous measurements are needed to learn a vector?", arXiv:2412.06468 (v2, 22 Sep 2026; Proc. AMS 2026 "to appear" per Ullrich's reference list) [FT of abstract, Sec. 1]. Abstract: "One can recover vectors from R^m with arbitrary precision, using only ceil(log2 m) + 1 continuous measurements that are chosen adaptively." Thm 1: algorithm R_m^eps uses at most n(m) = ceil(log2 m)+1 adaptive continuous measurements with ||x - R_m^eps(x)|| <= eps for all x in R^m. "If we allow n(m+1) instead of n(m) measurements, the measurements from Theorem 1 can be chosen with Lipschitz-constant at most one." Same paper: fewer than m NON-adaptive measurements are useless for linear AND for continuous ones (Borsuk-Ulam), also fewer than m adaptive linear ones.
- Matching lower bound: Ullrich, "A Borsuk-Ulam theorem for adaptive continuous measurements," arXiv:2610.33781 (v1, 24 Oct 2026) [FT of abstract, Sec. 1, refs; proof not checked]. Model: lambda_1 in C(F); for k >= 2 "an arbitrary (no regularity assumed) assignment (y_1..y_{k-1}) -> lambda_k^{(y_1..y_{k-1})} in C(F)"; reconstruction Phi arbitrary; worst-case error. Thm 1: "if 2^n <= m, then there is x in S_R^m with N(x) = N(-x)" (any norm). Cor. 2: ceil(log2(m+1)) <= n*(m,eps) <= ceil(log2 m)+1 for 0 < eps < R on the ball of radius R. WARNING: a one-week-old preprint, unrefereed; the author states the main proof idea "was found by Claude Fable 5, an AI model developed by Anthropic" (Sec. 5 documents it). Treat as unverified.
  Reading for the lane: the real-valued analogue of "rank <= 2^b" is exactly this: n adaptive continuous scalars resolve at most about 2^n dimensions. This happens ONLY because later measurements depend irregularly on earlier answers; LT's Pi_1/Pi_2 classes require m~_i to be C^1/C^2 in (own input, previous messages) jointly, which kills the collapse (that is the role of the smoothness hypothesis on the whole map, not just on x).

### A9. What section A gives for "s real numbers with a regular decoder"
- Exact, smooth (C^2), two-way (any number of rounds): s >= max_p rank of the mixed Hessian of the mean-output map G(w_front, w_back) in the two parameter vectors (Abelson Thm 2); this is <= min(p_front, p_back), so it can never exceed the parameter count. One-way smooth exact, local: s = dim span{ dG/dw_front,i (w*, .) } as functions of w_back (Abelson Thm 1 / LT93 Thm 3.1(b)). For BOUNDED BACK-AND-FORTH smooth protocols the right lower bound is the mixed-Hessian rank, not the one-way span: the span can exceed two-way cost arbitrarily (Abelson's n-vs-3 example).
- Nothing in A covers eps-approximate or mean-square error.

## B. Nonlinear widths

### B1. DeVore-Howard-Micchelli 1989 [FT, IMG pp. 469-476 of the print]
"Optimal nonlinear approximation." Manuscripta Math. 63(4):469-478. Opened via the Gottingen digitization: https://gdz.sub.uni-goettingen.de/id/PPN365956996_0063 (IIIF page images gdz:PPN365956996_0063:00000471...; viewed printed pp. 469-476; pp. 477-478 not viewed). Metadata: https://eudml.org/doc/155392.
- Definition (pp. 469-470). X Banach; M_n is ANY "mapping from R^n into X" (no continuity of M_n assumed); a map a-bar: K -> R^n is a "continuous selection" if continuous in the topology of some quasi-norm (on compact K all quasi-norms are equivalent). (1.3) E(K, a-bar, M_n)_X := sup_{f in K} ||f - M_n(a-bar(f))||. (1.4) "d_n(K)_X := inf over a-bar, M_n of E(K, a-bar, M_n)_X, the continuous nonlinear n-width of K." So in the ORIGINAL definition only the encoder (selection) is required to be continuous; later papers (Siegel, DeVore-Hanin-Petrova, CDPW) require both a_n and M_n continuous, which is not needed for the lower bound.
- (3.1) Bernstein width b_n(K)_X := sup over (n+1)-dim subspaces X_{n+1} of sup{rho : rho U(X_{n+1}) in K} (U = unit ball).
- Thm 3.1 (p. 473): "Let X be a normed linear space and let K in X. Then d_n(K)_X >= b_n(K)_X. (3.2) If X is a quasi-normed linear space then d_n(K)_X >= c_0 b_n(K)_X. (3.3)"
  Proof (p. 474): take rho < b_n, X_{n+1} with rho U(X_{n+1}) in K; for ANY manifold M_n and any continuous selection a-bar put a~(f) = a-bar(f) - a-bar(-f), a continuous odd map of the boundary sphere of rho U(X_{n+1}) into R^n; by Borsuk's antipodality theorem there is f_0 with a-bar(-f_0) = a-bar(f_0); then 2||f_0|| <= ||f_0 - M_n(a-bar(f_0))|| + ||-f_0 - M_n(a-bar(-f_0))||, so one of +-f_0 has error >= ||f_0|| = rho.
  => Needs continuity of the ENCODER only; decoder arbitrary; K must contain a symmetric (n+1)-dim ball (odd sphere); worst-case (sup) error; any norm.
- Thm 4.2 (p. 475): "Let X = L_q, 1 <= q <= infty. If K_{p,r} := {f : |f|_{W_p^r} <= 1}, 1 <= p <= q, r = 1,..., then d_n(K_{p,r})_X >= C n^{-r/d}. (4.5)" and for Besov balls K_{p,sigma,alpha} (alpha > 0, 0 < p, sigma <= infty, p <= q): d_n >= C n^{-alpha/d} (4.6). "The constants C depend only on r." (d = dimension of the unit cube Omega.) Proof: Lemma 4.1 (disjointly supported bumps) + Thm 3.1.
- Thm 5.1 (p. 476): for d = 1, d_n(K_{p,r}) ~ n^{-r}, via free-knot splines with a continuous selection (upper bound needs care).

Suppose that there is a continuous map M: F_{d,n} -> R^W such that ||f - eta(M(f))||_infty <= eps for all f in F_{d,n}. Then W >= c eps^{-d/n}." (F_{d,n} = unit ball of W^{n,infty}.) ### B4. Average-case versions [FT of definitions; nothing found beyond]
- Bensalah, Nouy, Soffo, "Nonlinear manifold approximation using compositional polynomial networks," arXiv:2502.05088 (v3, 19 Nov 2025), Sec. 1-2 [FT]. URL: https://arxiv.org/pdf/2502.05088. - Searched (search tool, summaries only, [ABS]): average/probabilistic LINEAR and Kolmogorov widths under Gaussian measures exist (Maiorov; Fang-Ye, J. Complexity 19 (2003) 73-84; arXiv:1603.04578; MDPI Axioms 12 (2023) 698 and 13 (2024) 492). - [MINE] Continuity alone gives NO mean-square lower bound, even for s = 1 and BOTH maps continuous. Let nu be a Borel probability measure on R^n with finite second moment (standard measure theory; the Borel isomorphism theorem, Lusin and Tietze were not opened). Take a Borel isomorphism phi: R^n -> R (zero-error encoder, Borel decoder). Lusin: a compact F inside {|x| <= R} with nu(F^c) < delta and phi|_F continuous; phi|_F is injective on a compact set, hence a homeomorphism onto the compact set phi(F), so its inverse is continuous there. Extend both phi|_F and its inverse by Tietze to continuous maps a: R^n -> R and D: R -> R^n (D with values in the ball of radius R). Error is 0 on F and <= 2 integral_{F^c} |x|^2 d nu + 2 R^2 nu(F^c) elsewhere, which -> 0 as delta -> 0 and R -> infinity. So "continuous (or C^infty, since continuous maps can be smoothed) summary, mean-square" is vacuous, exactly as "continuous, worst case" is not; Lipschitz constants must be fixed (here they -> infinity as delta -> 0). This is the average-case reason CDPW needs gamma.
- [MINE] The Carl-type argument transfers only with a confidence level: a gamma-Lipschitz (a, M) with mean-square error eps gives, by Markov, error <= eps/sqrt(delta) outside a set of measure delta; so CDPW's covering step bounds the entropy of the measure at confidence 1 - delta (a "(1-delta)-entropy" / quantization number), not the worst-case entropy. Not checked against Graf-Luschgy quantization theory (not opened).

## C. Embedding theorems that cap continuous summaries

### C1. Menger-Nobeling [2ND, verified on the page image]
Source opened: Gutman, Levin, Meyerovitch, "Equivariant embedding of finite-dimensional dynamical systems," arXiv:2305.17717 (v4, 2 Jul 2024), p. 1 [IMG]: "According to the classical Menger-Nobeling theorem, a compact metric space X of (Lebesgue covering) dimension less than r/2 admits a topological embedding into [0,1]^r (see [HW41, Theorem 5.2])." With r = 2m+1: covering dimension <= m => embeds in [0,1]^{2m+1} (my substitution). Original: Hurewicz-Wallman, Dimension Theory (1941) [UNV]; a search result names it Theorem V.2 (not opened).
Consequence [MINE]: any compact metric family of covering dimension m admits a continuous injective encoder into R^{2m+1}; the inverse on the compact image is continuous, so exact continuous summaries with a continuous decoder never need more than 2m+1 numbers; with Borsuk-Ulam (B1) the continuous, exact, worst-case count lies between m and 2m+1 when the family is an m-manifold. No Lipschitz/Holder control in Menger-Nobeling.

### C2. Sauer-Yorke-Casdagli 1991 [ABS]
"Embedology," J. Stat. Phys. 65:579-616, DOI 10.1007/BF01053745. ### C3. Hunt-Kaloshin 1999 and Robinson 2009 [2ND, formula verified on the page image]
Hunt, B. R.; Kaloshin, V. Y. "Regularity of embeddings of infinite-dimensional fractal sets into finite-dimensional spaces." Nonlinearity 12 (1999) 1263-1275. Primary (IOP) NOT opened. Statement as quoted in Margaris-Robinson, "Embedding properties of sets with finite box-counting dimension," arXiv:1811.03872 (v2, 10 Apr 2019), Thm 1.3 [FT of Sec. 1, IMG p. 3], https://arxiv.org/pdf/1811.03872:
  "Let X be a compact subset of a real Hilbert space H with thickness exponent tau(X) and box-counting dimension d_B(X) < infty. Then for any integer k > 2 d_B(X) and any given theta with 0 < theta < (k - 2 d_B(X)) / ( k (1 + tau(X)/2) ), mu-almost every linear map L: H -> R^k satisfies ||x - y|| <= C_L |Lx - Ly|^theta for all x,y in X, for some C_L > 0. In particular every such L is bijective from X onto L(X) with a Holder continuous inverse."
  Definitions (same paper): upper box dimension d_B(X) = limsup log N(X,eps)/(-log eps); thickness exponent tau(X,B) = limsup log d(X,eps)/(-log eps), d(X,eps) = smallest dimension of a linear subspace within distance eps of X; tau <= d_B.
  "mu-almost every" = a probability measure mu on a class of linear maps (Hunt-Kaloshin "probe"); prevalence, Ott-Hunt-Kaloshin Def. 2.1 [FT]: a Borel set S in a Banach space B is prevalent if there is a measure mu on B with 0 < mu(C) < infty for some compact C and S - x has full mu-measure for every x in B; prevalent sets are dense and closed under countable intersection. URL: http://terpconnect.umd.edu/~bhunt/research/eopofs.pdf (W. Ott, B. Hunt, V. Kaloshin, "The effect of projections on fractal sets and measures in Banach spaces", draft dated 16 Dec 2003, "in press" on Hunt's page; Hunt-Sauer-Yorke 1992 original at ams.org returned HTTP 403, [UNV]).
- Banach spaces: Margaris-Robinson p. 3: the original Banach-space claim of Hunt-Kaloshin relied on a linear isometry from the dual of any finite-dim subspace into the dual of B, "However, Kakutani [4] proved that this can only be true in the context of a Hilbert space." Fix: Robinson 2009 (Nonlinearity 22:711-728; [2ND]) Thm 1.5: X compact in a Banach space B with dual thickness tau*(X) < infty and d_B(X) < infty: for integer k > 2 d_B and 0 < theta < (k - 2 d_B)/(k (1 + tau*(X))), mu-a.e. linear L: B -> R^k satisfies ||x-y|| <= C_L |Lx-Ly|^theta; and (Margaris-Robinson Sec. 4) tau* <= 2 d_B, giving every theta < 1/(1 + 2 d_B(X)) for k large. Ott-Hunt-Kaloshin's own Thm 1.3 (quoting HK99; their alpha < (m-2d)/(m(1+tau(X))), "C |f(x)-f(y)|^alpha >= |x-y|", prevalent bounded linear, C^1 or Lipschitz f) states the Banach version with 1+tau(X) in the denominator and says the factor improves to 1+tau(X)/2 in Hilbert space; per Margaris-Robinson the Banach-space argument of HK99 rests on a claim that is false outside Hilbert spaces, so use the Hilbert statement or Robinson's.
- For the lane (Hilbert case, e.g. L^2 of the back law): a family of front readouts with box dimension <= d admits an EXACT summary by k = 2d+1 generic linear functionals with a Holder decoder, exponent theta < 1/((2d+1)(1+tau/2)) at k = 2d+1 (it tends to 1/(1+tau/2) as k grows). Note k = 2d+1 > d: generic LINEAR sketches of a d-dimensional family need about twice the dimension (a closed d-manifold does not embed in R^d), while an adapted nonlinear encoder (the parameters) needs d.

### C4. ReLU-network parametrization: finite dimension, Lipschitz in weights
- Petersen, Raslan, Voigtlaender, "Topological properties of the set of functions generated by neural networks of fixed size," arXiv:1806.08459 (dated 24 Jan 2020) [FT of Sec. 4, App. C]. URL: https://arxiv.org/pdf/1806.08459.
  Prop. 4.1: "Let Omega in R^d be compact and let S = (d,N_1,...,N_L) be a neural network architecture. If the activation function rho is continuous, then the realization map R_rho^Omega is continuous. If rho is locally Lipschitz continuous, then so is R_rho^Omega. Finally, if rho is globally Lipschitz continuous, then there is a constant C = C(rho,S) > 0 such that Lip(R_rho^Omega(Phi)) <= C ||Phi||_scaling^L for all Phi in NN(S)." (target norm: sup norm on C(Omega; R^{N_L}); NN(S) includes biases.)
  Lemma C.2: for rho locally Lipschitz, Lambda: C(Omega; R^{N_L}) -> R^M locally Lipschitz (uniform norm), if M > sum_{l=1}^L (N_{l-1}+1) N_l then Lambda(RNN(S)) has Lebesgue measure zero in R^M. I.e. no locally Lipschitz map from function space can carry the realization set onto an open subset of R^M with M above the parameter count.
  Thm 4.2 / Cor. 4.3 (inverse INSTABILITY): for Lipschitz non-affine rho, L >= 2, N_1 >= 3, Omega bounded with interior, there are networks Phi_n with R(Phi_n) -> 0 uniformly and Lip(R(Phi_n)) -> infinity, and for every sequence Psi_n with R(Psi_n) = R(Phi_n) one has ||Psi_n||_scaling -> infinity; so the realization map is not a quotient map: functions can converge while all their weight preimages blow up.
- Grigsby, Lindsey, Meyerhoff, Wu, "Functional dimension of feedforward ReLU neural networks," arXiv:2209.04036 [FT of abstract, Thm 7.1, Cor. 7.2]. URL: https://arxiv.org/pdf/2209.04036.
  Thm 7.1: "For any ordinary parameter theta in P_{n_0,...,n_m}, dim_fun(theta) <= n_m + sum_{i=0}^{m-1} n_i n_{i+1}." Proof: positive diagonal rescalings of hidden layers commute with ReLU, a group of dimension sum_{i=1}^{m-1} n_i acts with generically trivial stabilizers; rank-nullity. Cor. 7.2: dim P - dim_fun P >= n_1 + ... + n_{m-1}. Parameter dimension there is D = sum (n_i + 1) n_{i+1}, so the bound is D minus the number of hidden units. Statement is for architectures WITH biases.
- [MINE] bias-free critical nets (the lane's ensemble): the same positive-scaling argument removes sum of hidden widths from the weight count W = sum n_i n_{i+1}; GLMW do not state it for bias-free. Permutation symmetry is discrete and removes nothing. Forward Lipschitz on Gaussian input: a bias-free ReLU net is positively homogeneous of degree 1 in x, so |f_W(x) - f_W'(x)| <= ||x|| sup_{|u|=1}|f_W(u) - f_W'(u)| <= ||x|| Lip_loc ||W - W'|| (PRV Prop. 4.1 with Omega = the unit sphere), hence the mean output E_x f_W(x) is locally Lipschitz in W with constant ~ E||x|| Lip_loc.
- [MINE] covering numbers: the image of a weight ball of radius R under a map that is L-Lipschitz on it has N(image, eps) <= (3 R L/eps)^W, so upper box dimension <= W; whether the box dimension of the image equals the maximal local functional dimension (W minus hidden widths) is not established by any source I opened; then C3 applies in a Hilbert target with d_B <= W.

## D. Bit communication and approximate real-valued functions

### D1. Lee-Shraibman Thm 4.3 (Krause 1996): exact model and statement [FT]
Lee, T.; Shraibman, A. "Lower bounds in communication complexity." Found. Trends TCS 3(4) (2009). URL: https://www.cs.toronto.edu/~toni/Courses/CommComplexity/Papers/adi-book.pdf (re-opened 10:52Z; Def. 2.1 p. 14, Sec. 4 pp. 42-46).
- Def. 2.1 (deterministic protocol): "a binary tree T with internal nodes labeled either by a function a_v: X -> {0,1} or b_v: Y -> {0,1}, and leaves labeled by elements from {T,F}... A protocol correctly computes a function f if for every input (x,y) the path defined by (x,y) in T arrives at a leaf labeled by f(x,y). The cost ... number of edges in a longest path." So the OUTPUT IS THE LEAF LABEL: a function of the transcript only; it is NOT allowed to depend on a party's private input beyond what the transcript reveals. "As the height of this tree is c, it has at most 2^c many leaves" (Sec. 2).
- Private-coin protocol (Sec. 4): internal nodes labeled a_v: X x R -> {0,1} or b_v: Y x R -> {0,1}; "Alice and Bob flip coins as they go"; leaves labeled in {0,1}; error: probability the path arrives at a leaf labeled f(x,y) is >= 1 - eps; cost = height.
- Def. 4.1: rank^alpha(A) = min rank(B) over B with 1 <= A[i,j] B[i,j] <= alpha, A a sign matrix.
- Thm 4.3 (Krause [Kra96]): "Let A be a sign matrix and 0 <= eps < 1/2. Then R^pri_eps(A) >= log rank^alpha(A) where alpha = 1/(1-2 eps)."
  Proof (p. 46): P[x,y] = Pr[protocol outputs 1]; "On input x,y ... the probability that the protocol arrives at leaf l and outputs 1 as the product Pr[a_{v1}(x,r)=s_1] Pr[b_{v2}(y,r)=s_2] ... which we write as U_l(x) V_l(y). Then P[x,y] = sum_l U_l(x) V_l(y)... both U and V have at most 2^c many columns and P = U V^t. This demonstrates that rank(P) <= 2^c." Number of rounds plays no role (arbitrary tree; they assume strict alternation only "for notational simplicity").
  Cor. 4.1 (via Newman): A a 2^n x 2^n sign matrix, eps, delta with eps + delta < 1/2, alpha = (1 - 2 eps - 2 delta)^{-1}: R_eps(A) >= log rank^alpha(A) - O(log n - log delta) (public coin). Thm 4.2 (Newman): R^pri_{eps+delta}(f) <= R_eps(f) + O(log n - log delta). Example p. 43-44: Equality has public-coin cost Theta(1) and private-coin cost Theta(log n), with Newman tight.
- Krause's original (TCS 156 (1996) 99-117; metadata from dblp via the search tool) NOT opened [UNV]; the leaf decomposition above is the proof in Lee-Shraibman.
- Answer to "does the printed statement allow the final output to depend on one party's full input?" NO. The extension is a one-line change [MINE]: if leaf l prescribes Bob's output g_l(y) (or a randomized g_l(y, r_B)), then E[Z | x,y] = sum_l U_l(x) V'_l(y) with V'_l(y) = E_{r_B}[1{Bob's coins consistent with l} g_l(y, r_B)]; rank <= #leaves <= 2^b. (The transcript probability factorizes across the parties, and given the transcript Bob's posterior over his coins depends only on (y, l).) For Boolean functions Bob can append the answer, one extra bit; for real-valued outputs the extension above is the right statement. The final output may also be produced by Alice symmetrically.

### D2. Mean-square, real-valued [MINE; no source found]
No source I opened states a rank- or discrepancy-based bound for approximating a REAL-valued function in mean square by a bounded-bit protocol. Derivation from D1: let Z = output of a (possibly randomized, public- or private-coin) protocol with worst-case total length b, M the target, (x,y) drawn from a product measure.
 (i) Jensen: E|M - Z|^2 >= E|M - E[Z | x,y]|^2, and E[Z | x,y] is a matrix/kernel of rank <= 2^b (private coins; D1).
 (ii) Public coins: E_{x,y,R}|M - Z|^2 <= eps^2 implies some fixed R has E_{x,y}|M - Z_R|^2 <= eps^2 (averaging; distributional/Yao form), and Z_R is a deterministic protocol, so rank <= 2^b again. No Newman loss because the criterion is an average over a known input law, not worst case in (x,y).
 (iii) Hence b >= log2( min{ s : sum_{i>s} sigma_i^2 <= eps^2 } ), sigma_i the singular values of the cut operator in L^2(mu_x x mu_y) (Eckart-Young/Schmidt for the best rank-s fit; product measure needed only here).
 Caveats: "b" must be a WORST-CASE bound on transcript length (leaf count <= 2^b); an average-length bound does not bound the leaf count. The bound is exponentially lossy (log of rank).

The protocol is described in Shi, Zhu, "Tensor norms and the classical communication complexity of nonlocal quantum measurement," arXiv:quant-ph/0511071 [FT of that paragraph, [2ND] for KNR]: if ||psi_A||, ||psi_B|| <= C, send the norms to O(1/C) precision (O(log C) bits), then estimate cos(theta) to precision O(1/C^2) using Goemans-Williamson random hyperplanes, Prob[sign<psi,psi_A> != sign<psi,psi_B>] = theta/pi; "gives a protocol that accomplishes the latter task using O(C^4) bits" (the full count printed, garbled in my extraction, is of the form C^4 ln(1/eps)/eps^2). Shared randomness, one round (their SMP/one-way setting). Sherstov (earlier notes) gives the VC-dimension form for sign matrices under product distributions [2ND].
- Chakrabarti, Regev, "An optimal lower bound on the communication complexity of Gap-Hamming-Distance," arXiv:1009.3460 (v3, 29 Jun 2012) [FT of abstract, Sec. 1-2, Sec. 4.2 remark]. URL: https://arxiv.org/pdf/1009.3460. GHD_{n,t,g}: x,y in {0,1}^n; output 0 if Delta(x,y) <= t - g, 1 if Delta > t + g (free otherwise). Thm 1.1 (informal): "If a randomized protocol solves GHD, then it must communicate a total of Omega(n) bits." Thm 2.6 (formal): R(GHD_{n, n/2, sqrt n}) = Omega(n), R = R_{1/3}, cost = worst-case bits, ANY number of rounds ("settles this conjecture fully"; earlier results were deterministic or round-limited). Thm 2.7: D_{xi_0, eps}(GHD_{n,n/2,sqrt n}) = Omega(n) for an absolute constant eps > 0 under the UNIFORM input distribution.
  Sec. 4.2 remark (GAP-INNER-PRODUCT): "Alice and Bob have d-dimensional unit vectors x,y as inputs and are trying to distinguish between the cases <x,y> >= eps and <x,y> <= -eps. There is a simple O(1/eps^2) protocol for this problem: the players use shared randomness to choose O(1/eps^2) random hyperplanes and then compare which side of each hyperplane their inputs lie in. Our main theorem implies that this is tight assuming d >= 1/eps^2, as can be seen by embedding the hypercube in the set {-1/sqrt n, 1/sqrt n}^n."
  Translation [MINE]: estimating <x,y> for typical random unit vectors to within about its own standard deviation (eps ~ 1/sqrt n) already costs Omega(n) bits for ANY number of rounds; the rank bound of D2 gives only log2 n there. Constant relative error only; no statement for relative error -> 0.

### D4. For the lane
- "b bits, any rounds, output = function of own input and transcript" => rank <= 2^b (D1, D2): TRUE for deterministic/private-coin, and for any coin model under an average criterion with fixed law (D2), with b worst-case length.
- It is a weak bound; C-R (D3) show the true bit cost of the inner-product problem at noise-level accuracy is Omega(n) against log2 n from rank.

## E. Gromov's waist inequality

### E1. Statements [FT of the cited passages]
- Gromov, M. "Isoperimetry of waists and concentration of maps." GAFA 13 (2003) 178-215 (Erratum GAFA 18 (2009), per search tool). URL (author site, opened 10:52Z): https://www.ihes.fr/~gromov/wp-content/uploads/2018/08/waists.pdf.
  Sec. 1, "Waist of the Sphere Theorem": "Let f: S^n -> R^k be a continuous map where S^n is the unit n-sphere. Then there exists a point z in R^k such that the spherical n-volumes of the epsilon-neighbours of the level Y_z = f^{-1}(z) in S^n, denoted Y_z + epsilon, satisfy Vol(Y_z + epsilon) >= Vol(S^{n-k} + epsilon) for all epsilon > 0, where S^{n-k} in S^n denotes an equatorial (n-k)-sphere. This is proven in Sec. 5.9." Remarks: (a) k = n with fibres of at most 2 points at epsilon = pi/2 is Borsuk-Ulam; (b) k = 1: Levy mean + spherical isoperimetric inequality; (c) epsilon -> 0 gives Minkowski (n-k)-volume of the level >= that of the equator. [Proof in Sec. 5.9 not read.]
  Sec. 3.1, "Log-waist theorem (see Sec. 5.8)": X convex in R^n with a log-concave probability measure => wst(X -> R^k, epsilon) >= wst_.(Ga^k, epsilon) = integral over B(0,epsilon) of g^k(x) dx; "If n >= k then the inequality is sharp: for example, the equality is achieved for linear maps Ga^n -> R^k." (Ga^n = standard Gaussian.)
- Gaussian version as stated in Akopyan, Karasev, "Gromov's waist of non-radial Gaussian measures and radial non-Gaussian measures," arXiv:1808.07350 (v4, 26 Dec 2019) [FT of intro]: "Gromov proved the waist of the Gaussian measure theorem: For any continuous map f: R^n -> R^k and a radially symmetric Gaussian measure gamma, it is possible to find a fiber f^{-1}(y) such that for any t > 0: gamma(f^{-1}(y) + t) >= gamma(R^{n-k} + t), where X + t denotes the t-neighborhood of a set X and R^{n-k} in R^n denotes any (n-k)-dimensional linear subspace." Their Thm 1.1: for gamma with density exp(-a_1^2 x_1^2 - ... - a_n^2 x_n^2), a_1 >= ... >= a_n > 0, any continuous f: R^n -> R^k has y with gamma(f^{-1}(y) + t) >= gamma(R^{n-k} + t) for all t > 0, R^{n-k} = coordinate subspace of the FIRST n-k coordinates (the largest a_i, i.e. smallest variances); general non-degenerate Gaussians follow by translation and diagonalization. Thm 3.2 and the sentence in the abstract: no such precise t-neighborhood waist theorem for compactly supported radial measures and 2 <= k < n (a counterexample for the uniform measure on a high-dimensional ball is cited from their [3, Remark 5.7]).
- Memarian, "On Gromov's waist of the sphere theorem," arXiv:0911.3972 (v1, 20 Nov 2009), Thm 1 [FT]: same statement as Gromov's sphere theorem ("k <= n ... for every epsilon > 0 vol_n(f^{-1}(z)+epsilon) >= vol_n(S^{n-k}+epsilon)"). Journal not checked.
- Akopyan, Karasev, "A tight estimate for the waist of the ball," arXiv:1608.06279 (v2, 9 Oct 2016), Thm 1 [FT]: for the unit ball B^n and continuous f: B^n -> R^k some fibre has (n-k)-dimensional lower Minkowski content >= vol_{n-k}(B^{n-k}); tight for linear f. (Minkowski-content version only.)
- Not read: Akopyan-Hubard-Karasev, "Lower and upper bounds for the waists of different spaces," arXiv:1612.06926 (downloaded, unread); Klartag 2017; Guth's survey.

### E2. What it gives [MINE sketch; constants unchecked; hypotheses explicit]
Continuity alone gives only ONE large fibre, and nothing about the encoder's values on the fibre's neighbourhood; a mean-square lower bound needs a Lipschitz transfer. Let gamma = N(0, I_n) (or a non-degenerate Gaussian after diagonalization), a: R^n -> R^s with Lipschitz constant L_a, decoder D: R^s -> R^n with Lipschitz constant L_D, Gamma = L_a L_D. Take y from the waist theorem. For x in a^{-1}(y) + t: |a(x) - y| <= L_a t so |D(a(x)) - D(y)| <= Gamma t, hence |x - D(a(x))| >= |x - D(y)| - Gamma t. Take t_0 = median of chi_s ~ sqrt(s): gamma(a^{-1}(y) + t_0) >= P(chi_s <= t_0) >= 1/2. By Anderson's inequality the ball B(D(y), sqrt(n)/2) has gamma-mass <= P(chi^2_n <= n/4) <= exp(-0.31 n). If Gamma sqrt(s) <= sqrt(n)/4 then mean-square error >= (sqrt(n)/4)^2 (1/2 - e^{-0.31 n}) ~ n/32, a constant fraction of the total variance n. So: mean-square error below a constant fraction of the variance requires s >= c n / Gamma^2 for an isotropic Gaussian. Matches rescaling invariance (only Gamma matters; CDPW Remark 1.1). It is far from the PCA/SVD value (n - s) and uses one fibre only. For non-Gaussian fronts the exact form can fail (Akopyan-Karasev Thm 3.2); one would need a Minkowski-content or other version.

## (iii) Checks against the lane's intended claims

### Claim 1: "with locally Lipschitz decoders, a summary of p real numbers that is the parameter vector itself is exact, so regular nonlinear one-way summaries never need more numbers than the parameter count"
Verdict: survives as an UPPER bound; nothing I opened contradicts it. Five hypotheses the sources force you to state:
1. Which metric makes the summary "regular". The identity map on weights is 1-Lipschitz as a function of the WEIGHTS. The CDPW notion of stable (B3) asks the encoder to be Lipschitz in the metric of the ELEMENT being summarized. PRV Thm 4.2 / Cor. 4.3 (C4) show weights -> function is not inverse-stable (functions converge while all weight preimages blow up), so the parameter vector is in general NOT a Lipschitz (or even continuous) function of the readout function (PRV state this with biases, L >= 2, N_1 >= 3; the bias-free case was not checked, though the positive-scaling symmetry already makes weight norms uncontrolled by the function). If the lane's regularity is in the weight metric the claim holds; if it is in the function metric it can fail, and the answer is then governed by the entropy of the function family (smaller than that of the weights).
2. "Locally Lipschitz" is not enough for any lower bound, and not enough for the CDPW constants. PRV Prop. 4.1: Lip <= C ||Phi||_scaling^L for globally Lipschitz rho, so the decoder's constant grows polynomially with the weight norm; Gaussian weights are unbounded, so any CDPW-type statement must truncate to a ball (K compact) or state constants. [MINE] on Gaussian inputs the mean output is locally Lipschitz in W by positive homogeneity (C4).
3. The count p can be reduced: local functional dimension <= p - (sum of hidden widths) (GLMW Thm 7.1, stated with biases; bias-free adaptation [MINE]). So "never more than the parameter count" is correct but not tight. Any LOCAL exact smooth lower bound (Abelson one-way, LT93 Thm 3.1(b); mixed-Hessian rank <= min(p_front, p_back), A9) is bounded by those counts. For a GLOBAL exact smooth summary the upper bound p always holds, and p - (sum of hidden widths) should hold after normalizing the incoming rows of the hidden units on the open set where they are nonzero [MINE, unchecked]; I did not find a global lower-bound statement.
4. Generic LINEAR sketches of the readout function need about 2 d + 1 (Hunt-Kaloshin, C3), not d; the claim is about the adapted encoder (the weights), not about linear sketches.
5. Exactness vs epsilon: this is an exact-reproduction statement; for eps > 0 a regular summary can use far fewer numbers than p, and the lane's linear-readout eps-rank may be larger or smaller than p (no contradiction: linear readout is a restricted class; the parameter-vector decoder is nonlinear).
Not in conflict: DHM Thm 3.1 / Siegel Prop. 1 give worst-case LOWER bounds of the form "n >= dimension of an odd sphere in the family"; they sit below p.

### Claim 2: "any-round protocols exchanging b bits in total, where the back outputs any function of its own input and the transcript, give a rank <= 2^b linear protocol"
Verdict: correct under the stated reading; the literature statement as printed does NOT include the "back outputs a function of its own input" clause, the extension is [MINE] (D1) and is immediate. Conditions:
1. "b bits in total" = worst-case transcript length, i.e. at most 2^b leaves (LS Sec. 2: height c => at most 2^c leaves). An average-length budget (average communication) does not bound the leaf count.
2. Randomized: the object that has rank <= 2^b is the EXPECTED output E[Z | x, y] under PRIVATE coins (LS proof, with the extension of D1). Under public coins the mixture over coins can have larger rank (Equality: public Theta(1) vs private Theta(log n), LS pp. 43-44; Newman O(log n) loss, LS Thm 4.2). For the lane's MEAN-SQUARE criterion with a fixed input law, fix the coins by averaging (D2) so there is no loss; for a worst-case-in-(x,y) criterion there is.
3. The linear protocol is x -> (U_l(x))_l in R^{2^b}, readout with V'_l(y); it is a rank-2^b factorization of the expected output; the mean-square approximation guarantee follows by Jensen (D2(i)); the optimal such rank-s fit is the SVD tail only for a PRODUCT measure on (x,y) (earlier notes, D1 caveat on non-product weights).
4. Lossy: b >= log2 rank only. Chakrabarti-Regev (D3) show Omega(n) bits for gap-inner-product at noise-level accuracy where rank gives log2 n; do not present the rank bound as the bit complexity.
5. Real-valued analogue exists and matches in form: n adaptive continuous scalars resolve at most about 2^n dimensions (Ullrich Thm 1, KNU Thm 1), but only because later scalars may depend irregularly on earlier ones; with jointly smooth dependence (LT/Abelson classes) the bound is the plain Hessian rank. A "regular decoder with s numbers" claim must say whether adaptivity is allowed and how regular it is.

### Additional warnings that bear on the lane's planned statements
- Continuity alone: vacuous in mean square (B4, Lusin) and collapsing with irregular adaptivity (A8); only worst-case one-way continuity (B1, B2) gives clean dimension bounds. A regularity hypothesis for any mean-square theorem must be a Lipschitz constant (or modulus) stated quantitatively.
- The Borsuk-Ulam / Bernstein route needs a symmetric (odd-sphere) subfamily; the lane's family of front readouts is not obviously symmetric. Without it the relevant tools are Urysohn-width/waist versions, which I did not open.
- Abelson-type theorems are exact-computation theorems: no source gives an epsilon-approximate smooth-protocol lower bound; the bilinear case is settled only through Eckart-Young (SVD tail), which is the lane's existing result.
- Gromov's waist: exact t-neighbourhood form holds for any non-degenerate Gaussian but fails for some radial compactly supported measures; do not apply it to the lane's non-Gaussian front law without a separate check.
