# Narrow-deep networks: verified literature map
Compiled 2026-10-29 (UTC 21:48-22:20). Read-only literature check; this is the only file written. Counts (77 paper bullets): 65 VERIFIED, 4 CORRECTED, 3 bibliographic-only (claim not checked), 5 VERIFIED with an UNVERIFIED sub-detail (venue or width).
Status key: VERIFIED = authors/year/venue/id and the stated claim matched the arXiv abs page, a proceedings/publisher record, or the paper text (noted). CORRECTED = a recollection was wrong in a detail (correct statement given). UNVERIFIED = could not check (reason given).
Method: arXiv API/abs pages for authors, ids, abstracts, comments; full-text checks on arXiv PDFs (text extracted with Ghostscript); venues from proceedings.mlr.press, proceedings.neurips.cc, PDF headers, Crossref, Numdam. openreview.net returned 403 to fetches, so ICLR venues come from PDF headers or citing papers where noted. Source shorthand in bullets: "arXiv abs" = https://arxiv.org/abs/<id given in the bullet>; "PDF" = https://arxiv.org/pdf/<id>; PMLR pages are named by slug (proceedings.mlr.press/<slug>.html).
Notation: n = width, L = depth, d_x / d_y = input / output dimension.

## Corrections to the recollection list
- Hanin-Sellke: min width is exactly d_in+1 for scalar output; d_in+d_out is the upper bound for vector output (lower bound d_in+1).
- Beise et al.: second author is Steve Dias Da Cruz (not "Da Cruz").
- De-Smith (NeurIPS 2020): the paper is titled "Batch normalization biases residual blocks towards the identity function in deep networks"; SkipInit is the proposed init, not the title.
- Hayou et al. Stable ResNet: the general condition is sum_l lambda_{l,L}^2 bounded as L->inf; uniform lambda=1/sqrt(L) is one example, square-summable decreasing scalings are the other.
- Pennington-Schoenholz-Ganguli (NeurIPS 2017) is "Resurrecting the sigmoid in deep learning through dynamical isometry: theory and practice"; its finding is that ReLU nets cannot reach dynamical isometry (tanh/sigmoid with orthogonal init can).
- Johnson: arXiv:1810.00393; the theorem is "no level set has a bounded path component" (not just "level sets unbounded"); ICLR 2019 venue not confirmed on a primary page.
- Lu et al. 2017: "Lebesgue-integrable / L1" is Theorem 1 in the body, not in the arXiv abstract; Theorem 2 gives the width<=n dichotomy (L1 error is +inf or ||f||_1).
- Roberts-Yaida-Hanin: the abstract says the aspect ratio "controls the deviations" from the Gaussian limit; the words "expansion parameter" are not in the abstract.
- ReZero: 10,000 fully connected layers were trained only to overfit the CIFAR-10 training set; the width of that run is not stated (the 32-layer comparison uses width 256).
- Xiao et al.: channels are 256 (depth<=256) and 128 (deeper), so not narrow. Schoenholz et al.: width 300 is stated only for the depth-240 gradient test; the trainability sweeps (depth 10-300) give no width in the text.
- AlgZoo: 2nd-argmax grid is hidden in {2,3,4,5,6,8,16,32} x length in {2,3,4,5,6,8,10}; the blog's M_{16,10} (432 params) has 95.3% accuracy.

## 1. Minimal width, universality, depth separation, learnability
- Lu, Pu, Wang, Hu, Wang (2017). The expressive power of neural networks: a view from the width. NeurIPS 30 (NIPS 2017). arXiv:1709.02540. VERIFIED (2026-10-29, arxiv.org/abs/1709.02540 + PDF Thms 1-3, header "NIPS 2017"). Claim: Thm 1: any Lebesgue-integrable f:R^n->R is L1-approximable by a fully connected ReLU net of width <= n+4; Thm 2: with width <= n and f of positive-measure support, the L1 error is +inf or ||f||_1 (no approximation); Thm 3: width <= n-1 cannot approximate (within a fixed eps*) a continuous f on [-1,1]^n that is non-constant along every direction.
- Hanin, Sellke (2017). Approximating continuous functions by ReLU nets of minimal width. arXiv:1710.11278 (preprint, no venue on page). VERIFIED (2026-10-29, arxiv.org/abs/1710.11278). Claim: ReLU nets of width exactly d_in+1 approximate any continuous f:[0,1]^{d_in}->R (width <= d_in cannot); for vector output width d_in+d_out suffices, so min width in [d_in+1, d_in+d_out].
- Hanin (2019). Universal function approximation by deep neural nets with bounded width and ReLU activations. Mathematics 7(10):992. arXiv:1708.02691; doi:10.3390/math7100992. VERIFIED (2026-10-29, arxiv abs + Crossref). Claim: width d+1 ReLU nets approximate any continuous convex function of d variables; this gives quantitative depth bounds for any continuous scalar function on [0,1]^d with width d+3.
- Johnson (2019). Deep, skinny neural networks are not universal approximators. ICLR 2019. arXiv:1810.00393. VERIFIED for content (2026-10-29, arxiv.org/abs/1810.00393 + PDF Thm 1); venue UNVERIFIED at primary page (OpenReview 403; forum id ryGgSsAcFQ and ICLR 2019 are cited by Park et al. and Kidger-Lyons). Claim: for n>=2 and uniformly continuous activation approximable by one-to-one maps, layered nets with input dim n and every hidden layer width <= n cannot approximate any scalar function with a level set containing a bounded path component, independent of depth.
- Kidger, Lyons (2020). Universal approximation with deep narrow networks. COLT 2020, PMLR 125:2306-2327. arXiv:1905.08539. VERIFIED (2026-10-29, proceedings.mlr.press/v125/kidger20a.html + arXiv abs). Claim: arbitrary-depth nets of width n+m+2 are dense in C(K;R^m) for any nonaffine continuous activation with a nonzero continuous derivative at some point (includes polynomials); width n+m+1 suffices for "most" activations (Park et al. Table 1: n+m+1 for continuous nonpolynomial, n+m+2 for nonaffine polynomial).
- Park, Yun, Lee, Shin (2021). Minimum width for universal approximation. ICLR 2021. arXiv:2006.08859. VERIFIED (2026-10-29, arXiv abs + PDF Table 1/Thms 1-3; ICLR 2021 per the reference list of Cai 2023, arXiv page has no venue). Claim: ReLU nets of width w are dense in L^p(R^{d_x},R^{d_y}) iff w >= max{d_x+1, d_y}; uniform approximation differs (C([0,1],R^2) needs w=3 > max{d_x+1,d_y}=2); ReLU+STEP restores max{d_x+1,d_y} for C(K,R^{d_y}). Table 1 also lists Lu et al. d_x+1 <= w_min <= d_x+4 (L1(R^{d_x},R)).
- Cai (2023). Achieve the minimum width of neural networks for universal approximation. ICLR 2023. arXiv:2209.11395. VERIFIED (2026-10-29, arXiv abs + PDF header "ICLR 2023" + Table 1). Claim: for arbitrary activations w_min >= max(d_x,d_y) on compact K (L^p and C); leaky-ReLU nets achieve exactly max(d_x,d_y,2) for L^p(K) (Thm 2), i.e. max(d_x,d_y) once max(d_x,d_y)>=2; leaky-ReLU+ABS gives max(d_x,d_y) (Thm 3); proof uses neural-ODE flow maps.
- Kim, Min, Park (2024). Minimum width for universal approximation using ReLU networks on compact domain. ICLR 2024. arXiv:2309.10402. VERIFIED (2026-10-29, arXiv abs + PDF header "ICLR 2024"). Claim: for L^p([0,1]^{d_x},R^{d_y}) the min width is exactly max{d_x,d_y,2} for ReLU-like activations (ReLU, GELU, Softplus), smaller than max{d_x+1,d_y} on R^{d_x}; for uniform approximation w_min >= d_y+1 when d_x < d_y <= 2d_x.
- Yang, Zhou, Zhou (2025). Minimum width of deep narrow networks for universal approximation. arXiv:2511.06837 (preprint). VERIFIED (2026-10-29, arxiv.org/abs/2511.06837). Claim: w_min <= max(2d_x+1,d_y) also for ELU/SELU; d_x+1 <= w_min <= d_x+d_y for LeakyReLU, ELU, CELU, SELU, Softplus; new proof of w_min >= d_y + 1[d_x<d_y<=2d_x] for injective activations.
- Vardi, Yehudai, Shamir (2022). Width is less important than depth in ReLU neural networks. COLT 2022, PMLR 178:1249-1281. arXiv:2202.03841. VERIFIED (2026-10-29, proceedings.mlr.press/v178/vardi22a.html + arXiv abs). Claim: any ReLU net on R^d can be approximated by a net of width O(d) with only a linear-factor parameter increase (open question of Lu et al.); also width <= d+2 with a polynomial overhead; the reverse (shallow emulating deep) is impossible by depth separation.
- Telgarsky (2016). Benefits of depth in neural networks. COLT 2016, PMLR 49:1517-1539. arXiv:1602.04485. VERIFIED (2026-10-29, proceedings.mlr.press/v49/telgarsky16.html + PDF Thm 1.1). Claim: for every k there is a ReLU net with 2k^3+8 layers, 3k^3+12 nodes total and 4+d distinct parameters (width ~2-3) that no net of (t,alpha,beta)-semi-algebraic gates (includes ReLU) with <= k layers and <= 2^k/(t alpha beta) nodes approximates within L1 distance 1/64 on [0,1]^d (boosted trees: 2^{k^3} nodes needed).
- Eldan, Shamir (2016). The power of depth for feedforward neural networks. COLT 2016, PMLR 49:907-940. arXiv:1512.03965. VERIFIED (2026-10-29, arXiv abs). Claim: a radial-type function expressible by a small 3-layer net cannot be approximated to constant accuracy by any 2-layer net unless the width is exponential in d.
- Malach, Yehudai, Shalev-Shwartz, Shamir (2021). The connection between approximation, depth separation and learnability in neural networks. COLT 2021. arXiv:2102.00434. VERIFIED (2026-10-29, arXiv abs + PDF Sec 1). Claim: weak approximability by shallow nets is necessary for gradient-descent learnability by deep nets; as a corollary Telgarsky's triangle (sawtooth) function, which narrow deep nets represent exactly, cannot be learned by gradient descent (they define "not weakly learnable" for polynomially many steps and polynomial learning rate; initialization assumption as in the paper).
- Malach, Shalev-Shwartz (2019). Is deeper better only when shallow is good? NeurIPS 32 (papers.nips.cc/paper/8871, pp 6426-6435). arXiv:1903.03488. VERIFIED (2026-10-29, arXiv abs; NeurIPS venue via papers.nips.cc search record). Claim: fractal-structured distributions are expressible by deep but not shallow nets; gradient-based training fails when mass sits on the fine details, and for such families deep learning succeeds only if shallower nets already approximate.
- Lin, Jegelka (2018). ResNet with one-neuron hidden layers is a universal approximator. NeurIPS 31 (proceedings.neurips.cc/paper/2018/hash/03bfc1d4783966c69cc6aef8247e0103). arXiv:1806.10909. VERIFIED (2026-10-29, arXiv abs + PDF Sec 2). Claim: a deep ResNet whose residual blocks have a single ReLU hidden neuron (layers alternate width 1 and d) approximates any Lebesgue-integrable f on R^d in l1; in a trained 2-D unit-disk task width-2 MLPs (1-5 hidden layers) fail while the one-neuron ResNet (>=2 hidden layers) learns the bounded region.
- Nguyen, Mukkamala, Hein (2018). Neural networks should be wide enough to learn disconnected decision regions. ICML 2018, PMLR 80:3740-3749. arXiv:1803.00094. VERIFIED (2026-10-29, proceedings.mlr.press/v80/nguyen18b.html). Claim: nets with no hidden layer wider than the input dim d (pyramidal, leaky-ReLU-like activations) have connected decision regions, so disconnected regions need a hidden layer > d (v3 extends to non-pyramidal nets and ReLU).
- Beise, Dias Da Cruz, Schroder (2021). On decision regions of narrow deep neural networks. Neural Networks 140:121-129; doi:10.1016/j.neunet.2021.02.024. arXiv:1807.01194. CORRECTED (author name) / VERIFIED (2026-10-29, arXiv abs + Crossref). Claim: for width <= input dim every connected component of every decision region is unbounded (continuous strictly monotone activations and ReLU).
- Zhang, Gao, Unterman, Arodz (2020). Approximation capabilities of neural ODEs and invertible residual networks. ICML 2020, PMLR 119:11086-11095. arXiv:1907.12998. VERIFIED (2026-10-29, proceedings.mlr.press/v119/zhang20h.html). Claim: Neural ODEs/i-ResNets with state dim p are limited, but any homeomorphism of R^p is approximated by a Neural ODE on R^{2p}. Dupont, Doucet, Teh (2019), Augmented Neural ODEs, NeurIPS 32, arXiv:1904.01681, VERIFIED (arXiv abs + PDF header): Neural ODEs preserve input topology so some functions are unrepresentable; augmenting dimensions fixes it.
- Park, Lee, Yun, Shin (2021). Provable memorization via deep neural networks using sub-linear parameters. COLT 2021, PMLR 134:3627-3661. arXiv:2010.13363. VERIFIED (2026-10-29, proceedings.mlr.press/v134/park21a.html). Claim: O(N^{2/3}) parameters memorize N pairs under a separation condition; deeper nets, even of width 3, memorize more pairs than shallow ones.
- Dommel, Wegner (2025). An in-depth look at approximation via deep and narrow neural networks. arXiv:2510.07202 (11 pp, preprint). VERIFIED (2026-10-29, arXiv abs + PDF Sec 5). Claim: trains width n and n+1 ReLU nets (n = input dim, widths 2-6, depth up to 20) on the Hanin-Sellke counterexample; error improves with depth at first, then dying neurons collapse nets to constant functions.

## 2. Trainability at initialization and in training
- Hanin, Rolnick (2018). How to start training: the effect of initialization and architecture. NeurIPS 31 (NIPS 2018). arXiv:1803.01719. VERIFIED (2026-10-29, arXiv abs + PDF Thm 3/Cor 2, header "NIPS 2018"). Claim: FM1 (mean squared activation length explodes/vanishes) is avoided by weight variance 2/fan-in (truncated He-normal in Keras/PyTorch has too little variance and decays); FM2: for fully connected ReLU nets E[Var of squared activation lengths over layers] is exponential in beta = sum_j 1/n_j (c e^{c beta} <= E <= C e^{C beta}, beta=(d-1)/n for constant width); ResNets never hit FM2 once FM1 is avoided; MNIST (SGD lr 0.01, batch 1024, <=100 epochs) epochs-to-20%-test-accuracy are predicted by sum 1/n_j for widths 15, 20 and 30/10 mixes.
- Hanin (2018). Which neural net architectures give rise to exploding and vanishing gradients? NeurIPS 31 (NIPS 2018). arXiv:1801.03744. VERIFIED (2026-10-29, arXiv abs + PDF Thm 1, header "NIPS 2018"). Claim: for fully connected ReLU nets at init the variance of input-output Jacobian entries is exponential in beta = sum_{j} 1/n_j; the exploding/vanishing-gradient problem occurs iff beta is large; for a fixed neuron or parameter budget constant width is best.
- Hanin, Nica (2020). Products of many large random matrices and gradients in deep neural networks. Commun. Math. Phys. 376(1):287-322; doi:10.1007/s00220-019-03624-z; arXiv:1812.05994. VERIFIED (2026-10-29, arXiv abs + PDF Thm 1 + Crossref). Claim: for a product M of d random matrices (ReLU Jacobian = Bernoulli p=1/2) (n_0/n_d)||M u||^2 ~ exp(N(-beta/2, beta)), i.e. log-normal, with beta = (3/p-1) sum_i 1/n_i + (mu_4-3)/(p n_1) ||u||_4^4 (= 5 sum 1/n_i for Gaussian weights, p=1/2); KS error O((sum 1/n_i^2)^{1/5}); so fluctuations are set by depth/width.
- Hanin, Nica (2020). Finite depth and width corrections to the neural tangent kernel. ICLR 2020. arXiv:1909.05989. VERIFIED (2026-10-29, arXiv abs; ICLR 2020 poster page iclr.cc/virtual_2020/poster_SJgndT4KwB.html via search). Claim: for random ReLU nets the NTK standard deviation and the mean of its first SGD update grow exponentially in depth/width, so the NTK stays random and evolves when depth and width scale together.
- Roberts, Yaida, Hanin (2022). The principles of deep learning theory. Cambridge Univ. Press; arXiv:2106.10165; doi:10.1017/9781009023405. VERIFIED (2026-10-29, arxiv.org/abs/2106.10165). Claim: output distributions are nearly Gaussian with the depth-to-width aspect ratio controlling deviations from the infinite-width limit; the ratio sets effective model complexity; residual connections can push the useful aspect ratio to arbitrary depth.
- Lu, Shin, Su, Karniadakis (2020). Dying ReLU and initialization: theory and numerical examples. Commun. Comput. Phys. 28(5):1671-1706; doi:10.4208/cicp.OA-2020-0165; arXiv:1903.06733. VERIFIED (2026-10-29, arXiv abs + PDF Sec 3 + Crossref). Claim: Thm 3.1: at fixed width N, P(net is constant at init, "born dead") -> 1 as L->inf (if each neuron has probability >= p>0 of all-negative incoming weights and a negative bias; symmetric init gives p=2^{-N-1}); Thm 3.2 (symmetric init): P(BD) <= 1 - prod_l (1 - 2^{-N_l}); Cor 3.5: width N = log2(L/delta) keeps P(BD) <= delta (max safe depth grows exponentially in width); Thm 3.4: a born-dead net is trained to a constant by any gradient method; numerics: a 10-layer net of width 10 dies with probability <1%, width 5 >10%, width 3 about 60% (text accompanying Fig 3), Fig 2 is d_in=1, bias-free, symmetric init, 10^6 runs per estimate, widths 2-5 and 10, depth to 20; randomized asymmetric initialization fixes it.
  - My arithmetic from Thm 3.2 (upper bounds, symmetric init): L=64: width 16 <=0.1%, width 12 <=1.5%, width 10 <=6%, width 8 <=22%, width 6 <=63%, width 4 <=98%; L=128: width 16 <=0.19%, width 8 <=39%.
- Shin, Karniadakis (2020). Trainability of ReLU networks and data-dependent initialization. J. Mach. Learn. Model. Comput. 1(1):39-74; doi:10.1615/JMachLearnModelComput.2020034126; arXiv:1907.09696. VERIFIED (2026-10-29, arXiv abs + Begell record via search). Claim: trainability (probability that few neurons are permanently dead) is necessary for successful training and upper-bounds success rates; over-parameterization is necessary and sufficient for minimizing training loss; proposes a data-dependent initialization.
- Jakub, Nica (2024). Depth degeneracy in neural networks: vanishing angles in fully connected ReLU networks on initialization. JMLR 25(239):1-45. arXiv:2302.09712. VERIFIED (2026-10-29, JMLR PDF read, jmlr.org/papers/v25/23-0350.html). Claim: Approximation 1 (angle theta_l << 1, width n_l >> 1): ln sin^2(theta_{l+1}) ~ ln sin^2(theta_l) - (2/(3 pi)) theta_l - rho(n_l), rho(n) = ln((n+5)/(n-1)) - 10n/(n+5)^2 + 6n/(n-1)^2 = 2/n + O(n^-2); hence theta_l <= exp(-(1/2) sum_i rho(n_i)) = exp(-sum_i (1/n_i + O(n_i^-2))): exponential decay with e-fold depth ~ n, versus theta_l ~ 1/l in the infinite-width limit (rho=0). Regime: iid Gaussian weights at the edge of chaos (He init), no skips/norms; Theorem 1 (mean/variance of ln sin^2 theta_{l+1}) is rigorous as n->inf with O(n^-2) error; Monte Carlo checks only at n=256 (5000 nets, 30 layers, Fig 1) and n=1024 (Fig 2); also var(ln sin^2 theta_{l+1}) ~ 8/n per layer; Fig 3 / Algorithm 1 applies mu(theta,n) layer by layer to 45 MLPs (2-50 hidden layers, average width 10-200; Tables 7-10), trained 1 epoch (Adam, Keras defaults, 10 runs): smaller predicted final angle correlates with lower test accuracy; per-network accuracies are in Tables 7-8 (see Sec 5).
  - Extrapolation, my arithmetic, NOT in the paper: asymptotic bound exp(-L/n) gives 1.8% of the initial angle at n=16, L=64 and 1e-7 at L=256; the literal rho(16)=0.40 (vs 2/n=0.125) shows the n>>1 expansion is not reliable at n<=16 (rho(8)=1.1, rho(4)=3.3).
- Li, Nica, Roy (2022). The neural covariance SDE: shaped infinite depth-and-width networks at initialization. NeurIPS 35. arXiv:2206.02768. VERIFIED (2026-10-29, arXiv abs + PDF Sec 2-3). Claim: with depth-dependent activation shaping the penultimate-layer covariance converges (d,n->inf, d/n fixed) to an SDE; the unshaped (p=0) ReLU limit is degenerate (correlation 1), so shaping is necessary for non-degenerate covariance at large depth.
- Poole, Lahiri, Raghu, Sohl-Dickstein, Ganguli (2016). Exponential expressivity in deep neural networks through transient chaos. NeurIPS 29. arXiv:1606.05340. VERIFIED (2026-10-29, arXiv abs; NeurIPS 2016 per the Jakub-Nica reference list URL). Claim: order-to-chaos transition; in the chaotic phase curvature of computed functions grows exponentially with depth (not width), and such random deep functions cannot be computed efficiently by shallow nets.
- Schoenholz, Gilmer, Ganguli, Sohl-Dickstein (2017). Deep information propagation. ICLR 2017. arXiv:1611.01232. VERIFIED (2026-10-29, arXiv abs + PDF header "ICLR 2017"). Claim: depth scales xi bound the trainable depth (trainable when L is within a few xi_c), arbitrarily deep nets only near the edge of chaos; tanh gradient test at L=240, width 300; sweeps depth 10-300 on MNIST/CIFAR-10 reach 100% train accuracy (width not stated in text).
- Pennington, Schoenholz, Ganguli (2017). Resurrecting the sigmoid in deep learning through dynamical isometry: theory and practice. NeurIPS 30. arXiv:1711.04735. CORRECTED (title) / VERIFIED (2026-10-29, arXiv abs + PDF header "NIPS 2017"). Claim: free-probability computation of the Jacobian spectrum; ReLU nets cannot achieve dynamical isometry, orthogonally initialized sigmoidal nets can.
- Xiao, Bahri, Sohl-Dickstein, Schoenholz, Pennington (2018). Dynamical isometry and a mean field theory of CNNs: how to train 10,000-layer vanilla convolutional neural networks. ICML 2018, PMLR 80:5393-5402. arXiv:1806.05393. VERIFIED (2026-10-29, proceedings.mlr.press/v80/xiao18a.html + PDF Sec 3.4). Claim: delta-orthogonal init trains vanilla tanh CNNs of 1,250-10,000 layers; 99% MNIST and 82% CIFAR-10 test accuracy at 10,000 layers; channels c=256 (depth<=256) or 128.
- Daneshmand, Kohler, Bach, Hofmann, Lucchi (2020). Batch normalization provably avoids rank collapse for randomly initialised deep networks. NeurIPS 33, pp 18387-18398 (proceedings.neurips.cc/paper/2020/hash/d5ade38a2c9f6f073d69e1bc6b6e64c1). arXiv:2003.01652. VERIFIED (2026-10-29, arXiv abs + PDF Sec 1.2). Claim: without normalization the rank of hidden representations collapses with depth (Fig 1: Fashion-MNIST MLPs of depth 1-32, width 128; vanilla nets are essentially unable to learn beyond ~10 layers in the limited epochs); BN keeps rank >= Omega(sqrt(d)) (d = width) for deep linear nets at any depth.
- Feng, Zheng, Huang, Zhao, Jordan, Zha (2022). Rank diminishing in deep neural networks. NeurIPS 35, pp 33054-33065. arXiv:2206.06072. VERIFIED (2026-10-29, arXiv abs; NeurIPS 2022 via proceedings.neurips.cc search record). Claim: network rank is monotonically non-increasing with depth (composition rules); layerwise rank measured on ResNets, deep MLPs, Transformers.
- Yang, Pennington, Rao, Sohl-Dickstein, Schoenholz (2019). A mean field theory of batch normalization. ICLR 2019. arXiv:1902.08129. VERIFIED (2026-10-29, arXiv abs + PDF header "ICLR 2019"). Claim: in fully connected BN nets gradients explode exponentially with depth regardless of init variance/activation, so vanilla BN nets without skips are untrainable at large depth.
- Martens et al. (2021). Rapid training of deep neural networks without skip connections or normalization layers using Deep Kernel Shaping. arXiv:2110.01765 (preprint). VERIFIED (2026-10-29, arXiv abs). Claim: shaping the initialization-time kernel (init, activation transform, small tweaks) enables SGD training of residual nets without normalization on ImageNet/CIFAR-10 at ResNetV2/WRN speeds.
- Hayou, Doucet, Rousseau (2019). On the impact of the activation function on deep neural networks training. ICML 2019, PMLR 97:2672-2680. VERIFIED venue only (2026-10-29, proceedings.mlr.press/v97/hayou19a.html); claim not read (cited by Jakub-Nica for the infinite-width 1/l angle decay at the edge of chaos).
- Avelin, Karlsson (2022). Deep limits and a cut-off phenomenon for neural networks. JMLR 23(191):1-29. arXiv:2104.10727 (arXiv title: "Deep limits and cut-off phenomena for neural networks"). VERIFIED (2026-10-29, jmlr.org/papers/v23/21-0431.html + PDF Figs 1-2). Claim: random layer maps + non-commutative ergodic theorems give deep limits; simulations of width-1 and width-2 tanh nets (W~U(+-1/sqrt N)) show a cut-off in total-variation distance to the point mass at 0 after ~9 and ~11 layers; seen for swish, not for ReLU.
- Shamir (2019). Exponential convergence time of gradient descent for one-dimensional deep linear neural networks. COLT 2019, PMLR 99:2691-2713. arXiv:1809.08587. VERIFIED (2026-10-29, proceedings.mlr.press/v99/shamir19a.html). Claim: for f(prod_{i=1}^k w_i) (a width-1 depth-k linear net) with standard random init, gradient descent needs iterations exponential in k (experiments k=2..8; also for matrices).
- Du, Hu (2019). Width provably matters in optimization for deep linear neural networks. ICML 2019, PMLR 97:1655-1664. arXiv:1901.08572. VERIFIED (2026-10-29, proceedings.mlr.press/v97/du19a.html + arXiv abs). Claim: for an L-layer fully connected linear net with every hidden width >= O~(L r d_out kappa^3) (r, kappa = rank and condition number of the data) GD from Gaussian init converges linearly to a global minimum; together with Shamir's exp(Omega(L)) lower bound for narrow nets, wide layers are necessary in plain deep nets.
- Zou, Long, Gu (2020). On the global convergence of training deep linear ResNets. ICLR 2020. arXiv:2003.01094. VERIFIED (2026-10-29, arXiv abs, comment "In ICLR 2020"). Claim: GD/SGD converge for L-hidden-layer linear ResNets with a width condition sharper than Du-Hu by O(kappa L); with modified identity input/output maps a (d+k)-wide net (d, k = input/output dims) suffices for global convergence, independent of depth.
- Allen-Zhu, Li, Song (2019). A convergence theory for deep learning via over-parameterization. ICML 2019, PMLR 97:242-252. arXiv:1811.03962. VERIFIED (2026-10-29, proceedings.mlr.press/v97/allen-zhu19a.html). Claim: SGD reaches global minima in polynomial time when the width is polynomial in both depth L and sample size n (NTK-like regime); narrow-deep nets lie outside this theory.
- Hardt, Ma (2017). Identity matters in deep learning. ICLR 2017. arXiv:1611.04231. VERIFIED (2026-10-29, arXiv abs, comment "ICLR 2017"). Claim: arbitrarily deep linear residual networks have no spurious local optima; ReLU residual nets have universal finite-sample expressivity once parameters exceed the sample size; a plain all-conv residual net without BN improves on earlier all-conv nets on CIFAR-10/100 and ImageNet.
- Saxe, McClelland, Ganguli (2014). Exact solutions to the nonlinear dynamics of learning in deep linear neural networks. ICLR 2014 (arXiv comment "Submission to ICLR2014"; proceedings page not checked). arXiv:1312.6120. VERIFIED for content (2026-10-29, arXiv abs). Claim: for a special class of initial conditions very deep linear nets incur only a finite, depth-independent learning delay; scaled random Gaussian initializations cannot.

## 3. Residual, normalized and infinite-depth limits

## 6. Not found / open
- No paper found that trains a plain (no skip/gate) MLP with width <= 16 and depth >= 64 end-to-end by SGD to non-trivial accuracy on a real task (searched arXiv/web: "deep narrow", width 8, depth 100, MNIST). Nearest: Highway width 50 x 100 layers (loss only); Hanin-Rolnick widths 15-20 (early training only); Jakub-Nica widths 10-15 x <=30 layers (1 epoch).
- Jakub-Nica angle formula: Monte Carlo agreement is shown only at n=256 and n=1024; at widths 10-200 and depth <= 50 it is used (Algorithm 1) as a screening statistic whose correlation with 1-epoch test accuracy is plotted; no Monte Carlo check of the predicted angle at n <= 16 or L >= 64 found.
- No result found for plain narrow ReLU MLPs combining exact rates with n <= 16: the only quantitative narrow results are Hanin (beta = sum 1/n_j), Hanin-Nica (beta = 5 sum 1/n_i), Lu et al. (born-dead bounds) and Jakub-Nica (asymptotic in n).
- No narrow-deep PINN study with n <= 16, L >= 64 found; the nearest, the original PINN (8 hidden layers x 20 neurons, 3021 params), is quoted second-hand in arXiv:2602.08515 (UNVERIFIED primary).
- No trained (learned-from-scratch) narrow-deep sorting/comparator network found; only fixed-topology relaxed sorting networks (Petersen et al.).
- No successful gradient-descent learning of Telgarsky-type sawtooth targets found; Malach et al. (2021) prove it is not weakly learnable by gradient descent (under their definition), even though narrow deep nets represent it exactly.
