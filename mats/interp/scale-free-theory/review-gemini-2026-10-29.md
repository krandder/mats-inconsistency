### 1. Mathematical Errors and Missing Hypotheses in `PROVEN` / `PROVEN UNDER` Claims

**1.1 [High] T2b: Inverse-Wishart query predictive does not require a $T|S|$ volume-law message when $T \ll |S|$, nor full $E_S$ when $T \ge |S|$**
- **Text at issue (Sec. 5.1, T2b; also Table 5.9 and Sec. 6.3 M7):** *"Two error histories $E_S \ne E'_S$ give different cross blocks for some completion $E_{S^c}$, so the exact message is the whole history $E_S$: $T|S|$ numbers, a volume law in both $T$ and $|S|$... PROVEN UNDER the Gaussian model (exact posterior of Sigma; for the predictive of the query, generically)."*
- **Error:**
  1. The factor $\mathcal{N}(e_t; 0, \Sigma)$ directly couples items $e_{t,S}$ and $e_{t,S^c}$ across the cut, violating T2's assumed conditional-independence factorization $p(x,u) = \prod_c \psi_c(u_c)\prod_i p(x_i \mid u_{L(i)})$.
  2. For the **posterior predictive of the query $y^*$** (where $\Sigma$ is marginalized out at the root) under an exchangeable Inverse-Wishart prior $\Sigma \sim \mathcal{IW}(\nu_0, \alpha I_N)$ (or any diagonal scale matrix $\Psi_0 = \text{diag}(\Psi_S, \Psi_{S^c})$), let $\tilde{E}_S(y^*) = [E_S, o_{\text{query},S} - y^* 1_S]^T \in \mathbb{R}^{(T+1)\times |S|}$. By Sylvester's determinant identity ($\det(I_N + A^T A) = \det(I_{T+1} + A A^T)$),
     $$p(E, o_{\text{query}} \mid y^*) \propto \det\!\left(\Psi_0 + \tilde{E}(y^*)^T \tilde{E}(y^*)\right)^{-\frac{\nu_0+T+1}{2}} \propto \det\!\left(I_{T+1} + \tilde{E}_S(y^*)\Psi_S^{-1}\tilde{E}_S(y^*)^T + \tilde{E}_{S^c}(y^*)\Psi_{S^c}^{-1}\tilde{E}_{S^c}(y^*)^T\right)^{-\frac{\nu_0+T+1}{2}}.$$
     The cross-block $E_S^T E_{S^c}$ disappears completely: the exact sufficient statistic of cut $S$ for $p(y^* \mid E, o_{\text{query}})$ is the $(T+2)\times(T+2)$ Gram matrix of $[E_S, o_{\text{query},S}, 1_S]$ weighted by $\Psi_S^{-1}$, which has $\binom{T+3}{2} = O(T^2)$ numbers (**independent of $|S|$**, an area law in $|S|$ when $T \ll |S|$) and merges **additively** across trader cuts. Even when $T \ge |S|$, any two histories $E_S, E'_S$ in the same $O(|S|-1)$-orbit fixing $(o_{\text{query},S}, 1_S)$ are Nerode-equivalent for every completion $E_{S^c}$, reducing the dimension by $\binom{|S|-1}{2}$.
- **Fix:** Restrict the $T|S|$ volume-law claim to estimating the full $N \times N$ covariance $\Sigma$ itself (or to non-block-diagonal prior scale matrices $\Psi_0$ coupling $S$ and $S^c$), and state that for the query predictive under diagonal/isotropic $\Psi_0$, the exact message size across a trader cut is $\min\!\big(T|S| - \binom{|S|-1}{2},\, \binom{T+3}{2}\big) = O(T\min(T,|S|))$.

**1.2 [High] T4: Conflation of log-posterior error rate with KL rate, plus three missing hypotheses**
- **Text at issue (Sec. 5.3, T4):** *"C(D + p, p) numbers, with log-posterior error about $N (\log N / N)^{(p+1)/2}$, which vanishes for $p \ge 2$. PROVEN UNDER local asymptotic normality, $p + 1$ bounded derivatives near the truth, and a root-$N$ pilot from finitely many moments... At fixed size the two-round error falls steeply with $N$ (theory: about $N^{(1-p)/2}$ up to logs)"*
- **Error:**
  1. **Rate error for KL:** A uniform log-posterior perturbation $\Delta L(\theta) = \tilde{O}(N^{(1-p)/2})$ on the local posterior support yields KL divergence $\text{KL}(p \| \tilde{p}) = \frac{1}{2}\text{Var}_p(\Delta L)(1 + o(1)) = \tilde{O}(N^{1-p})$, the **square** of $N^{(1-p)/2}$. This is why the measured N1c table at $p=4$ (`3 + 5 = 8` numbers) drops by $\sim 4^3 = 64\times$ per $4\times$ increase in $N$ ($N^{-3} = N^{1-p}$), not $4^{1.5} = 8\times$ ($N^{(1-p)/2}$).
  2. **Missing truncation & global identifiability:** LAN is purely local; without (i) a global identifiability / Bernstein–von Mises condition ensuring posterior mass outside the $\sqrt{(\log N)/N}$ window is $o(1)$, and (ii) explicit truncation of the reconstructed density outside the window, a degree-$p$ Taylor polynomial for odd $p$ (or non-negative leading even derivative) diverges to $+\infty$ as $\|\theta - \hat{\theta}\| \to \infty$, making the approximate posterior unnormalizable ($\text{KL} = \infty$).
  3. **Insufficient pilot hypothesis:** "$\sqrt{N}$-consistent pilot" means $|\hat{\theta} - \theta_0| = O_P(N^{-1/2})$, which does not guarantee $\theta_0$ lies inside a window of radius $C\sqrt{(\log N)/N}$ with probability $1 - o(1)$; the pilot requires sub-Gaussian / moderate-deviation concentration of order $\sqrt{(\log N)/N}$, and the bound holds with high probability over the data, not worst-case.
  4. **Message count:** Total communication over two rounds is $m_{\text{pilot}} + \binom{D+p}{p} - 1$ (including round-1 pilot moments and dropping the constant term), not $\binom{D+p}{p}$.
- **Fix:** Add global posterior concentration, window truncation at the root, and moderate-deviation concentration of the pilot to the hypotheses; qualify the bound as holding with high probability; change the theoretical KL scaling from $\tilde{O}(N^{(1-p)/2})$ to $\tilde{O}(N^{1-p})$.

**1.3 [High] T1 (with tolerance): Substitution argument fails for external $\epsilon$-nets**
- **Text at issue (Sec. 2, D1, T1):** *"With tolerance (PROVEN): quantising each node's class to an epsilon-net in sup norm gives $e_v \le e_a + e_b + \epsilon$ (same substitution argument), so the root error is at most $(2N - 1) \epsilon$; covering numbers at $\epsilon = \delta / 2N$ replace $K$."*
- **Error:** The substitution step $|f(x_a, x_b, z) - f(\hat{x}_a, \hat{x}_b, z)| \le |f(x_a, x_b, z) - f(\hat{x}_a, x_b, z)| + |f(\hat{x}_a, x_b, z) - f(\hat{x}_a, \hat{x}_b, z)| \le e_a + e_b$ requires that the quantized representatives $\hat{x}_a \in \mathcal{X}_{S_a}$ and $\hat{x}_b \in \mathcal{X}_{S_b}$ are **realisable sub-inputs** (an *internal* $\epsilon$-net of $\{f(x_{S_v}, \cdot)\} \subset \ell_\infty(\mathcal{X}_{S_v^c})$). If messages are quantized to an arbitrary *external* $\epsilon$-net in the function space $\ell_\infty(\mathcal{X}_{S_v^c})$, $f(\hat{x}_a, \hat{x}_b, z)$ is undefined because no merge rule exists for arbitrary perturbed functions $g_a(x_b, z)$ and $g_b(x_a, z)$ when $x_a, x_b$ are unknown; converting an external $\epsilon$-cover to an internal one doubles the radius to $2\epsilon$ at each node. Also, leaves and the root do not require slice-function quantization (or if all $2N-1$ nodes are quantized, $\epsilon = \delta/(2N-1)$).
- **Fix:** Specify **internal** $\epsilon$-covering numbers (representatives chosen as actual sub-inputs $\hat{x}_{S_v} \in \mathcal{X}_{S_v}$), or replace $\epsilon$ by $2\epsilon$ per internal node for external covering numbers.

**1.4 [Medium] D3 & Sec. 4: Confusion between item-cut rank $M_S[x_S, x_{S^c}]$, parameter-cut rank $M_S[x_S, \theta]$, and open-latent count $o(s)$**
- **Text at issue (Sec. 2, D3 & Sec. 4):** *"The rank of the matricisation $M_S[x_S, x_{S^c}] = F(x)$ across each cut, for $F$ a function, a log-likelihood, or a probability table... an exponential-family log-likelihood has rank $d + 1$ in log space and infinite rank as a likelihood (PROVEN)."* And Sec. 4: *"The smallest number of latent states that makes the two sides of a cut independent is the nonnegative rank of the joint law across the cut, so the profile is a property of the law, not of a chosen parametrisation (PROVEN)."*
- **Error:**
  1. In D3, $M_S[x_S, x_{S^c}]$ is the matricisation across the **item cut** $(S, S^c)$. For fixed $\theta$ and independent items, $\log p(x_S, x_{S^c} \mid \theta) = \log p(x_S \mid \theta) + \log p(x_{S^c} \mid \theta)$ has rank **2** in log space and rank **1** as a likelihood; for the marginal $p(x_S, x_{S^c}) = \int p(x_S\mid\theta)p(x_{S^c}\mid\theta)d\pi(\theta)$, $\log p(x_S, x_{S^c})$ does **not** have rank $d+1$ in log space. The statement "rank $d+1$ in log space and infinite rank as a likelihood" actually refers to the kernel $M[x_S, \theta] = \log p(x_S \mid \theta)$ across $(x_S, \theta)$—where the log-space rank is $d+2$ (due to Both the base measure $\log h(x_S)$ and log-partition $-|S|A(\theta)$, unless $h \equiv 1$), and the likelihood rank is **finite** whenever $\mathcal{X}_S$ or $\Theta$ is finite ("a probability table").
  2. In Sec. 4, the open-latent profile $o(s)$ counts the **number of open latent variables** in a global factor graph, whereas $\operatorname{rank}_+ P(X_S, X_{S^c})$ counts the **number of discrete latent states** ($q^{o(s)}$ for $q$-ary latents, or $\infty$ for continuous latents like $y^* \in \mathbb{R}$) factoring a single cut $S$ in isolation (which need not be realizable by a single consistent joint latent model across all cuts simultaneously).
- **Fix:** Distinguish the item-cut matrix $M_S[x_S, x_{S^c}]$ from the parameter-message kernel $M[x_S, \theta]$ (rank $\le d+2$ in log space; infinite rank as likelihood only for continuous non-degenerate families), and in Sec. 4 state that $\operatorname{rank}_+ P(X_S, X_{S^c})$ bounds the state-space cardinality of a single-cut separator rather than the number of open latents $o(s)$.

**1.5 [Medium] T2 & T2a: Missing factor-assignment rule, richness condition fails when open nuisance latents decouple from target $y$, and $y^*$ is not open inside labelled-only cuts**
- **Text at issue (Sec. 5.1, T2 & T2a):** *"The message $m_S(u_{\text{open}}) =$ sum over closed latents of the product of the factors and item likelihoods inside $S$, and the merge multiplies children's messages and sums out the latents that close there... Minimality: if the outside data can produce likelihoods that separate functions of the open latents, two contents with non-proportional messages are Nerode-inequivalent, so no smaller message is exact. PROVEN UNDER that richness condition... Within a source, $v_s$ is open too. PROVEN (from the model)."*
- **Error:**
  1. Factors $\psi_c(u_c)$ on latents that remain open at $v$ (such as the prior $\psi(y^*)$) cannot be included in both $m_a$ and $m_b$, or multiplying $m_a m_b$ double-counts $\psi_c$; each factor must be assigned to a unique node of the hierarchy.
  2. For the normalized posterior of a target $y \subsetneq u_{\text{open}}$, if an open nuisance latent $\eta \in u_{\text{open}} \setminus \{y\}$ does not couple to $y$ in $S^c$ (so $m_{S^c}(y,\eta) = g(y)h(\eta)$), then $m_S(y,\eta) = f(y)r(\eta)$ and $m'_S(y,\eta) = f(y)r'(\eta)$ are non-proportional on $u_{\text{open}}$ yet produce the **exact same** normalized posterior $p(y \mid x_S, x_{S^c})$ for all $x_{S^c}$ because $\int r(\eta)h(\eta)d\eta$ cancels in the normalization over $y$. Richness must require that $S^c$ can produce likelihoods coupling every open latent in $u_{\text{open}}$ to the target $y$.
  3. In T2a (tiny-PFN), the 5 historical questions of source $s$ have shown labels $y_{s,t}$ and do not depend on the query answer $y^*$. For a cut $S$ containing only historical questions of source $s$ (such as the source-splitting cut in Sec. 6.3 M1: "two of one source's labelled questions vs the rest"), **only $v_s$ is open** ($y^*$ is not attached inside $S$).
- **Fix:** Assign each latent factor $\psi_c$ to the unique lowest node containing its scope; require in the richness condition that outside likelihoods couple all open latents to the target $y$; clarify in T2a that $y^*$ is open at a within-source cut $S$ only if $S$ contains the query reading.

**1.6 [Medium] T3a: Missing compact-prior and uniform-complex-bound hypotheses**
- **Text at issue (Sec. 5.2, T3a):** *"Smooth families (PROVEN UNDER analyticity of $l(\theta; x)$ in a complex neighbourhood of the prior range, uniformly in $x$): Chebyshev interpolation gives epsilon-rank $r(\epsilon) = O(\log(1/\epsilon)^d)$. Per-source sup error $\epsilon$ gives log-posterior error at most $2 N \epsilon$ (so $\text{KL} \le 2 N \epsilon$)"*
- **Error:**
  1. $\text{KL}(p \| \tilde{p}) \le 2N\epsilon$ requires that the prior $\pi(\theta)$ has **compact support** contained inside the Chebyshev interpolation box (in tiny-PFN, the prior on $y^*$ is an unbounded Gaussian, and $[-5.5, 5.5]$ is a truncation).
  2. Uniform Chebyshev error $\epsilon$ across all $x$ requires not just analyticity on a fixed Bernstein ellipse $E_\rho$, but that $\sup_{\theta \in E_\rho} |\ell(\theta; x) - c(x)| \le M < \infty$ uniformly in $x$, which fails for unbounded observations $x \in \mathbb{R}$ (even for a Gaussian location family $\ell(\theta; x) = -(x-\theta)^2/2\sigma^2$) unless $|x|$ is bounded or the bound holds with high probability over $x$.
- **Fix:** State compact support of $\pi(\theta)$ and uniform boundedness of $|\ell(\theta; x) - c(x)|$ on the complex neighbourhood $E_\rho$ (or restrict to bounded $x$).

**1.7 [Medium] T7: Missing shared-randomness and union-bound $\log N$ factor in key size**
- **Text at issue (Sec. 5.4, T7):** *"Sending $O(\log(1/\delta)/\rho^2)$ random coordinates achieves it. So per-item keys must have about $\min(T, 1/\rho^2)$ bits"*
- **Error:** For per-item keys $k_i(x_i)$ to estimate pairwise correlations without interactive communication, all items must sample the **same** coordinate subset (requiring shared/public randomness independent of the histories), and to group all $N$ items correctly across all $\binom{N}{2}$ pairs simultaneously, a union bound requires failure probability $\delta / N^2$, making the upper-bound key length $O(\min(T, \log(N/\delta)/\rho^2))$ bits rather than $O(\log(1/\delta)/\rho^2)$. Also, when $\rho < 2/\sqrt{T}$, the repetition reduction on $n = 4/\rho^2$ coordinates does not apply ($T\rho^2/4 < 1$); the $\Omega(T)$ lower bound in that regime follows instead by embedding $\text{GHD}_{T, \sqrt{T}}$ without repetition since gap $\pm 2/\sqrt{T}$ implies gap $\pm \rho$.
- **Fix:** Note that the $\rho < 2/\sqrt{T}$ lower bound uses unrepeated $\text{GHD}_{T,\sqrt{T}}$, and include shared randomness and the $\log N$ union-bound factor in the upper bound.

**1.8 [Medium] T11a: Cost is cubic ($O(RK(R+K))$), not the product $RK$, and T11a is an upper bound, not a necessity proof**
- **Text at issue (Sec. 5.7, T11a & Plain Summary 6):** *"so the exact law of $f(X)$ (every tail) costs $O(\sum_v R_v (R_a K_a + R_b K_b + K_a K_b))$. Exact estimation needs the computation and the input law untangled along the same hierarchy; the cost scales with the product of the two bond dimensions."*
- **Error:**
  1. For uniform bond dimensions $R_v = R$ and $K_v = K$, the stated cost per node is $O(R^2 K + R K^2) = O(RK(R+K))$, which is **degree 3** in the bond dimensions, not their product $RK$.
  2. T11a is a dynamic-programming **upper bound** (sufficiency), not a lower bound ("needs"). Moreover, if $f$ is symmetric (e.g. $\sum_i x_i$ on $\{0,1\}^N$, which has $K_v \le N+1$ along *every* tree), $f$ can always be evaluated along the input law's tree $T_1$.
- **Fix:** Change "needs" to "is tractable when", and state that the cost per node is $O(RK(R+K))$.

**1.9 [Medium] T11d: Five unstated or imprecise steps in the noisy-message capacity bound**
- **Text at issue (Sec. 5.7, T11d):** *"Noise forces dimension to grow with scale (PROVEN UNDER a Gaussian prior on theta, $N$ sources with Fisher information $I$ each, and a root that sees one $m$-dimensional message with signal range $R$ and noise $\sigma$ per coordinate). If the root outputs a Gaussian within KL $\delta$ of Bayes's $\mathcal{N}(\mu_N, v_N)$ on every input, its mean-squared error is at most about $(1 + 2 \delta) v_N$, with $v_N = 1/(1 + N I)$, so $I(M; \theta) \ge (1/2) \log_2((1 + N I) / (1 + 2 \delta))$ by rate-distortion, while $I(M; \theta) \le (m/2) \log_2(1 + R^2/\sigma^2)$ by capacity."*
- **Error:**
  1. $v_N = 1/(1 + NI)$ and exact Gaussianity of the posterior require a **unit-variance** prior $\theta \sim \mathcal{N}(0,1)$ and **linear-Gaussian sources** $x_i \mid \theta \sim \mathcal{N}(\theta, 1/I)$ (arbitrary non-Gaussian sources with Fisher information $I$ do not have exact Gaussian posteriors with constant variance $v_N$).
  2. $I(M; \theta) \le \frac{m}{2}\log_2(1 + R^2/\sigma^2)$ requires the channel noise to be **independent additive white Gaussian noise (AWGN)** $\mathcal{N}(0, \sigma^2 I_m)$ (non-Gaussian noise of variance $\sigma^2$ can have strictly larger capacity) and $|M_j - \xi_j| \le R$ (radius $R$; if "range $R$" means peak-to-peak interval of length $R$, the variance bound is $R^2/4$).
  3. Under unbounded Gaussian noise $\xi$, the root cannot achieve $\text{KL} \le \delta$ "on every input" (and noise realization); the condition must be in expectation $\mathbb{E}[\text{KL}] \le \delta$.
  4. For forward KL $\text{KL}(\mathcal{N}(\mu_N, v_N) \| \mathcal{N}(\hat{\mu}, \hat{v})) \le \delta$ (measured in nats), $(\hat{\mu} - \mu_N)^2 \le 2\delta \hat{v}$, which gives $\text{MSE} \le (1 + 2\delta)v_N$ only asymptotically as $\delta \to 0$ (since $\hat{v}/v_N$ can exceed $1 + \sqrt{2\delta}$); the exact inequality $\text{MSE} \le (1 + 2\delta)v_N$ for all $\delta > 0$ holds for **reverse** KL $\mathbb{E}[\text{KL}(\mathcal{N}(\hat{\mu}, \hat{v}) \| \mathcal{N}(\mu_N, v_N))] \le \delta$ in nats.
- **Fix:** Specify $\theta \sim \mathcal{N}(0,1)$, Gaussian sources $x_i \mid \theta \sim \mathcal{N}(\theta, 1/I)$, AWGN channel $\mathcal{N}(0, \sigma^2 I_m)$ with amplitude bound $[-R, R]$, and expected reverse KL $\mathbb{E}[\text{KL}(\hat{Q} \| P_{\theta|X})] \le \delta$ in nats.

**1.10 [Low] T1, T6a, T12, Sec. 5.8, and A1: Minor mathematical inaccuracies**
- **T1 (Sec. 2):** *"log2 K_f(S) is the deterministic one-way communication complexity from S to the rest (number of distinct rows of the communication matrix)."* Fix: $K_f(S)$ (not $\log_2 K_f(S)$) is the number of distinct rows, and the deterministic one-way complexity is $\lceil \log_2 K_f(S) \rceil$.
- **T6a (Sec. 5.4):** *"the logit gap must be at least about $\log(N / \delta)$."* Fix: Change "logit gap" (standardly top-1 minus top-2 logit, which only needs to be $\log(1/\delta)$ if other logits are $-\infty$) to **logit range** $\max_j L_j - \min_j L_j \ge \log((N-1)(1-\delta)/\delta)$ (as correctly named in Table 8).
- **T12 (Sec. 5.8):** *"block mutual information at most $(2(b - 1) \log_b L + O(1)) \log_2 q$"* and *"converges to a Gaussian or stable law... max-merges converge to extreme-value laws. PROVEN"*. Fix: Conditioning on the ancestors along the two boundary paths of the interval separates the block using at most $2\log_b L + O(1)$ nodes (removing the $b-1$ factor); and convergence to stable / extreme-value laws requires the per-item law to lie in the respective **domain of attraction** (e.g., discrete geometric/Poisson maxima do not converge to any extreme-value law).
- **A1 (Sec. 6.1):** *"Without the sink... the merged message loses its total precision and is not closed under further merges."* Fix: Even with a single shared sink token $\tau_0$, hierarchical multi-stage merges are **not** closed without subtracting $\tau_0$ at intermediate nodes, because merging two already-sunk subtrees adds $\tau_0$ twice ($2\tau_0 + \tau_A + \tau_B$).

### 2. Status Tags That Are Too Strong or Too Weak

**2.1 [High] Too strong — A2 (`PROVEN (construction sketch)` in Sec. 6.2 & Table 8): Transformers implementing $R$-round SFU computations in $O(R)$ layers**
- **Text at issue (Sec. 6.2 & Table 8, A2):** *"a transformer whose labels are linearly readable can implement an R-round SFU computation with message size $k$ in $O(R)$ layers and width $O(k + \text{label dimension})$... (PROVEN as a construction sketch; MLP steps are approximations)."*
- **Why too strong:** In Sec. 1 and Sec. 4, a single **round** is a full upward pass of a hierarchy $T$ of depth up to $H = O(\log N)$, where latents close and are **marginalized out** ($\log\sum_{u_{\text{closed}}}\exp(\cdot)$, a nonlinearity) at every internal scale before the next scale's merge. One attention+MLP layer can only perform a single level of group pooling followed by one nonlinearity, so simulating 1 round of a multi-level SFU hierarchy of depth $H$ requires $\Omega(H)$ transformer layers (not $O(1)$ layers per round) unless the hierarchy is flat (depth 1). Furthermore, undoing softmax normalization via $\bar{T}/a_0$ requires dividing by $a_0 = \Theta(1/N) \to 0$, which cannot be uniformly approximated by a fixed-size MLP as $N \to \infty$.
- **Fix:** Downgrade A2 (and the exponential-family MLP claim in Sec. 6.1) to **`PROVEN UNDER` flat (1-level) routing hierarchies and bounded group size $N \le N_{\max}$** (or **`HEURISTIC`** for general multi-scale hierarchies).

**2.2 [High] Too strong — T2b (`PROVEN UNDER the Gaussian model`), T1 tolerance (`PROVEN`), T3a (`PROVEN UNDER analyticity`), T4 (`PROVEN UNDER ...`), and Sec. 4 nonnegative rank (`PROVEN`)**
- **Why too strong:** See Findings **1.1–1.5** above. In particular, T2b's $T|S|$ claim for the query predictive is false for $T \ll |S|$ under exchangeable priors, and Sec. 4's `PROVEN` claim that nonnegative rank across a cut makes the open-latent profile $o(s)$ parameterization-independent conflates single-cut discrete state count with multi-cut latent variable count.
- **Fix:** Apply the hypothesis and statement corrections in Findings 1.1–1.5.

**2.3 [Medium] Too weak — T4a (`HEURISTIC` in Sec. 5.3 & Table 8): Exponential growth of one-round message size in $D$**
- **Text at issue (Sec. 5.3 & Table 8, T4a):** *"One-round size grows exponentially in the number of open latents for location-type families | HEURISTIC; MEASURED (N2)"*
- **Why too weak:** For smooth location families $\ell(\theta - \mu_x)$ on $[-M, M]^D$ with scale $\sigma \ll M$, the Kolmogorov $n$-width / $\epsilon$-rank of the translation family $\{\ell(\cdot - \mu) : \mu \in [-M, M]^D\}$ in $L_\infty([-M, M]^D)$ is **provably** $\Omega((M/\sigma)^D \log(1/\epsilon)^D)$ by standard metric-entropy / Bernstein-width lower bounds (e.g., Novak & Woźniakowski 2008, *Tractability of Multivariate Problems*, Vol. I).
- **Fix:** Upgrade to **`PROVEN UNDER` non-degenerate translation-invariant kernel on $[-M,M]^D$**.

**2.4 [Low] Too weak — T11b (`CONJECTURE` / `MEASURED` in Sec. 5.7 & Table 8): Linear treewidth of the union of two independent random binary trees**
- **Text at issue (Sec. 5.7):** *"linear growth is not established (CONJECTURE: linear for independent random trees, as for expanders)."*
- **Why too weak:** The union of two independent leaf-labelled binary trees on $N$ leaves (a random tanglegram / cubic multigraph formed by identifying leaves) is a random subcubic graph that contains a $\Theta(N)$-vertex expander minor with high probability, so its treewidth is **provably $\Theta(N)$** w.h.p. (Bollobás 1988, *Random Graphs*).
- **Fix:** Upgrade from `CONJECTURE` to **`PROVEN` (cited, w.h.p.)**.

### 3. Known Results Presented as New and Missing Prior Work

**3.1 [High] "Open-latent profile" (Sec. 4 & 5.1 T2) is separator width / induced width in junction trees and bucket elimination**
- **Text at issue (Plain Summary 2, Sec. 4, Sec. 5.1):** Presented as a new framework (*"The definition that fits your intuition... the message at a node covering $s$ items is the likelihood of the latents that are still open at that node"*).
- **Missing attribution:** The set of latents attached both inside and outside subtree $S_v$ is the **separator** at edge $v$ in a junction tree / cluster tree (Lauritzen & Spiegelhalter 1988, *JRSS-B*, "Local computations with probabilities on graphical structures and their application to expert systems"), and the open-latent profile $o(s)$ along an elimination tree is the classical **induced width** in variable/bucket elimination (Dechter 1999, *Artificial Intelligence*, "Bucket elimination: A unifying framework for reasoning"). Input-dependent routing of the elimination tree is **context-specific independence** (Boutilier, Friedman, Goldszmidt, Koller 1996, *UAI*).
- **Fix:** Explicitly credit junction-tree separators (Lauritzen & Spiegelhalter 1988) and bucket-elimination induced width (Dechter 1999) as the graphical-model equivalents of $u_{\text{open}}$ and $o(s)$.

**3.2 [High] "What is ours is the link to architectures" (Plain Summary 3 & Sec. 6.1) misses the 2022–2024 literature on transformers as multi-round iterative estimators and attention sinks**
- **Text at issue (Plain Summary 3 & Sec. 6.1):** *"The mechanism is known in distributed statistics (one-step estimators); what is ours is the link to architectures and these measurements"* and Sec. 6.1 A1 (*"Attention is the merge of Gaussian messages, with the prior as a sink"*).
- **Missing attribution:**
  1. **Transformer layers as iterative statistical estimation / Newton / gradient steps around a pilot:** Bai et al. (NeurIPS 2023, "Transformers as Statisticians: Provable In-Context Learning with In-Context Algorithm Selection", arXiv:2306.04637), von Oswald et al. (ICML 2023, "Transformers Learn In-Context by Gradient Descent", arXiv:2212.07677), and Ahn et al. (NeurIPS 2023, "Transformers learn to implement preconditioned gradient descent for in-context learning", arXiv:2306.00297) already establish that multi-layer transformers implement multi-round iterative parameter refinement in-context.
  2. **Attention sinks as softmax normalizer / default prior channel:** Xiao et al. (ICLR 2024, "Efficient Streaming Language Models with Attention Sinks", arXiv:2309.17453) introduced the term "attention sink" for a token that absorbs softmax denominator mass when query-key evidence is weak.

### 4. Central Proposal (Section 4: SFU) and Separations Table (Section 3)

#### 4A. Strongest Objections and Counterexamples to the SFU Definition (Section 4)

**4.1 [High] Counterexample 1 — Static round-0 label routing (Clause 1) fails when routing itself depends on multi-round inference (e.g., W2 hidden group membership)**
- **Text at issue (Sec. 4, Clauses 1–2; Table 5.9 Row 4):** Clause 1 fixes the hierarchy from per-item $b$-bit labels $\lambda(x_i)$ *before* message passing, while Clause 2 uses rounds only to expand log-likelihoods of open latents on that fixed hierarchy. In Table 5.9 Row 4 (*"G groups, membership hidden"*), the note claims this has *"function of G latents"* and *"broadcast: O(G^2)"*.
- **Objection / Counterexample:** In W2 with **hidden group membership** across $T_{\text{hist}}$ past questions (Sec. 6.5: *"W1 plus G shared-error groups (one shared error per group and question), membership visible as a label or hidden"*), each source $i$ has a persistent hidden group assignment $z_i \in \{1,\dots,G\}$, and each question $t \in \{1,\dots,T_{\text{hist}}\}$ has $G$ shared group errors $(g_{1,t},\dots,g_{G,t})$. Because $z_i$ is hidden ($b = 0$), any hierarchy splits every group. Worse, $z_i$ only closes inside source $i$ if source $i$'s message is a function of **all $G \times T_{\text{hist}}$ group errors** $(g_{c,t})_{c \in [G], t \in [T_{\text{hist}}]}$ plus $y^*$—so **$G T_{\text{hist}} + 1$ latents are open at every source cut, NOT $G$ latents!** Table 5.9 Row 4's claim of $G$ open latents and $O(G^2)$ broadcast is **false** whenever $T_{\text{hist}}$ grows. Conversely, if Round 1 broadcasts pilot group errors so sources can infer their memberships $\hat{z}_i$ and **re-route** into group-aligned subtrees in Round 2, routing must be updated *between rounds*—which SFU's Clause 1 excludes.
- **Fix:** Allow the routing labels $\lambda^{(r)}(x_i, \text{broadcast}_{<r})$ in SFU Clause 1 to be updated across rounds, and correct Table 5.9 Row 4 to state that with fixed hierarchy and $T_{\text{hist}}$ questions, $G T_{\text{hist}}$ group-error latents are open (unless routing is updated after a pilot round).

**4.2 [High] Counterexample 2 — Bounding $o(s)$ does not bound the cost of Clause 3 ("sum out the latents that close") or of two-round multimodal posteriors**
- **Text at issue (Sec. 4, Clauses 2–3):** *"Untangled means $b = O(\log N)$ and $o(s)$ small (bounded, or growing with the number of groups, not of items)... (combination) every merge, at every scale, is the same two operations: add log-likelihoods, and sum out (contract) the latents that close at that node."*
- **Objection / Counterexample:**
  1. **Closing complexity vs open complexity:** If a node $v$ encloses a set of latents $u_{\text{closing}}$ whose internal factor graph is an expander or 2D grid, the number of *open* latents at $v$ is $o(s) \le 1$, yet Clause 3's step of summing out $u_{\text{closing}}$ at node $v$ is **#P-hard**. Even if latents close one by one, allowing $o(s)$ to "grow with the number of groups $G$" means the joint table/expansion over $o(s) = G$ simultaneous open latents has size $\exp(\Omega(G))$ in one round, and marginalizing a closing latent requires integrating over it jointly with all $o(s)$ open latents.
  2. **Multimodality / label-permutation symmetry breaks 2-round Taylor expansion:** In W2 with $G$ exchangeable hidden groups, the posterior over the $G$ group latents has **$G!$ exact permutation modes**; a single broadcast pilot and local degree-$p$ Taylor expansion (Clause 2) cannot represent a symmetric multimodal posterior unless symmetry is broken before broadcasting.
- **Fix:** Require in SFU that $\text{open}(a) \cup \text{open}(b)$ (which equals $\text{open}(v) \cup \text{closing}(v)$) has bounded size (not $O(G)$) at every merge node $v$, and note that two-round local expansions require an identifiable unimodal (or symmetry-broken) posterior.

#### 4B. Errors in the Separations Table (Section 3) and Table 5.9

**4.3 [High] Sec. 3 Row 3 (`D3 vs estimation: same f = sum_i a_i x_i`): Conflates the rank-2 function $f(x)$ with the exponential-rank threshold indicator $\mathbf{1}\{f(x) > t\}$**
- **Text at issue (Sec. 3, Row 3):** *"D3 vs estimation: same $f$ | $E f$ is trivial; $P(f > t)$ under the uniform law is counting knapsack solutions, #P-complete (Dyer 2003) | PROVEN"*
- **Error:** $P(f(X) > t) = \mathbb{E}[\mathbf{1}\{f(X) > t\}]$ is the expectation of the **step composition** $h(x) = \mathbf{1}\{\sum_i a_i x_i > t\}$, not of $f(x)$. Across a balanced cut, $h(x)$ has D3 rank **$2^{n/2}$** (full rank), not rank 2. Thus #P-hardness of $P(f(X) > t)$ does not separate low D3 rank of an observable from computing its expectation; it simply reflects that applying an indicator $\mathbf{1}\{\cdot > t\}$ blows up D3 rank from $2$ to $2^{n/2}$. (Also, #P-completeness of $0$-$1$ knapsack counting is due to Simon 1977 / Valiant 1979, whereas Dyer 2003 is on approximate counting.)
- **Fix:** State that D3 rank is not closed under nonlinear readout $\mathbf{1}\{f(x) > t\}$ (which has D3 rank $2^{n/2}$), so low D3 rank of $f$ suffices for $\mathbb{E}[f(X)]$ but not for tails $\mathbb{E}[\mathbf{1}\{f(X) > t\}]$.

**4.4 [Medium] Sec. 3 Rows 4 & 5 (`D4 vs D1/D3` and `D4 vs everything`): Misstates D4(a) circuit treewidth and D4(b) latent graphical-model treewidth**
- **Text at issue (Sec. 3, Rows 4 & 5):** Row 4: *"D4 vs D1/D3: $f = x^T U x \bmod 2$ on the complete graph | treewidth $n - 1$"*. Row 5: *"D4 vs everything: Bayes with one shared target $\theta$ | items are pairwise dependent (a clique, treewidth $N - 1$); one latent is open at every cut"*.
- **Error:** In Sec. 2, D4 includes *(a) treewidth of the computation's DAG* and *(b) the graphical model of the items or activations*.
  - In Row 4, since $f(x) = \binom{|x|}{2} \bmod 2$ depends only on $|x| \bmod 4$, the minimal Boolean circuit computing $f$ along a binary tree has **circuit treewidth $O(1)$** under D4(a); only the naive pairwise interaction graph has treewidth $n-1$.
  - In Row 5, the bipartite graphical model over $(x_1,\dots,x_N, \theta)$ is a **star graph of treewidth 1**; it only becomes a clique of treewidth $N-1$ when $\theta$ is marginalized out first while SFU is allowed to keep $\theta$ explicit.
- **Fix:** Specify "treewidth of the pairwise interaction graph" in Row 4 and "treewidth of the marginal item graph (with latents integrated out)" in Row 5.

**4.5 [High] Table 5.9 Rows 1 & 6: Wrong D1 bit count for exponential families and impossible $(O(k\log n) \text{ bits},\, \log k \text{ layers})$ combination for $k$-hop lookup**
- **Text at issue (Sec. 5.9, Table):**
  - Row 1 (*"Conditionally independent sources, exponential family"*): Column `D1 fixed cuts` says `(d/2) log s bits`.
  - Row 6 (*"k-hop lookup (pointer chasing)"*): Column `D2 routed` says `O(k log n) in k rounds`, and Column `SFU` says `untangled with k rounds (log k layers)`.
- **Error:**
  1. **Row 1:** In D1 (exact Nerode classes), a continuous exponential family has $\infty$ classes, and a discrete one (e.g. $d$ binary statistics summed over $s$ items) has $(s+1)^d$ classes, i.e. **$d \log_2(s+1)$ bits**, not $(d/2)\log s$ bits (which is the asymptotic mutual information $I(X_S; \Theta)$ / rate-distortion at $O(1/\sqrt{s})$ tolerance).
  2. **Row 6:** You cannot have **both** $O(k \log n)$ bits across cuts **and** $\log k$ layers! Sequential pointer chasing tracks the single active pointer from the root in **$k$ sequential broadcast rounds ($\Omega(k)$ layers)** using $O(\log n)$ bits per round; Sanford, Hsu, Telgarsky (2024) achieve $\Theta(\log k)$ transformer layers via **parallel pointer doubling**, where *every* node $i \in [n]$ simultaneously looks up its $2^\ell$-th successor, which requires **$\Omega(n \log n)$ bits across cuts per layer** (volume law). Also, D2 in Sec. 2 is a 1-round upward pass without root broadcast, which still requires $\Omega(n)$ bits for pointer chasing.
- **Fix:** In Row 1, change exact D1 to $\infty$ (continuous) / $d\log_2(s+1)$ (discrete), or label $(d/2)\log s$ as $\epsilon$-tolerant D1 at $\epsilon = O(1/\sqrt{s})$. In Row 6, separate sequential broadcast ($k$ rounds / $k$ layers, $O(k\log n)$ bits) from parallel pointer doubling ($\log k$ layers, $\Omega(n\log n)$ bits per layer).

### 5. Transformer Measurements (Section 6.3–6.4) and Experiment Spec (Section 6.5): Discriminative Power and Confounds

**5.1 [High] M4 (Sec. 6.3, Bottleneck probes): Fatal design flaw — measures the input-output function's sufficiency, not the network's internal messages**
- **Text at issue (Sec. 6.3, M4):** *"Distil the net's predictive into an encoder of source $s$'s tokens to $k$ numbers plus a decoder that also sees the other tokens... Smallest $k$ with $\text{KL}(\text{net} \| \text{probe}) \le 0.01$... Refuted if: general $k \gg 2$: the net passes more than the sufficient statistic between sources (tangled beyond the task)."*
- **Why it fails to discriminate / Confound:** M4 trains an **external encoder $E(x_s) \in \mathbb{R}^k$ on raw input tokens $x_s$** and an external decoder $D(E(x_s), x_{-s})$ to approximate the final output $p_{\text{net}}(y \mid x)$, **without bottlenecking the network's internal activations**. By the triangle inequality, for any trained network that is already close to Bayes ($\text{KL}(p_{\text{Bayes}} \| p_{\text{net}}) \le 0.007\text{--}0.03$, as in Table 6.4), an external encoder $E(x_s) \in \mathbb{R}^2$ that simply computes the 2 exact Bayesian sufficient statistics of $x_s$, paired with a general decoder computing exact Bayes, will achieve $\text{KL}(\text{net} \| \text{probe}) \approx 0.007 \le 0.01$ at $k = 2$ **even if the transformer internally passes all $T$ raw tokens across sources in a maximally tangled way**!
- **Fix:** Insert the $k$-dimensional bottleneck **causally inside the transformer's cross-source attention messages / residual stream** (activation patching / internal causal bottleneck), rather than training an external autoencoder from raw inputs $x_s$ to $p_{\text{net}}(y \mid x)$.

**5.2 [High] M1 & Sec. 6.4 (N5 Interaction profile): Confounded by 2-round pilot broadcast, Gaussian-head projection, and distance-to-Bayes smoothness**
- **Text at issue (Sec. 6.3 M1 & Sec. 6.4 N5):** *"Refuted if: source-aligned share $\ge$ within-source share well above the floor: the net combines sources non-additively (tangled at the source scale)"* and Sec. 6.4: *"Bayes projected to a Gaussian (floor for Gaussian heads) | 0.054 | 0.054 | 0.010... Across all 40 nets the cross-source share correlates with KL to Bayes at 0.96"*.
- **Confounds:**
  1. **$0.054$ is NOT a floor for additive Gaussian heads:** For any Gaussian head $\mathcal{N}(\hat{\mu}, \hat{\tau}^{-1})$, the log-odds $\log p(y_1\mid x) - \log p(y_2\mid x) = (y_1 - y_2)(\hat{\tau}\hat{\mu}) - \frac{1}{2}(y_1^2 - y_2^2)\hat{\tau}$ is linear in the natural parameters $(\hat{\tau}\hat{\mu}, \hat{\tau})$. Therefore, a 1-round Gaussian head that merges sources additively in natural parameters (such as **Oracle GLS** in Sec. 6.1, where $\hat{\tau} = \tau_0 + \sum_s \tau_s(x_s)$) has **exact cross-source interaction $0$**, whereas the moment-matched Gaussian projection of Bayes has interaction **$0.054 > 0$** (already satisfying M1's refutation inequality $\text{cross-source} \ge \text{within-source}$!) because moment-matching uses cross-source query agreement $(o_s - o_{s'})^2$ to inflate variance when sources disagree. Thus for Gaussian heads, improving from 1-round GLS to optimal moment-matched Gaussian Bayes **increases** cross-source interaction from $0$ to $0.054$.
  2. **Two-round SFU creates non-zero M1 interaction:** In a 2-round SFU protocol (Sec. 5.3), each source expands its non-quadratic log-likelihood around the shared broadcast pilot $\hat{y}_{\text{pilot}}(x_1,\dots,x_N)$, coupling $a$ and $b$ in the finite-degree truncation error and producing $\Delta \ne 0$ even when the architecture is strictly SFU.
  3. **Smoothness confound in the 0.96 correlation (Sec. 6.4):** Because $\Delta(p_{\text{Bayes}}) = 0$, *any* smooth functional vanishing at $p_{\text{Bayes}}$ satisfies $|\Delta(p_{\text{net}})| \le L \cdot d(p_{\text{net}}, p_{\text{Bayes}})$ and will correlate strongly with $\text{KL}(p_{\text{Bayes}} \| p_{\text{net}})$ across good vs bad networks without proving that non-additivity is the cause of the KL gap.
- **Fix:** Distinguish 1-round natural-parameter additivity ($\Delta = 0$ for Oracle GLS) from 2-round cross-source variance adaptation ($\Delta = 0.054$ for moment-matched Gaussian Bayes); control for distance to Bayes when testing M1 across architectures.

**5.3 [High] Sec. 6.5 (P5, Exact output law by convolution): Fails for 2-pass trees (shared pilot breaks conditional independence) and has $O(M^k)$ grid complexity**
- **Text at issue (Sec. 6.5, P5):** *"for the SFU tree, given $y^*$ and the latents, the summed message is a sum of independent per-group terms, so the law of the output (all tails) is a convolution that can be computed exactly on a grid or bounded by Chernoff; compare against sampling at equal compute."*
- **Why it fails / Confounds:**
  1. **Loss of conditional independence in 2-pass trees:** In the 2-pass tree (which P1 relies on to keep $k = 5\text{--}7$ small), each group's pass-2 message $m_g^{(2)}(x_g, \hat{\theta}_{\text{pilot}}(x_1,\dots,x_N))$ depends on the **global pilot $\hat{\theta}_{\text{pilot}}$**. Given only $y^*$ and the latents, the pass-2 messages are **dependent across groups** through $\hat{\theta}_{\text{pilot}}$; restoring independence requires conditioning on the continuous pilot value $\hat{\theta}_{\text{pilot}}$ (or convolving jointly in $\mathbb{R}^{3+k}$).
  2. **Curse of dimensionality in $k$-D grid convolution & nonlinear readout MLP:** Convolving $N$ distributions on a $k$-dimensional grid with $M$ bins per coordinate costs $O(N M^k \log M)$, which for $k = 5\text{--}8$ (2-pass) or $k = 48\text{--}64$ (1-pass) is vastly slower than Monte Carlo sampling at equal compute; and Chernoff bounds apply to scalar linear sums, not to the distribution after the **nonlinear readout MLP** specified in Sec. 6.5.
- **Fix:** Restrict exact grid convolution to $k \le 2\text{--}3$ in 1-pass (or condition on a discretized scalar pilot in 2-pass with scalar log-likelihood evaluations at target points $y$), and apply Chernoff/saddlepoint bounds to the additive log-odds message *before* any nonlinear readout MLP.

**5.4 [Medium] M2 & M3 (Sec. 6.3, Routing classes & causal substitutions): Confounded by fixed token layout in tiny-PFN and per-episode free parameters $w_j$**
- **Text at issue (Sec. 6.3, M2 & M3):** M2 fits $L_{ij} = R(\text{pair class}) + w_j + e_{ij}$ with *"w_j free per key and episode; R^2 of the full fit and of R alone on held-out episodes"*. M3 compares replacing logits by *(ii) $R$ alone* vs *(iii) another episode with the same layout* vs *(iv) the episode-averaged pattern*, predicting *(iii), (iv) worse than (i)* and *(ii) or (iv) as good as (i)* refuting input-dependent attention.
- **Confounds:**
  1. **Fixed token layout confound (M3):** In tiny-PFN, although there are no positional encodings, if tokens sit at the same array indices $(s, q)$ across episodes ("another episode with the same layout"), then the pair-class matrix $R(\lambda_i, \lambda_j)$ is **identical in every episode**, so **(iv) the episode-averaged pattern equals (ii) $R$ alone (plus average class weight)**! Thus (iv) does not ablate routing in tiny-PFN—it only ablates episode-specific precision weights $w_j$, making (ii) and (iv) indistinguishable unless token order is randomly permuted per episode.
  2. **Unidentifiable / non-transferable $w_j$ and softmax shift invariance (M2):** Fitting $w_j$ freely per episode adds $N_{\text{tok}}$ parameters per episode that cannot be evaluated on "held-out episodes" without refitting on the test episode; also, raw logit $R^2$ is sensitive to arbitrary row shifts $c_i$ (which leave softmax unchanged) and to large errors on strongly negative logits that have zero effect on attention weights.
- **Fix:** Permute token order randomly per episode in tiny-PFN before running M3(iii)–(iv); project out row means before computing logit $R^2$ in M2 (or measure KL/TV between softmax rows $\text{softmax}(L)$ and $\text{softmax}(R + w)$).

**5.5 [Medium] Sec. 6.5 (P1–P4, 2x2 Experiment Spec): Confounds between routing mechanism, $O(d)$-equivariance, and hierarchy depth**
- **Text at issue (Sec. 6.5):** *"Learned routing for the tree: a router that assigns tokens to groups from their ID embeddings (attention to learned prototypes, or hashing); the dense net routes by itself."* And for W2: *"SFU tree (per-group encoder, a set network over that group's tokens, to k numbers; merge = sum; readout = small MLP)"*.
- **Confounds:**
  1. **Hashing vs learned prototypes on random per-episode IDs (P4):** Because tokens of the same source share the **exact same** random ID embedding vector within an episode, **hashing** (or exact key grouping) on the ID embedding vector trivially gives 100% oracle routing with zero learning, whereas **attention to fixed learned prototypes** breaks $O(d)$-rotation equivariance across episodes (unlike dense pairwise self-attention $q_i \cdot k_j$, which depends only on inner products of the episode's random IDs). Neither is a fair comparison to dense learned routing.
  2. **1-level set encoder cannot represent W2's 2-level hierarchy (P2/P3):** W2 has two nested grouping scales (tokens $\to N$ sources with reliability $v_s$ $\to G$ groups with shared error $g_{c,t}$ $\to$ root $y^*$). The specified 1-level SFU tree ("per-group encoder, a set network over that group's tokens... merge = sum") collapses either the source boundaries or the shared-error group boundaries.
  3. **Unmatched capacity in 1-pass vs 2-pass tree (P1):** The 2-pass tree uses two encoders, $k+3$ numbers, and a hand-engineered pilot summary ("pilot mean and scale"), confounding round count with parameter count and domain-specific inductive bias.
- **Fix:** Use pairwise ID dot-product clustering ($q_i \cdot k_j$) for the tree's learned router in P4; use a 2-level tree (tokens $\to$ sources $\to$ error groups $\to$ root) in W2; and match total message dimension ($k$ vs $3 + (k-3)$) and learned broadcast readout between 1-pass and 2-pass trees in P1.
